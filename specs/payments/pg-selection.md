# PG 선택

**Status**: Draft (미결정) · **Updated**: 2026-06-03

{: .highlight }
> **recoverGX 단순화**: GX 모델에서 PG 연동 범위는 **지갑 충전 1건**만. 클래스 예약·취소는 지갑 내부 차감으로 PG 미관여. 정기결제(빌링키) 불필요. 현재 mock PG 사용 중.

## 연동 범위 (GX 기준)

| 동작 | PG 관여 | 비고 |
|---|---|---|
| 지갑 충전 | ✅ | 1회성 결제 (`POST /api/wallet/charge`) |
| 클래스 예약 | ❌ | 지갑 내부 차감 |
| 취소 환불 | ❌ | 지갑 내부 복구 |
| 폐강 전원 환불 | ❌ | 지갑 내부 복구 |

## 후보

- 토스페이먼츠 vs 포트원

## 결정 기준

- 단건 결제·환불 지원 (정기결제 불필요)
- 한국 시장 점유율
- 수수료

## 추천

- Phase 1 (GX): **토스페이먼츠** — 단건 결제 API 단순, 개발자 문서 우수
- Phase 2 (가맹·구독 등): 포트원 — 다중 PG 지원 시 유리

> **실 PG 연동은 지갑 충전 통합 테스트 완료 후 진행** (기술부채: `wallet charge 멱등 경로 통합 테스트` 우선순위 높음). 1호점 직전 최종 결정.
