# 👤 멤버십·결제·정책 (회원 흐름)

**Status**: Draft
**관련 결정**: [2B 멤버십](../../members/membership.html) · [2C 가격](../../members/pricing.html) · [2D 정책](../../members/policies.html) · [2A 회원 여정](../../members/journey.html)

## 1. 회원 시나리오

| 단계 | 액션 |
|---|---|
| 가입 | 이름·연락처·기본 페르소나 정보 (운동 경험·목표) 입력 |
| 첫 체험 (선택) | 1만원 결제로 1세션 체험 — 의지 검증 |
| 멤버십 선택 | 주 1회권 / 주 2회권 + 약정 기간 (1/3/6/12개월) |
| 결제 | 카드·간편결제 → 자동결제 default |
| 포인트 충전 (옵션) | Pro 인증 멘토용 — 5만/10만/20만 단위 |
| 일시정지 (가능) | 사유 ❌, 자유. 약정 30% 이내, 자동 연장 |
| 환불 | 미사용 회차 정상가 환산 100% 환불, 약정 할인분 차감 |
| 갱신 | 자동결제 default. 7일 전 알림 + 업그레이드 권유 |
| 이탈 | 사유 서베이 → 환불 처리 → 6개월 후 콜백 |

## 2. 화면 요구사항

- **가입 화면**: 페르소나 입력 (운동 경험·주 운동 횟수·목표)
- **멤버십 선택 화면**:
  - 주 1회권 (월 4회) vs 주 2회권 (월 8회)
  - 약정 슬라이더 (1/3/6/12) 선택 시 가격 동적 표시
  - 자동결제 안내
- **결제 화면**: 토스페이먼츠/포트원 연동 (선택은 [🏢 결제 시스템](../platform/2026-05-13-membership-system.html))
- **포인트 충전**: 별도 결제 화면, 잔액 표시
- **마이페이지**:
  - 멤버십 정보 (회차·만료일·자동결제 여부)
  - 포인트 잔액
  - 결제 내역
  - 일시정지 토글 + 사유 입력 (선택)
  - 환불·해지 신청
- **갱신 알림 (7일 전)**: 푸시 + 인앱 배너 + 업그레이드 인센티브

## 3. 회원이 보는 환불·노쇼·취소 룰 (2D)

명확한 안내 카드:
- 변경/취소: 48h 전 무료 / 48h-6h 당일 예약권 / 6h 이내 차감
- 회원 노쇼: 회차 1회 차감
- 본사·멘토 측 노쇼: 회차 +1 보상

## 4. 데이터 모델 (회원 관점)

```
Membership
  ├─ member_id, type (주1/주2), credits, expires_at
  ├─ contract_months, discount, auto_renew, paused_at
PointBalance
  ├─ member_id, balance, last_charged_at
Payment
  ├─ id, member_id, type (membership/point/trial), amount, status
Refund
  ├─ id, payment_id, used_credits, refund_amount, reason
```

## 5. 다른 레이어 영향

- **🏢 플랫폼**: 결제 PG 연동·환불 산출 로직·일시정지 자동 처리·갱신 알림
- **💪 멘토**: 직접 영향 ❌ (정산에서 ↗)

## 6. 엣지 케이스

- 약정 기간 중 일시정지 + 환불 동시: 정지 해제 → 환불 산출
- 갱신 카드 결제 실패: 7일 grace + 자동 해지
- 포인트 결제 시 잔액 부족: 멤버십 회차로 fallback (일반 멘토 사용)
- 청약철회 (7일 이내): 사용분 차감 후 환불

## 7. 측정 지표

- 가입 → 첫 결제 전환율 ≥ 60%
- 갱신율 ≥ 70%
- 환불 발생률 ≤ 10%
