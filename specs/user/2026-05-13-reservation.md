# 👤 예약 시스템 (회원 흐름)

**Status**: Draft
**관련 결정**: [5A 예약 시스템](../../operations/reservation.html) · [2D 정책](../../members/policies.html) · [4B 세션 포맷](../../service/session.html)

## 1. 회원 시나리오

| 흐름 | 액션 |
|---|---|
| 신규 예약 (비피크) | 14일 캘린더 → 시간 선택 → AI 멘토 추천 3명 → 선택 → 확정 |
| 고정 슬롯 (피크 6-10pm) | 멤버십 가입 시 1회 시간 선택 → 매주 자동 예약 |
| 변경/취소 | 마이페이지 예약 리스트 → 변경/취소 |
| 자동 매칭 모드 ON | AI가 자동 매칭 → 회원 24h 거절권 |
| 멘토 변경 (거절) | 매칭된 멘토 거절 → 다른 멘토 자동 재매칭 |

## 2. 화면 요구사항

### 예약 화면
- 14일 캘린더 (오늘 ~ +14일)
- 시간 슬롯 표시 (피크/비피크 색상 구분)
- 고정 슬롯 = 자동 표시 (변경 ❌, 취소만 가능)
- 비피크 슬롯 = 가용 자리 수 표시

### 멘토 매칭 화면
- AI 추천 3명 노출 (수동 모드)
  - 사진·이름·평점·Pro 인증 배지·간단 소개
  - 이전 진행 멘토 = 상단 표시
  - Pro 인증 선택 시 = "포인트 차감" 안내
- 자동 매칭 모드 (옵션 ON) = 24h 거절 가능 화면

### 예약 변경/취소 화면
- 변경: 다른 시간 슬롯 선택 (멘토 자동 재매칭)
- 취소 룰 명시:
  - 48h 전 무료
  - 48h~6h: 당일 예약권 발급 안내
  - 6h 이내: 회차 차감 (= 노쇼) 경고

### 고정 슬롯 관리
- 마이페이지에서 고정 슬롯 보기·변경 (월 1회 변경 가능 가설)
- 멘토 연속성 안내 ("이전 멘토 우선 매칭")

## 3. 데이터 모델 (회원 관점)

```
Reservation
  ├─ id, member_id, session_id
  ├─ mentor_id, room_slot_id, cardio_slot_id
  ├─ type ENUM(fixed, ad-hoc)
  ├─ matching_mode ENUM(manual, auto)
  ├─ status ENUM(confirmed, rejected, cancelled, completed)
  ├─ created_at, cancelled_at
```

## 4. 매칭 거절권

- AI 자동 매칭 후 24h 내 회원이 거절 가능
- 거절 횟수 무제한 (Phase 1 가설)
- 거절 시 자동으로 다른 멘토 매칭

## 5. 우선 예약권 (고정권 회원)

- 비피크 시간 자유 예약 시 우선권 ❌ (시점 동일)
- but **자기 고정 슬롯의 이전 멘토를 이어서 받을 권리** = 보장
  - 다른 회원이 그 슬롯의 그 멘토 가로채기 ❌

## 6. 다른 레이어 영향

- **💪 멘토**: 슬롯 오픈 시 회원 매칭 → [멘토 슬롯 PRD](../mentor/2026-05-13-reservation.html)
- **🏢 플랫폼**: 매칭 알고리즘·우선권·고정 슬롯 관리 → [플랫폼 PRD](../platform/2026-05-13-reservation-system.html)

## 7. 엣지 케이스

- 매칭 시 모든 멘토 슬롯 마감: "이 시간 매칭 불가" 안내 + 대기 큐
- 고정 슬롯 멘토가 다음 주 슬롯 안 오픈: 자동으로 다른 멘토 매칭 (회원 알림)
- 자동 매칭 후 거절 → 또 거절 (반복): 수동 모드로 안내

## 8. 측정 지표

- 매칭 성공률 ≥ 95%
- 매칭 거절률 ≤ 15%
- 고정 슬롯 회원 유지율 ≥ 85%
