# 👤 세션 진행 (회원 흐름)

**Status**: Draft
**관련 결정**: [4A 세션 종류](../../service/session-types.html) · [4B 세션 포맷](../../service/session.html) · [4D 공간](../../service/space.html) · [4C AI 역할](../../service/ai-role.html)

## 1. 배경

회원 1세션 = 90분 세트 (카디오 30분 + 방 60분). 카디오존·방 둘 다 예약 단위. 멘토는 방 안에서 30분만 1:1, 나머지 30분은 자율 운동 (AI 가이드).

## 2. 회원 시나리오 (1세션)

| 단계 | 시간 | 회원 액션 | 앱·시스템 반응 |
|---|---|---|---|
| 예약 | -14일~ | 앱에서 시간·멘토 선택 (또는 자동 매칭) | 슬롯 확정 + 카디오/방 슬롯 동시 점유 |
| 도착 | T-5분 | 지점 입구에서 앱 QR 체크인 | 카디오존 자리 번호 안내 |
| 카디오 | T~T+25 | 카디오존에서 운동 (러닝/바이크 등) | AI 가이드 푸시 (강도·시간) |
| 휴식 | T+25~T+30 | 방으로 이동 | "○○방 입장하세요" 알림 |
| 방 자율 | T+30~T+60 | 방 안 자율 운동 | AI 가이드 (오늘 운동 시퀀스) |
| 멘토 1:1 | T+60~T+90 | 멘토와 코칭 | 멘토 입장 알림 → 30분 진행 |
| 종료 | T+90 | 퇴장 | 세션 요약·다음 추천 화면 |

**중요**: 시간대 staggered. 정각 시작 회원과 30분 시작 회원이 같은 방을 60분씩 번갈아 사용.

## 3. 화면 요구사항

- **세션 예약 화면**: 14일 캘린더 + 시간 슬롯 + 멘토 추천 3명 (이전 멘토 우선)
- **세션 D-Day 알림**: T-1시간 / T-15분 / T-5분 푸시
- **체크인 화면**: QR 스캔 → 카디오 자리 번호 표시
- **카디오 가이드**: 25분 카운트다운 + 강도 추천
- **방 입장 알림**: 방 번호·자리 표시 (다른 회원 불편 방지)
- **AI 가이드 (방 자율 30분)**: 오늘의 운동 시퀀스 (강사 인계 + AI 설계)
- **멘토 등장 알림**: 멘토 사진·이름·"Pro 인증" 배지
- **세션 종료**: 만족도 5점 평가 + 다음 추천 (운동·시간)

## 4. AI 가이드 콘텐츠 (방 자율 30분)

- 오늘 수행할 운동 종목·세트·중량·rep
- 직전 세션 데이터 기반 (예: "지난번 60kg 데드 → 오늘 65kg 시도")
- 운동 폼·휴식 타이밍 안내
- 멘토 도착 직전 알림

## 5. 데이터 모델 (회원 관점)

- 예약 (`Reservation`): 시간·멘토 ID·카디오 자리·방 번호
- 출석 (`Attendance`): 체크인·실제 시작·종료 시각
- 세션 평가 (`Rating`): 5점 만점 + 자유 코멘트

## 6. 다른 레이어 영향

- **💪 멘토**: 방 입장 알림 (T+60), 회원 이력 확인
- **🏢 플랫폼**: 슬롯 동시 점유 (카디오+방), AI 운동 시퀀스 생성

## 7. 엣지 케이스

- 회원 지각 (T+10분 이후 도착): 카디오 단축 시작 → 멘토 30분은 보장
- 회원이 카디오 거부 (이미 한 경우): 방 슬롯 30분 늦게 (T+30 입장)
- 멘토 노쇼: 다른 멘토 자동 매칭 또는 회차 보상 ([2D](../../members/policies.html))

## 8. 측정 지표

- 정시 체크인 비율 ≥ 90%
- 카디오 → 방 전환 누락률 < 5%
- 세션 만족도 평균 ≥ 4.3 / 5
