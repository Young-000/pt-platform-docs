# 👤 AI 시스템 PT (회원 흐름)

**Status**: Draft
**관련 결정**: [4C AI 역할](../../service/ai-role.html) · [1B 문제의식](../../product/problems.html) · [1D VP](../../product/value-prop.html)

## 1. 회원이 보는 AI

AI = "**시스템 PT** — 세션 기록 누적 + 다음 운동 자동 제안". 매일 챙기는 코치 ❌.

| 터치포인트 | 콘텐츠 |
|---|---|
| **세션 전** (예약 후) | 오늘 추천 운동 미리보기 (이번 세션에 뭐 할 건지) |
| **카디오 25분** | 강도·시간·심박 가이드 (러닝/바이크별) |
| **방 자율 30분** | 운동 시퀀스 (종목·세트·중량·rep) + 폼 안내 (영상·이미지) |
| **세션 후** | AI 자동 요약 (오늘 한 운동 + 강사 인계 핵심) |
| **다음 세션 추천** | 직전 세션 데이터 기반 (예: "지난번 60kg → 오늘 65kg") |
| **운동 이력 (마이페이지)** | Phase·진행률 가시화 (예: "근비대 Phase 2/4 · 4주차") |

## 2. AI가 하지 않는 것 (회원에게 명시)

- 매일 챙기는 코치 ❌
- 24h 챗봇 ❌
- 영양·습관 풀 케어 ❌
- 실시간 폼 자동 교정 ❌ (인간 멘토 영역)

→ 일상 코칭 광고 시 회원 오해 발생. 가입 시 onboarding에서 명시.

## 3. 화면 요구사항

### 세션 카드 (홈 화면)
- 다음 예약 정보 + AI 추천 미리보기
- "오늘 추천: 하체 데드리프트 65kg × 5세트" 같은 한 줄 요약

### AI 가이드 (세션 중)
- 카디오: 큰 카운트다운 + 강도 추천 (예: "심박 130~150 유지")
- 방 자율 30분: 운동 시퀀스 카드 슬라이드
  - 각 카드: 종목명·세트·중량·rep·휴식 시간·폼 영상
- 멘토 등장 알림 (T+30 직전)

### 세션 요약 화면 (종료 직후)
- 오늘 수행: 운동·세트·중량·총 무게
- 멘토 피드백 핵심 (3줄)
- 다음 추천 미리보기

### 운동 이력 (마이페이지)
- 그래프: 주별 운동량·각 운동 중량 진행
- Phase 진행 표시 (현재 단계 / 다음 목표)
- 강사 인계 메모 (요약본만)

## 4. 데이터 모델 (회원 노출)

```
ExerciseHistory (회원 운동 이력)
  ├─ member_id, session_id, performed_at
  ├─ exercises (jsonb): [{name, sets, weight, reps}]
  ├─ total_volume, intensity_score

AIRecommendation (다음 세션)
  ├─ id, member_id, for_session_at
  ├─ plan (jsonb): cardio + room_warmup + main_workout
  ├─ rationale (text): "지난 세션 65kg 도달 → 67.5kg 시도"

Phase (운동 단계)
  ├─ member_id, phase_name (근비대 / 다이어트 / 컨디셔닝)
  ├─ stage (1-4), week_in_stage
```

## 5. 다른 레이어 영향

- **💪 멘토**: 세션 전 회원 추천 운동 본인 화면에서도 확인 → [멘토 PRD](../mentor/2026-05-13-session-flow.html)
- **🏢 플랫폼**: AI 추천 엔진·학습 파이프라인 → [플랫폼 PRD](../platform/2026-05-13-ai-engine.html)

## 6. 엣지 케이스

- 신규 회원 (이력 없음): 본사 표준 프로그램으로 첫 N세션 진행
- AI 추천 운동을 회원이 못 따라가는 경우: 멘토가 강도 조절 → AI 학습 보정
- 운동 부상 시: AI 추천 보류 + 멘토 인계로 회복 운동 추천

## 7. 측정 지표

- 회원이 AI 추천 운동을 따라간 비율 ≥ 70%
- 운동 이력 화면 진입율 ≥ 50% (월간)
- "이 추천 도움됨" 만족도 ≥ 4.0 / 5
