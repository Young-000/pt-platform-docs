# 💪 세션 진행 (멘토 흐름)

**Status**: Draft
**관련 결정**: [3A 강사 페르소나](../../partners/personas.html) · [3E 운영 모델](../../partners/model.html) · [4B 세션 포맷](../../service/session.html) · [4C AI 역할](../../service/ai-role.html)

## 1. 배경

멘토 = 1시간에 2 회원 cover. 정각 슬롯 방 A에서 30분, 30분 슬롯 방 B에서 30분. 본인이 슬롯 자유 오픈 (배달기사형).

## 2. 멘토 시나리오 (1시간 = 2 회원)

| 시간 | 방 | 회원 | 멘토 액션 |
|---|---|---|---|
| T~T+30 | 방 A | 회원 X (방 입장 T-30 → 자율 운동) | 멘토 입장 → 30분 1:1 |
| T+30~T+35 | 이동 | | 방 B로 이동·체크 |
| T+35~T+60 | 방 B | 회원 Y (방 입장 T → 자율 운동 끝남) | 30분 1:1 |
| T+60 | | | 세션 기록 입력 (5분 내) |

→ 한 시간에 2 회원 정산 (= 시급 환산 멘토 회당 × 2).

## 3. 화면 요구사항

- **슬롯 오픈 화면**: 캘린더 + "이 시간 슬롯 오픈" 토글. 14일 단위.
- **오늘 일정**: 시간순 회원 리스트 (회원 이름·방 번호·기록 미리보기)
- **세션 진입 화면 (T-15분)**: 회원 프로필 + 운동 이력 + AI 추천 운동
  - 회원 직전 세션 기록
  - 오늘 AI 추천 (본사 프로그램 + 회원 데이터 기반)
  - 회원 컨디션 (회원이 사전 입력 시)
- **세션 진행 중 (T~T+30)**: 운동 체크리스트 (Phase별 시퀀스)
- **세션 기록 입력 (T+30 이후, 5분 내)**:
  - 수행 운동·세트·중량·rep (대부분 자동, 멘토 보정)
  - 폼 이슈 (1-2줄)
  - 다음 세션 인수인계 (3-5줄, AI에 학습됨)
  - 회원 컨디션 메모
- **정산 카운트**: 이번 달 회수·예상 정산액

## 4. 멘토에게 제공되는 것 (4C AI 정합)

- 본사 프로그램 가이드 (PT 표준 매뉴얼·운동 라이브러리)
- AI 다음 운동 제안 (회원 이력 기반)
- 5분 내 입력 가능한 UX
- 멘토는 운동을 설계할 필요 ❌ (AI가 함)

## 5. 데이터 모델 (멘토 관점)

- 슬롯 (`MentorSlot`): 시간·지점·상태 (open/booked/done)
- 세션 (`Session`): 멘토 ID·회원 ID·방·시간·상태
- 기록 (`SessionRecord`): 운동·세트·중량·rep·폼·인수인계·컨디션
- 정산 (`Payout`): 세션 ID·단가·계산일·입금 상태

## 6. 다른 레이어 영향

- **👤 유저**: 방 입장 알림 (T+60에 멘토 도착 알림), 세션 후 멘토 평가
- **🏢 플랫폼**: AI에 세션 기록 학습, 정산 자동 산출

## 7. 엣지 케이스

- 멘토 지각: T+10분 이내 → 자동 알림 → 운영 매니저 통보, 회원에게 안내
- 멘토 노쇼 (T+15분 미도착): 회원에게 회차 +1 보상 발급, 멘토 등급 패널티
- 회원 노쇼: 멘토는 정상 정산 (회원 회차만 차감)
- 동시 2 방 운영 어려운 경우 (회원 1명 지각 등): 운영 매니저 개입

## 8. 측정 지표

- 멘토 정시 입장 비율 ≥ 95%
- 세션 기록 5분 내 입력 비율 ≥ 80%
- AI 다음 운동 제안 채택 비율 ≥ 70% (정확도 가설)
