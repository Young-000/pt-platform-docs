# 💪 멘토 정산

**Status**: Draft
**관련 결정**: [3G 정산](../../partners/payout.html) · [3E 운영 모델](../../partners/model.html) · [3F 일반 멘토](../../partners/peer-leader.html)

## 1. 정산 구조

- **일반 멘토**: 회당 X원 **고정** (본사 결정, 변경 시 공지)
- **Pro 인증 멘토**: 회당 **자율 단가** (본사 min~max 한도)
- **정산 주기**: 격주 (2주마다)
- **결제 흐름**: 회원 결제 → 본사 수령 → 자동 분배 → 격주 입금

## 2. 멘토 시나리오

| 흐름 | 액션 |
|---|---|
| 세션 진행 | 회원 도착·세션·기록 → 정산 카운트 +1 |
| 정산 예상액 | 마이페이지에 실시간 표시 (이번 격주 회수 × 단가) |
| 격주 마감 | 자동 산출 → 명세서 발급 |
| 입금 | 등록된 계좌로 자동 입금 (영업일 1-2일) |
| 세무 | 본사가 사업소득 신고 자료 제공 (월 1회) |

## 3. 화면 요구사항

### 정산 대시보드
- 이번 격주 누적 세션 수·예상 정산액 (실시간)
- 직전 정산 명세서 (PDF 다운로드)
- 연간 누적 수입 그래프

### 명세서
- 세션별 회수·단가·합계
- Pro 인증 시 자율 단가 표시
- 차감 항목 (있다면 — 노쇼 패널티 등)
- 세무 정보 (사업소득 / 인적용역)

### 단가 설정 (Pro 인증만)
- 슬라이더 (min ~ max)
- 변경 시 다음 결제부터 적용 (기존 예약은 기존 단가)

### 세무 자료
- 월 1회 사업소득 명세서 다운로드
- 4대 보험·세무 안내

## 4. 정산 계산

```
이번 격주 정산 = SUM(세션 회수 × 단가) - 차감
  - 일반 멘토 = 세션 수 × 고정 단가
  - Pro 인증 = 세션 수 × 본인 설정 단가 (변경 이력 적용)
  - 차감 = 노쇼 패널티·6h 이내 취소 패널티 등
```

## 5. 데이터 모델

```
PayoutPeriod (격주)
  ├─ id, start_date, end_date

MentorPayout
  ├─ id, mentor_id, period_id
  ├─ session_count, gross_amount, deductions, net_amount
  ├─ status ENUM(calculated, paid, failed)
  ├─ paid_at, transaction_id

PayoutLineItem (세션별)
  ├─ id, payout_id, session_id
  ├─ rate_applied, amount

PayoutDeduction (차감)
  ├─ id, payout_id, type ENUM(no_show_penalty, late_cancel)
  ├─ amount, reason
```

## 7. 엣지 케이스

- 입금 실패 (계좌 변경 등): 멘토에게 알림 + 재시도
- 세션 취소 (회원 측 6h 이내): 멘토는 정상 정산
- Pro 단가 변경 후 이미 매칭된 예약: 기존 단가 유지 (DB lookup 시점 기준)
- 멘토 활동 중단 후 정산: 마지막 활동 다음 격주에 자동 처리

## 8. 측정 지표

- 정산 정확도 100% (오류 0건 목표)
- 입금 SLA: 격주 마감 후 영업일 2일 이내
- 멘토 정산 만족도 (인터뷰) ≥ 4.0 / 5
