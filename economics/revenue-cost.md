> **📌 GX 피벗 전환 (2026-06-04)**

> 매출·원가 단위가 **1:1 PT 30분 unit → GX 클래스(가격 × 출석 인원)**으로 전환됩니다.
> 본 페이지의 구체 수치는 **PT 레일 기준 추정치**이며, GX 정원·드롭인 모델로 재산출이 필요합니다.

## GX 매출 모델 (정성 제시)

GX 매출은 개별 클래스 단위로 집계됩니다.

| 항목 | GX 구조 | 비고 |
|---|---|---|
| 매출 단위 | 클래스 가격 × 출석 인원 | no-show 포함 예약 차감 |
| 클래스 가격 범위 | 1~5만원/클래스 (예시) | 베타 운영 중 결정 |
| 정원 기본값 | N명 (예시: 20명) | 클래스 유형·공간별 차이 |
| 드롭인 이용 | 비정기 단건 구매 | 예약 가동률 변동 요인 |
| 월 총 매출 | Σ (전체 클래스 매출) | PT 레일 unit 합산과 구조 상이 |

> GX 정원·클래스 가격·드롭인 비중은 베타 실측 후 확정. 수치 창작 금지.

## 원가 모델

### 강사 정산 (변동비) — GX 조합형으로 재구성

GX 정산은 1:1 PT의 "unit당 고정 단가" 구조에서 **조합형**으로 전환됩니다.

**GX 정산 구조 (정성):**

```
강사 정산 = 기본금 (고정)
           + 인당 출석 단가 × 출석 인원
           + 매출 × 비율%
플랫폼 마진 = 매출 − 강사 지급액  (정산 구조에 따라 음수 가능)
```

> 기본금·인당 단가·매출 비율의 구체 배합은 베타 운영 중 결정. 플랫폼 마진이 음수가 되지 않도록 정산 캡 설계 필요.

**PT 레일 기준 정산 (구버전 참고):**

| 등급 | 비중 (Base) | 30분 unit 정산 | 가중 |
|---|---|---|---|
| P1 신입 | 20% | 10,000 | 2,000 |
| P2 검증 | 30% | 12,000 | 3,600 |
| P3 시니어 | 25% | 14,000 | 3,500 |
| P4 전문 | 15% | 16,000 | 2,400 |
| P5 마스터 | 10% | 18,000 | 1,800 |
| **평균** | 100% | | **13,300원 ≈ 13,000원** |

*PT 레일 기준 추정치. GX 조합형 정산 확정 후 대체 예정.*

### 시간당 비용 (PT 레일 기준)

```
2,600만 ÷ (12h × 30일) = 약 72,000원/h (12h 영업 기준)
또는 360h 기준 평균 62,000원/h
```

*PT 레일 기준 추정치, GX 재산출 대상.*

## 할인·프로모션 영향 (GX 적용 방향)

- GX 드롭인 할인은 클래스 매출 감소 → **플랫폼 마진 우선 차감** (PT 레일과 동일 방향)
- 조합형 정산에서 매출 비율% 항목이 있을 경우 할인 시 자동으로 강사 정산도 연동 감소
- 정산 캡 설계에 따라 할인 부담 주체(플랫폼 vs 강사) 분배 방식 결정 필요
