## 매출 항목

| 매출원 | 비고 | 비율 (가설) |
|---|---|---|
| 멤버십 결제 (월간 자동결제) | 메인 | 75% |
| 멤버십 결제 (장기 약정 선결제) | 캐시플로 핵심 | 15% |
| 추가 PT (멤버십 외 결제) | Pro 강사 자율 단가 | 5% |

| 광고·제휴 | Phase 3 | 0% |

→ 본사·가맹점주 시각이 다름. **지점 매출 ≠ 본사 매출.**

## 원가 항목 (지점 기준)

### 고정비 (회원수 무관)

| 항목 | 월간 가설 (90평) |
|---|---|
| 임대료 | 540만 |
| 관리비·공과금 | 150만 |
| 매니저 인건비 | 250만 |
| 알바 인건비 | 200만 |
| 보험 | 30만 |
| 기구 감가·소모품 | 100만 |
| 기타 (인터넷·청소 외주 등) | 50만 |
| **소계** | **1,320만** |

### 변동비 (회원수·매출 비례)

| 항목 | 비율 |
|---|---|
| 강사 정산 | 매출의 35% |
| 본사 로열티 | 매출의 7% |
| 본사 시스템 사용료 | 정액 50만/월 또는 매출의 2% |
| 본사 마케팅 분담 | 매출의 2% |
| 결제 수수료 (PG) | 매출의 2.5% |

→ 변동비 합계 ≈ **매출의 48~50%**

### 본사 변동비 (회원당)

| 항목 | 회원당 월간 |
|---|---|
| AI API 비용 (Claude·OpenAI 등) | 5,000~10,000원 |
| 클라우드·앱 운영 | 1,000~2,000원 |
| CS 인력 (회원수 비례) | 2,000~5,000원 |

## 본사 P&L (가맹 전제, 회원당)

회원 1인 월 25만 결제 기준:

| 본사 수령 | 금액 |
|---|---|
| 로열티 7% | 17,500 |
| 마케팅 분담 2% | 5,000 |
| 시스템 정액 (배분) | 변동 |
| **소계** | **약 22,500 + 정액** |

| 본사 비용 | 금액 |
|---|---|
| AI API | 7,500 |
| 인프라 | 1,500 |
| CS | 3,000 |
| 본사 운영 (배분) | 변동 |

→ 본사 마진은 **회원 1인당 약 10,000원** (가설). 100호점 × 200명/지점 = 20,000명 회원 = 월 본사 마진 2억.
