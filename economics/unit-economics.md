## GX 전환 후 3변수 재정의

recoverGX 환경에서 단위 경제는 동일한 3축 프레임을 유지하되, 각 변수의 **의미와 산출 방식**이 바뀝니다.

### 변수 1 — 시간당 비용 & capacity (공급) — GX 재산출 대상

| 항목 | PT 레일 추정치 | GX 재산출 방향 |
|---|---|---|
| 평당 임대 | 10만/평/월 (외곽·준도심) | 공간 구조 동일, 유지 가능 |
| 면적 | 60평 승계 | 룸 → 오픈 스튜디오 재배치 검토 |
| 월 임대 | **600만** (PT 레일 추정) | GX 재산출 대상 |
| 운영비 (인건비·관리·AI·CS) | **2,000만/월** (PT 레일 추정) | GX 인건비 구조 반영 필요 |
| **월 고정비** | **2,600만** (PT 레일 추정) | **GX 재산출 대상** |
| capacity 단위 | 슬롯 = 1명 (1:1 PT) | **슬롯 = 정원 N명 (GX 클래스)** |
| 동시 capacity | 12명 (1:1 × 12슬롯) | 클래스당 정원 × 동시 진행 클래스 수 |

> **GX capacity 전환 핵심**: 1:1 PT에서 "슬롯 = 1명"이던 것이 GX에서는 "슬롯 = 정원 N명"으로 바뀝니다.
> 동일 공간에서 수용 가능한 총 이용 인원이 급증하며, 이것이 GX 단위 경제의 핵심 레버입니다.

### 변수 2 — U (utilization) — GX 재정의 필요

```
GX U = 실 출석 인원-시간 / (정원 × 클래스 슬롯 수)
```

- PT 레일 U: 슬롯 가동 비율 (1:1 단위)
- GX U: 클래스 정원 충족률 × 클래스 슬롯 가동률의 복합 지표
- 드롭인(비정기 이용) 비중이 높을수록 U 예측 분산 ↑ → 베타 실측 필요

### 변수 3 — 클래스당 마진 (가격 − 정산) — GX 재산출 대상

| 항목 | PT 레일 추정치 | GX 재산출 방향 |
|---|---|---|
| 매출 단위 | unit당 회당가 30,000원 | **클래스 가격 × 출석 인원** |
| 강사 정산 구조 | unit당 13,000원 (P1~P5 등급 고정) | **조합형**: 기본금 + 인당 × 출석 + 매출 × 비율% |
| 플랫폼 마진 | unit 마진 17,000원 | 매출 − 강사 지급액 (음수 가능, 정산 구조 따라) |

## GX 매출 공식 (정성 제시)

```
클래스 매출 = 클래스 가격 × 출석 인원 (no-show 포함 예약 차감)
월 매출     = Σ (전체 클래스 매출)

강사 정산   = 기본금 + (인당 출석 단가 × 출석) + (매출 × 비율%)
플랫폼 마진 = 월 매출 − Σ 강사 정산액
월 순익     = 플랫폼 마진 − 고정비
```

> 클래스 가격 범위·정원 기본값·정산 비율은 베타 운영 중 결정. 예시 범위: 클래스당 1~5만원, 정원 기본 20명.
