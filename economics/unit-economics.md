## 단위 경제 가설 (90평 8룸 표준)

### 매출 가정

```
포화 회원 수 ≈ 8룸 × 12시간 × 30일 × 70%(평균 utilization) ÷ 8회/회원
            ≈ 200~250명
```

| 시나리오 | 회원수 | ARPU | 월매출 |
|---|---|---|---|
| 1차 BEP | 100명 | 25만 | 2,500만 |
| 2차 BEP | 150명 | 25만 | 3,750만 |
| 포화 | 220명 | 25만 | 5,500만 |

### 원가 가정 (월)

| 항목 | 추정 | 비고 |
|---|---|---|
| 임대료 | 540만 | 90평 × 6만 |
| 관리비·공과금 | 150만 | |
| 매니저 인건비 | 250만 | 1인 |
| 알바 인건비 | 200만 | 2인 시프트 |
| 강사 정산 (회원당 평균) | 매출의 35% | 회원수 비례 |
| 본사 시스템·로열티 | 매출의 9% | [5C](../expansion/revenue-share.html) |
| 본사 마케팅 분담 | 매출의 2% | |
| 보험 | 30만 | |
| 기구 감가·소모품 | 100만 | |
| 기타 | 50만 | |

### 손익 시뮬레이션 (회원 100명 기준)

```
매출         2,500만
강사 정산    -875만 (35%)
본사 로열티  -225만 (9%)
본사 마케팅  -50만 (2%)
임대료       -540만
관리비       -150만
인건비       -450만
보험·기타    -180만
─────────────────────
가맹점주 순익 +30만 (BEP 근처)
```

→ **회원 100명 = BEP. 150명에서 본격 흑자, 220명 포화 시 월 800만+**.
