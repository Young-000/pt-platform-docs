## CapEx (지점당)

| 항목 | 가설 |
|---|---|
| 보증금 (90평 × 6만 × 12개월 + α) | 7,000만 |
| 인테리어·시공 (평당 250만) | 22,500만 |

---

## 단계별 추정

### Phase 1 — 1~3호점 (직영 검증)

| 항목 | 가설 |
|---|---|
| 직영 3호점 CapEx | 12억 |
| 운영 12개월 누적 적자 (BEP 전) | 5~8억 |
| **자본 소요** | **17~20억** |

→ 자기 자본 + 시드 투자 필요.

### Phase 2 — 4~10호점 (가맹 시작)

| 항목 | 가설 |
|---|---|
| 직영 추가 1-2호점 | 5억 |
| 가맹 5-7호점 (가맹점주 자본) | 본사 부담 0 |
| 본사 운영 적자 (12-18개월) | 3~5억 |
| **자본 소요** | **8~10억** |

→ Series A 시드 또는 가맹비 회수.

### Phase 3 — 10~50호점 (가맹 본격)

| 항목 | 가설 |
|---|---|
| 가맹 40호점 추가 (본사 자본 ≈ 0) | - |
| 본사 시스템·인프라 확장 | 5~10억 |
| **본사 누적 마진** | + (가맹비·로열티) |

→ 이 시점부터 본사 자체 캐시플로로 운영 가능.

### Phase 4 — 50~100호점

| 항목 | 가설 |
|---|---|
| 가맹 50호점 추가 | - |
| 본사 마진 | 월 5억+ (회원 20,000명 × 2.5만 본사 마진) |
| **본사 누적 이익** | 연 60억+ |

---

## 본사 BEP

| 단계 | 본사 누적 이익 |
|---|---|
| 1~10호점 | 누적 적자 |
| 10~30호점 | BEP 도달 (회원 6,000명 가정) |
| 30~100호점 | 본격 흑자 |

→ **본사 BEP ≈ 30호점 시점.**
