# Level 8B — 강사 자격증 법규 (Pro 인증 멘토 vs 일반 멘토)

| **하위 영향** | 멘토 모델 가능 여부 · 사업 자체의 법적 안전성 |

> recoverGX 피벗 후에도 GX 강사(그룹 인스트럭터)를 포함한 모든 강사에 대해 동일한 자격 검증 정책 적용. 서비스 전환 맥락: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html).

> **🔥 2026-05-15 회의 — 자격증 정책 합의** ([ADR 0002](../decisions/0002-license-policy.html))
>
> **법적 사실관계** (확정):
> - **개별 PT 강사 자격증 의무 조항은 한국 법에 ❌** (PT 강사 면허 제도 자체가 없음)
> - **국민체육진흥법 §12**: "체육지도자" 칭호 사용에만 자격증 필요 → "**멘토**" 호칭으로 회피
> - **체육시설법 §26**: 신고/등록 체육시설에 자격증 보유 체육지도자 1명 배치 (**시설 단위 의무**, 강사 단위 ❌) → **가맹점장이 자격증 보유**로 충족
> - **의료법 §27**: 운동처방·재활 표방 금지 → "**운동 설계 = AI**" 구조로 회피
>
> **"무자격 트레이너 퇴출 법안"**: 2020·2021·2023 발의됐으나 **국회 통과·시행 사례 없음** (2025년 초 기준). 변호사가 2025~2026 진척 확인 필요.
>
> **우리 정책**:
> - 일반 멘토 자격증 ❌, Pro 인증 멘토 자격증 ✅ (생활스포츠지도사 2급 또는 동등)
> - 가맹점장 = 자격증 보유 슈퍼바이저 (시설법용)
> - 법안 통과 시 admin 정책 변수(`mentor.require_license_general`)로 즉시 토글
>
> ⚠️ 본 분석은 일반적 해석. 사업 개시 전 변호사 자문 필수 — 특히 (1) "private PT shop" 체육시설업 분류, (2) 자격증 법안 진척 상황.

---

## 결정해야 할 것

> **자격증 없는 일반 멘토 모델이 한국 체육·의료 법규에 저촉되지 않는가?** 어떻게 포지셔닝해야 안전한가?
> GX 클래스(그룹 인스트럭터) 형태에서도 동일 질문이 적용됨.

이 결정이 **사업 자체의 법적 토대**.

---

## 1. 관련 법규 (한국) — 사실관계

### 1.1 국민체육진흥법 §12 (체육지도자)
- "**체육지도자**" 칭호 사용 시 자격증 (생활스포츠지도사 등) 보유 필수.
- **개별 강사 단위 의무 ❌** — 칭호·간판 통제 중심.
- → **회피 전략**: "체육지도자"·"트레이너"·"PT"·"코치" 명칭 ❌. 본 서비스는 "**멘토**" 호칭만 사용.

### 1.2 체육시설법 §26 (시설 단위 자격증)
- 신고·등록 체육시설업장에 **자격증 보유 체육지도자 1명 이상 배치**.
- **시설 단위 의무** — 모든 강사가 자격증을 가질 필요는 없음. 1명만 충족.
- → **회피 전략**: **가맹점장 = 자격증 보유 슈퍼바이저**. 가맹점장이 시설법상 배치 의무를 단독 충족.

### 1.3 의료법 §27 (의료 행위)
- "운동처방"·"재활 치료" 표방은 의료 행위 → 의료기관·물리치료사 영역.
- → **회피 전략**: 운동 설계 주체 = **AI**. 멘토는 동행·실행 보조. 약관·UI 전반에 "운동처방 ❌, AI 가이드 ✅" 명시.

### 1.4 무자격 트레이너 퇴출 법안 (계류 중)
- 2020·2021·2023 국회 발의 — **시행 사례 없음** (2025 초 기준).
- 통과 시 일반 멘토 모델 직접 위협 → 즉시 admin 토글로 정책 전환.

---

## 2. 우리 모델의 법적 포지셔닝 (v2 — 2025-05-15 합의)

### 2.1 Pro 인증 멘토 (자격증 보유 — ✅ 안전)
- 생활스포츠지도사 2급 또는 동등 자격 보유자 한정.
- 본사 강사 풀 입회 시 자격증 인증 필수 — DB `mentor.license_verified=true`.
- "Pro 인증 멘토" 배지 표기 — 회원 UI 노출.
- 운동 설계도 가능 (의료 행위 영역만 회피).

### 2.2 일반 멘토 (자격증 ❌ — 회색지대, 회피 전략 다중 적용)
- "**멘토**" 호칭만. "트레이너"·"PT"·"코치"·"체육지도자" 사용 ❌.
- **운동 설계 = AI** (회원 데이터 기반 자동 처방). 멘토는 AI 가이드 실행 동행·자세 교정·안전 체크.
- 무자격자가 "지도(coaching)" 행위로 보이지 않도록 R&R 정의 — DB `mentor.role='general'` 시 운동 설계 권한 ❌.

### 2.3 가맹점장 (시설법용 자격증 보유 슈퍼바이저)
- 모든 가맹점에 1명 배치 — **체육시설법 §26 시설 단위 의무 충족**.
- 본사 직고용 권장 (Phase 1). Phase 2+ 정책 재검토.
- 자격증: 생활스포츠지도사 2급 또는 동등.

### 2.4 다중 방어 매커니즘 (법안 통과 대비)
1. **명칭 통제** — "멘토" 단일 호칭. "지도자·트레이너·PT" 절대 ❌.
2. **운동 설계 주체** — AI (회원 운동 로그 기반). 모든 세션 기록에 `program_source='AI'` 필수.
3. **R&R 분리** — 일반 멘토: 동행·동기·안전. Pro 멘토: + 운동 설계. 가맹점장: 시설 책임·자격증 보유.
4. **회원 면책 동의** — "AI 설계 운동 + 멘토 동행" 명시 약관.
5. **본사 보험** — 시설·배상 본사 일괄.
6. **Admin 토글** (`mentor.require_license_general`) — 법안 통과 즉시 일반 멘토 → Pro 의무화 정책 전환 가능.

## 3. 잠재 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 일반 멘토가 "무자격 PT" 신고당함 | (1) 운동 설계 = AI 로그 입증 (2) 멘토 명칭 사용 통제 |
| 사고 시 자격증 없는 멘토 책임 | AI 가이드 추적 + 본사 배상보험 + 면책동의 |
| 회원이 "PT 받았다" 주장 | 멘토 명칭·약관·세션 UI 일관성 |
| 시설법 §26 위반 신고 | 가맹점장 자격증 비치·게시 (시설 단위 충족) |
| 의료법 §27 위반 신고 | 운동처방·재활 표현 전면 금지 (마케팅·UI 일제 검수) |
| 무자격 법안 통과 | `mentor.require_license_general=true` 토글 — 신규 일반 멘토 채용 중단·기존 멘토 Pro 승격 유도 |
| 경쟁사 신고·민원 | 사전 변호사 의견서 + 공정위 협의 |

## 4. 변호사 검토 체크리스트

- [ ] 일반 멘토 모델이 체육시설법·국민체육진흥법 저촉 여부 (2025~2026 판례 포함)
- [ ] "멘토" 명칭의 법적 안전성 (체육지도자 칭호 회피 효과)
- [ ] AI 가이드 운동 설계의 법적 책임 소재 (제조물 책임·서비스 제공자 책임)
- [ ] 사고 시 일반 멘토의 형사 책임 한계
- [ ] 회원 면책 동의서의 효력 범위
- [ ] 무자격 트레이너 퇴출 법안 (2025~2026 진척 상황)
- [ ] "private PT shop" 형태가 체육시설법 신고·등록 대상인지 분류
