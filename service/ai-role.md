# 4C. AI 역할 — GX 레일에서 보류

**⏸️ 보류 (2026-06-04)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [ADR 0009](../decisions/0009-workout-record-as-asset.html) → [4A 클래스 종류](./session-types.html), [4B 클래스 포맷](./session.html)

> **이 페이지가 설명하는 AI 기능은 1:1 PT 레일의 자산이다. recoverGX(GX 그룹 클래스) 레일에서는 보류 상태이며, 현재 제품에서 활성화되어 있지 않다.**

{: .warning }
> **"AI가 브랜드의 스타"라는 마케팅 금지.** recoverGX는 접근성·큐레이션·입소문으로 승부한다. 체감 제품은 그룹 운동이다. ([ADR 0011 §6](../decisions/0011-recovergx-gx-pivot.html))

## 왜 GX에서 AI 자리가 약한가

GX(그룹 클래스·드롭인)는 본질적으로 **저개인화·저데이터** 레일이다.

- 회원이 매번 다른 클래스를 드롭인 → 개인별 누적 데이터 축적이 느림.
- 그룹 포맷에서 AI 개인화 제안이 체감될 접점이 적음.
- 콜드스타트 단계에서 AI 모트(moat)를 마케팅해도 회원이 체감하기 어려움.

→ AI 개인화의 가치는 **1:1 PT 레일(누적 세션 기록·다음 운동 설계)**에서 발현된다. GX 레일에서 AI를 앞세우는 것은 실체 없는 포지셔닝이 된다.

## 보류된 자산 목록 (1:1 PT 레일)

아래 기능은 [ADR 0009](../decisions/0009-workout-record-as-asset.html) 및 구 [ADR 0002](../decisions/0002-license-policy.html) 기반 설계이며, 코드·데이터는 보존되어 있으나 현재 라우트 미노출 상태다.

| 기능 | 설명 | 상태 |
|---|---|---|
| 세션 기록 보관 | 운동·세트·중량·메모 누적 | 보류 |
| 다음 운동 제안 | 이전 기록 기반 AI 추천 | 보류 |
| 강사 인수인계 | 이력 그대로 신규 강사에 전달 | 보류 |
| 본사 프로그램 가이드 | 운동 라이브러리 + AI 가이드 | 보류 |
| 세션 후 자동 요약 | 완료 시 AI 생성 요약 | 보류 |
| 데이터 플라이휠 | 강사 기록 → 유저 이력 → AI 개인화 | 보류 |

## 부활 조건

1:1 PT 레일은 **폐기가 아니라 보류**다. 아래 조건이 갖춰지면 AI moat 레일로 재가동 가능.

- recoverGX에서 PMF 확보 (회원 기반·재방문율·입소문 검증)
- 1:1 PT 수요 확인 (회원 또는 강사 요청 신호)
- 어드민에서 1:1 PT 카테고리 활성화 + 라우트 노출

## GX 레일에서 현재 제공하는 것

AI 기반 개인화는 없으나, 다음은 현재 작동 중이다.

- 강사가 수동으로 출석 체크 (`attended` / `no_show`)
- 클래스 완료 후 정산 계산 (정책 스냅샷)
- 어드민의 카테고리·가격 룰 관리
