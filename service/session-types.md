> - 카테고리는 어드민이 관리(`CourseCategory` 승계). 검증된 강사가 카테고리 지정해 클래스 개설.
> - 회원은 **드롭인** — 시간표에서 잔여석 확인 후 즉시 예약. 약정·티어·회원 가입 강제 없음.

## GX 클래스 카테고리 (어드민 큐레이션)

> **"어드민이 정의한 룰 안에서 검증된 강사가 그룹 클래스를 개설한다."**

- 카테고리는 **admin에서 추가·수정·삭제** 가능 (가변). `CourseCategory` 모델 승계.
- 강사는 클래스 개설 시 카테고리를 지정. 어드민이 사전 설정한 **가격 상한/하한** 범위 안에서 가격 결정.
- 개설 권한(`gxOpenEnabled`)은 어드민이 강사별로 부여. 검증되지 않은 강사는 개설 불가.

### 카테고리 예시 (admin 조정 가능)

| 카테고리 | 룸 | 비고 |
|---|---|---|
| 스트레칭 | 룸 사용 | 정원 소규모 가능. 가격 예: 15k |
| 필라테스 | 룸 사용 | 정원 소규모 가능 |
| 컨디셔닝 | 룸 또는 오픈 | 가격 예: 25k |
| 버닝 (HIIT 계열) | 오픈 | 정원 많음. 가격 예: 30k |
| 기타 | admin 지정 | admin이 추가·조정 |

> 위 카테고리는 예시이며 고정값이 아님. 어드민이 서비스 맥락에 맞게 운영.

## 강사 개설 조건

| 조건 | 내용 |
|---|---|
| 강사 검증 | 어드민이 `gxOpenEnabled` 권한 부여 |
| 카테고리 지정 | 클래스 개설 시 admin 정의 카테고리 중 선택 |
| 가격 | 어드민 상한/하한 범위 내에서 강사 지정 |
| 정원 | 강사 지정 (기본 20명) |
| 시간 | 강사 지정 (룸당 시간당 1 클래스 배타) |

## 드롭인 예약 모델

- 약정·티어 멤버십 없음. 회원은 지갑(충전금)에서 클래스별 가격만큼 차감.
- 진입 장벽: 충전 → 시간표 탐색 → 예약. 즉시 시작 가능.
- 취소: 시작 `refundCutoffHours`(기본 6h) 전 전액 환불(지갑 크레딧). 이후 0.
