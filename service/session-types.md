# 4A. 세션 종류 (30분 unit · Pro Only)

**🟢 v2 봉인 (2026-05-20)** · 의존: [ADR 0001](../decisions/0001-consumer-pivot.html), [ADR 0002](../decisions/0002-license-policy.html), [1D VP](../product/value-prop.html), [4C AI](./ai-role.html) → [3E 강사 모델](../partners/model.html), [3F 강사 등급](../partners/peer-leader.html), [3H 등급](../partners/quality.html), [8B 자격증법](../legal/pt-license.html)

> **📌 v2 봉인 (2026-05-20)**
>
> - **30분 = 1 unit** 기본. 60분 = 2 unit 연속 예약.
> - 모든 강사 = **Pro** (자격증 + 본사 아카데미). 등급 P1~P5 비공개.
> - **진입장벽 없는 모델**: 지나가다 "1회 30분 스트레칭" 단발 예약 가능 (체험·단발 회차권 35,000원). 회원 가입·약정 ❌.
> - 회원은 매 세션마다 강사·종목·시간(30·60분) 자유 선택.

## 다종목 코스 (가변 카테고리)

> **"AI 가이드 기반 다종목 Pro 강사 세션"** — 회원이 매 세션마다 강사·프로그램·시간 자율 선택.

- 운동 설계 = AI (회원 데이터 + 본사 프로그램)
- 강사 = **Pro 인증 강사** — 1:1 멘토링·동행 (자격증법 회피 위해 "지도" 표현 ❌)
- 호칭 = "코치·멘토" (PT·트레이너 ❌ — [ADR 0002](../decisions/0002-license-policy.html))

### 코스 카테고리 (예시, admin 추가 가능)

| 카테고리 | 룸 | 강사 | 비고 |
|---|---|---|---|
| 스트레칭·필라테스·요가 (룸 필요) | private room | Pro | 8개 룸 점유. 30분 unit |
| 1:1 PT | 오픈 공간 | Pro | 오픈 공간 + Pro 강사. 30분 또는 60분 |
| 자유 헬스 | 오픈 공간 | ❌ | 강사 코스 회원에게만 부가 ([ADR 0003](../decisions/0003-free-gym-add-on.html)) |

> 카테고리는 가변. admin에서 추가·조정 가능. Pro 강사 한 명이 멀티 종목 가능 (자격증 + 아카데미 통과 시).

## 시간 단위 (30분 unit)

| 세션 길이 | unit 차감 | 비고 |
|---|---|---|
| 30분 | 1 unit | 기본. 스트레칭·짧은 PT |
| 60분 | 2 unit | 깊은 PT·필라테스 등. 연속 슬롯 자동 매칭 |
| 90분 | 3 unit | 옵션 (admin 활성 시) |

## 진입장벽 없는 모델

- **1회권 35,000원 (30분)** = 회원 가입 후 즉시 예약 가능. 약정 ❌.
- 지나가다 "오늘 저녁 7시 30분 스트레칭" 단발 예약 가능 — Super Monkey식 진입장벽 ❌
- 동전노래방 + 헬스 + 멘토링 결합 컨셉

## 강사 풀 — Pro Only

| 등급 | 자격 | 회원 노출 |
|---|---|---|
| **Pro (P1~P5)** | 자격증 + 본사 아카데미 | "Pro 인증" 배지 (등급 비공개) |

- 회원이 강사 선택 시 등급 비공개. 평점·후기·전문 분야만 노출.
- 가격은 등급과 무관 (회원 입장 단일 회당가 = 정상 35,000원 / 평균 30,000원).
- "일반 멘토" 등급 폐기. 본사가 등급 P1~P5 정산만 흡수.

## 자격증법 회피 매커니즘

- 운동 설계 = AI
- 강사 = "멘토링·동행"
- 명칭 = "개인 맞춤 세션" / "운동 코치"
- 자격증 보유자만 모집 → 자격증법 부담 자동 회피
- → [8B 변호사 검토](../legal/pt-license.html) 필수
