## 한 가지 세션

> **"AI 가이드 기반 1:1 개인 맞춤 세션"**

- 운동 설계 = AI (회원 데이터 + 본사 프로그램)
- 강사 = "운동 멘토" — 1:1 멘토링·동행 (지도 ❌)
- "PT" 단어 사용 ❌

## 강사 풀 — 등급 2단계

| 등급 | 자격 | 회원 노출 |
|---|---|---|
| **일반 멘토** | 본사 검증 코스 통과 | 기본 |
| **Pro 인증 멘토** | 자격증 보유 + **본사 심사 통과** | "Pro 인증" 배지 |

- 회원이 예약 시 등급 노출
- Pro 인증 멘토 = 단가 ↑ 가능 (Premium 티어)
- **본사 심사가 브랜드 신뢰 자산**
