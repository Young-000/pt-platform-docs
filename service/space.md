# 4D. 공간 구조 (60평 표준)

**🟢 v2 봉인 (2026-05-20)** · 의존: [4B 세션 포맷](./session.html) → [5A 예약](../operations/reservation.html), [7A 단위 경제](../economics/unit-economics.html)

> **📌 v2 봉인 (2026-05-20)**
>
> **표준 1지점 = 60평** (룸 8 + 오픈 22평).
>
> - 평당 임대 **10만** (외곽·준도심) → 월 임대 **600만**
> - 운영비 (인건비·관리비·AI·CS) **2,000만/월**
> - 동시 capacity **12명** = 시간당 **24 unit** (30분 unit 기준)
> - Capex **1.5~2억**

## 표준 1지점 — 60평 구성

| 구역 | 평수 | 수 | 비고 |
|---|---|---|---|
| **Private 룸** | 약 38평 | **8개** × 약 4~5평 | 룸 필요 코스(스트레칭·필라테스 등) — 30분 unit 슬롯 |
| **오픈 공간** | **22평** | — | 1:1 PT + 자유 헬스 ([ADR 0003](../decisions/0003-free-gym-add-on.html)) |
| **총** | **60평** | | 공용/탈의/샤워는 오픈 공간 내 통합 또는 별도 |

## 동시 capacity & unit 처리량

| 항목 | 값 | 산출 |
|---|---|---|
| 룸 동시 사용 | 8명 | 룸 8 × 1명 |
| 오픈 공간 1:1 PT | ~4명 | 오픈 22평 ÷ 1:1 (5~6평) |
| **총 동시 capacity** | **12명** | 룸 8 + 오픈 4 |
| 시간당 unit (30분 unit 2배) | **24 unit** | 12명 × 2 unit/시간 |

## 슬롯 매칭

- 룸 8 = 30분 unit 기준 시간당 최대 **16 unit** (회원이 60분 선택 시 8 세션)
- 오픈 공간 1:1 PT = 시간당 약 8 unit (4명 × 2 unit)
- 자유 헬스는 강사 코스 회원에게만 부가 ([ADR 0003](../decisions/0003-free-gym-add-on.html))
- **시간당 총 24 unit** = 단위 경제 변수 1 (capacity) ([7A](../economics/unit-economics.html))

## 비용·BEP 요약

| 항목 | 값 |
|---|---|
| 월 임대 (평당 10만 × 60평) | 600만 |
| 월 운영비 (인건비·AI·CS·관리) | 2,000만 |
| **월 고정비** | **2,600만** |
| 일 영업 시간 (가정) | 12h (10시~22시) |
| 월 영업 unit capacity | 24 unit × 12h × 30일 = **8,640 unit** |
| **시간당 비용** | 약 **62,000원** (12h × 30일 = 360h 기준) |
| Capex | 1.5~2억 |

## Phase별 변형

- **Phase 0 (베타 1호점)** — 60평 외곽·준도심 (평당 10만·capex 1.5~2억)
- **Phase 1 (1~3호점)** — 표준 60평 직영 검증. 베타 KPI 4/5 통과 후 강남 2호점 추가 가능
- **Phase 2+** — 입지 따라 변형 가능 (소형·대형). admin 정책 변수
- **클러스터 전략** — 도심·준도심 3호점 밀집 배치 ([6A 확장 모델](../expansion/model.html))
