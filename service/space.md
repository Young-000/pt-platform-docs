# 4D. 공간 구조 (60평 표준)

**🟡 Updated (2026-06-04)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [4B 클래스 포맷](./session.html) → [5A 예약](../operations/reservation.html), [7A 단위 경제](../economics/unit-economics.html)

> **📌 GX 피벗 (2026-06-04)**
>
> 60평·룸 구조는 승계. 단, 룸 점유 의미 전환: 1:1 private room 1슬롯 1회원 → **그룹 클래스 정원 수용 공간**. 룸당 시간당 1 클래스 배타.

## 표준 1지점 — 60평 구성

| 구역 | 평수 | 수 | GX 역할 |
|---|---|---|---|
| **클래스 룸** | 약 38평 | **8개** × 약 4~5평 | 룸 필요 카테고리(스트레칭·필라테스 등) 그룹 클래스 수용. 룸당 시간당 1 클래스 배타 |
| **오픈 공간** | **22평** | — | 대규모 정원 클래스(버닝·컨디셔닝 등) 또는 강사 없는 자유 영역 |
| **총** | **60평** | | 공용/탈의/샤워는 오픈 공간 내 통합 또는 별도 |

> 룸 크기(4~5평)는 그룹 수업 특성에 따라 소규모 정원(예: 스트레칭 6명)에 맞게 운영. 대형 정원 클래스는 오픈 공간 활용.

## 동시 capacity

| 항목 | 값 | 산출 |
|---|---|---|
| 룸 동시 클래스 | 최대 8 클래스 | 룸 8 × 1 클래스 |
| 룸 수용 인원 | 룸당 카테고리·정원에 따라 상이 | 소규모: ~6명 / 중간: ~10명 |
| 오픈 공간 클래스 | 1 클래스 | 오픈 22평, 대형 정원 가능 |
| **총 동시 capacity** | **룸 8 클래스 + 오픈 1 클래스** | 정원 합계는 클래스 구성에 따라 유동 |

> GX 전환으로 capacity 단위가 "unit 수" → "클래스 수 × 정원"으로 변경됨. 단위 경제 재산출: [7A](../economics/unit-economics.html).

## 슬롯 배타 원칙

- **룸당 시간당 1 클래스** — 같은 룸에 동시간대 2개 클래스 개설 불가.
- 강사가 클래스 개설 시 룸을 지정하면, 해당 시간대 해당 룸은 잠김.
- 예약 시스템이 잔여석·충돌을 실시간 관리 → [5A 예약 시스템](../operations/reservation.html).

## 비용·BEP 요약

| 항목 | 값 |
|---|---|
| 월 임대 (평당 10만 × 60평) | 600만 |
| 월 운영비 (인건비·관리비·CS) | 2,000만 |
| **월 고정비** | **2,600만** |
| 일 영업 시간 (가정) | 12h (10시~22시) |
| Capex | 1.5~2억 |

> 시간당 단위 경제(매출·마진)는 GX 클래스별 가격·정원·출석률 변수로 재산출 필요. → [7A 단위 경제](../economics/unit-economics.html).

## Phase별 변형

- **Phase 0 (베타 1호점)** — 60평 외곽·준도심 (평당 10만·capex 1.5~2억)
- **Phase 1 (1~3호점)** — 표준 60평 직영 검증. 베타 KPI 통과 후 강남 2호점 추가 가능
- **Phase 2+** — 입지 따라 변형 가능 (소형·대형). admin 정책 변수
- **클러스터 전략** — 도심·준도심 3호점 밀집 배치 ([6A 확장 모델](../expansion/model.html))
