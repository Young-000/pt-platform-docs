# 4B. 세션 포맷

**🟢 Decided** · 의존: [4A 세션 종류](./session-types.html), [4D 공간](./space.html) → [5A 예약 시스템](../operations/reservation.html), [7A 단위 경제](../economics/unit-economics.html)

## 회원 예약 단위 = 연속 세트 (90분)

```
[카디오 30분 슬롯]  →  [방 60분 슬롯]
─────────────────────────────────────
     공용 공간            private room
   자리 단위 예약         방 단위 예약
   25분 + 5분 휴식        50분 멘토 + 10분 전환
```

## 운영 단위

| 단위 | 시간 | 비고 |
|---|---|---|
| 카디오 슬롯 | 30분 | 자리 1개 = 1 슬롯 |
| 방 슬롯 | 60분 | 방 1개 = 1 슬롯 |
| 회원 1세션 | 90분 (연속) | 카디오 + 방 묶음 |

## 핵심 원칙

- **모든 공간 예약제** — 카디오존도 자리 예약. 워크인 ❌
- 좌석·방 수 통제 → **북적임 차단** (1B 페인 #2 해소)
- 카디오/방 utilization 별도 트래킹
- 옵션 변형 없음 (모든 회원 동일 90분 세트). Phase 2 검토.
