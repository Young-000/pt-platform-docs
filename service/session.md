# 4B. 세션 포맷

**🟡 Updated (2026-05-16)** · 의존: [ADR 0001](../decisions/0001-consumer-pivot.html), [4A 세션 종류](./session-types.html), [4D 공간](./space.html) → [5A 예약 시스템](../operations/reservation.html), [7A 단위 경제](../economics/unit-economics.html)

## 회원 예약 단위 = 30분 unit

```
[30분 unit]   또는   [30분 unit + 30분 unit] (60분 연속)
────────────────────────────────────────────
강사 + 프로그램 선택 → 룸은 프로그램 속성에 따라 자동 배정
  · 룸 필요 코스 (스트레칭·필라테스 등) → 8 private room 중 1개
  · 1:1 PT → 오픈 공간
  · 자유 헬스 → 오픈 공간 (강사 ❌, 부가 가치)
```

## 운영 단위

| 단위 | 시간 | 비고 |
|---|---|---|
| 30분 unit | 30분 | 최소 예약 단위 |
| 60분 연속 | 30분 × 2 | 회원이 선택 시 |
| 회원 1세션 | 30~60분 | 강도·시간 자유 조절 |

## 핵심 원칙

- **예약 대상 = 강사 + 프로그램** (룸 ❌). 룸은 자동 배정.
- **30분 unit** — 회원이 원하면 60분(2 unit) 연속 예약.
- 강사 시간 단위 = 30분. 정산도 30분 단위 ([3G 정산](../partners/payout.html)).
- 코스 카테고리는 admin이 추가·조정 가능 (가변).
