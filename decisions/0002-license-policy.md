# 0002. 멘토 자격증 정책 (자격증법 회피 + 단계적 의무화 대비)

- **상태**: Accepted
- **결정일**: 2026-05-15 (회의), 2026-05-16 (ADR 작성)
- **결정자**: Young

## 맥락 (Context)

PT 강사 자격증을 둘러싼 사실관계가 시장에 혼란스럽게 퍼져 있다:

- 자격증 학원·취업 블로그: "PT 지도하려면 자격증 필수" 마케팅성 진술 다수
- 실제 법: **개별 PT 강사가 자격증 보유 의무인 조항은 한국 법에 없음**
- 발의됐던 "무자격 트레이너 퇴출 법안" (2020·2021·2023): 국회 통과·시행 사례 없음 (제 지식 기준 2025년 초)
- 대형 체인 헬스장: 채용 정책으로 자격증 요구 = 회사 정책, 법 의무 ❌

우리 모델 (소비자향 + 파트타이머 풀 + 다종목)에서 자격증 강제는 공급 풀을 좁히고 핵심 차별성을 잃게 만든다.

## 결정 (Decision)

### 1. 일반 멘토 — **자격증 ❌**
- 본사 자체 검증 코스 통과만 필수
- 자격증 있으면 우대 (UI에 뱃지)

### 2. Pro 인증 멘토 — **자격증 ✅ + 본사 심사**
- 생활스포츠지도사 2급 (또는 NSCA-CPT / NASM / KESPA 등 동등 자격) 1개 이상
- 본사 심사 (영상·면담·필기)
- 추가 통계 임계 (세션 ≥100, 평점 ≥4.3, 재예약률 ≥60%)

### 3. 가맹점 슈퍼바이저 — **자격증 필수 (시설법용)**
- 체육시설법 §26: 신고/등록 체육시설은 자격증 보유 체육지도자 1명 이상 배치
- 가맹점장 or 본사 직고용 슈퍼바이저가 자격증 보유자 → 시설 단위 의무 충족

### 4. 호칭·표방 안전판
- 외부 명칭: **"멘토"** (PT·트레이너·코치 단어 ❌) — 국민체육진흥법 §12 "체육지도자" 칭호 회피
- 운동 설계 = **AI** (멘토가 처방 ❌) — 자격증법·의료법 회피

### 5. 법안 변화 대응 — **admin 정책 변수**
"일반 멘토 자격증 의무" 토글을 admin 정책 변수에 미리 노출. 무자격 트레이너 퇴출 법안이 통과되면 admin에서 토글 → 즉시 정책 변경.

| 정책 변수 키 | 기본값 | 의미 |
|---|---|---|
| `mentor.require_license_general` | `false` | 일반 멘토 자격증 의무화 토글 |
| `mentor.required_license_types` | `[]` | 인정 자격증 종류 리스트 |
| `mentor.license_grace_period_days` | `0` | 기존 무자격 멘토 유예 기간 |

## 검토한 대안 (Alternatives)

### 대안 A: 처음부터 모든 멘토 자격증 의무
- 장점: 시장 트렌드 부합 (대형 체인 정책), 회원 신뢰
- 단점: 파트타이머 풀 차단 → 공급 ↓ → 베타 실행 불가능
- 기각

### 대안 B (채택): 단계적 — 일반 X / Pro O + 법안 대응 admin 토글
- 베타 공급 확보 + 시장 시그널 확보 (Pro)
- 법 변화 시 즉시 대응 가능

### 대안 C: 모든 멘토 자격증 OR 동등 경력
- 장점: 경력자 영입 가능
- 단점: 경력 검증 부담 + 파트타이머 풀 여전히 좁음
- 보류 (필요 시 추가 정책으로 추가)

## 결과 (Consequences)

### 긍정적
- 파트타이머 풀 확보 → 베타 공급 가능
- Pro 인증의 가치·차별화 명확
- 법 변화 시 코드 수정 없이 admin 토글로 대응

### 부정적
- 회원 일부가 "자격증 없는 강사" 인식으로 신뢰 ↓ 가능 → UI에 검증 코스·평점·재예약률 노출로 보완
- 가맹점장 자격증 의무 → 본사 직고용 슈퍼바이저 인건비 부담

### 중립
- "체육지도자" 칭호 금지 룰을 회원 앱·멘토 앱 UX writing 가이드에 반영 필요
