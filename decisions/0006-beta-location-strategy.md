# 0006. 베타 1호점 입지 전략 — 단위 경제 검증 우선

> [ADR 0005](./0005-pricing-phase-strategy.html) 에서 Phase 0~4+ 가격 매트릭스를 봉인했으나, **베타 1호점의 입지·capex 가정 자체**는 "강남·평당 35만·capex 3억"이라는 v1 기본값을 사용하고 있었다. 5/17 수익성 리뷰 결과, 이 가정으로는 마진 buffer 가 부족해 단위 경제 자체가 검증되지 않는 위험이 노출됨. 본 ADR 에서 **베타 1호점 = 평당 10만 외곽 입지·capex 1억** 으로 봉인한다.

- **상태**: Accepted
- **결정일**: 2026-05-18
- **결정자**: Young
- **선행**: [ADR 0001](./0001-consumer-pivot.html), [ADR 0004](./0004-one-time-ticket-pricing.html), [ADR 0005](./0005-pricing-phase-strategy.html)

## 맥락 (Context)

[ADR 0005](./0005-pricing-phase-strategy.html) 매트릭스의 Phase 0 (베타) 시나리오는 다음 v1 가정을 그대로 사용:

- 평당 임대료 **35만/월** (강남 기준)
- 60평 → 월 임대 **2,100만**
- 초기 capex **약 3억** (인테리어·기구·보증금)

5/17 수익성 리뷰 결과 (Base·Bear·Bull 3시나리오):

| 시나리오 | util | 마진 | BEP | 12개월 누적 (capex 차감) |
|---|---|---|---|---|
| Base | 50% | 20% | 14개월 | ~0 |
| Bear | 35% | 8% | 18개월+ | **−1억** |
| Bull | 65% | 28% | 8개월 | +1.5억 |

→ Bear 시 적자 1억. 베타 = "단위 경제가 가능한지" 자체를 검증하는 단계인데, capex 3억·BEP 14개월 = 검증 실패 시 회수 손실이 너무 큼. **베타의 목적과 가정이 정합하지 않음**.

## 결정 (Decision)

### 베타 1호점 = 평당 10만 외곽 입지 · capex 1억

- **입지**: 평당 임대료 **10만/월** (경기 외곽·인천·지방 광역시 외곽 중 택)
- **공간**: 60평 유지 (ADR 0001) → 월 임대 **600만**
- **Capex**: 약 **1억** (인테리어 5천 + 기구 3천 + 보증금/기타 2천 추정)
- **브랜드·강남 입지**: Phase 2+ (2~3호점)로 보류

### 시나리오 비교 (Base · S1 · 회원 495명 · ARPU 1.11억/월)

| | 강남 (평당 35만·capex 3억) | **베타 (평당 10만·capex 1억)** |
|---|---|---|
| 월 임대 | 2,100만 | **600만** |
| 월 고정비 | ~5,000만 | **~3,500만** |
| 월 이익 (Base util 50%) | 2,187만 (20%) | **3,687만 (33%)** |
| BEP | 14개월 | **2.7개월** |
| 12개월 누적 (capex 차감) | ~0 | **+3.3억** |
| Bear (util 35%) | 619만 (8%) | **2,119만 (27%)** |
| Bull (util 65%) | 3,700만 (28%) | **5,200만 (38%)** |

→ **모든 시나리오에서 베타 입지가 우월**. Bear 에서도 흑자 27% 유지.

### 입지 후보 (예시 · 미확정)

| 권역 | 후보지 | 평당 임대 추정 |
|---|---|---|
| 경기 외곽 | 의왕·광명·시흥 | 8~12만 |
| 인천 | 부평·계양 | 7~10만 |
| 지방 광역시 외곽 | 부산 사상·대구 달서 | 6~10만 |

→ 최종 후보지는 D-21 까지 현장 답사 + 지자체 인허가 확인 후 결정.

### 베타 KPI (단위 경제 검증)

| # | KPI | 임계 (D+) | 의미 |
|---|---|---|---|
| 1 | utilization (가중) | ≥ 35% (D+30) | Bear 임계 |
| 2 | utilization (가중) | ≥ 50% (D+90) | Base 도달 |
| 3 | CAC | ≤ 20만 (D+90) | LTV/CAC ≥ 3 보수 가정 |
| 4 | 회원 수 | ≥ 200명 (D+90) | capacity 활용 검증 |
| 5 | 마진 | ≥ 25% (D+90) | 단위 경제 통과 |

### 후속 트리거

- **Phase 2 진입** (강남·성수 등 브랜드 입지 2호점 추가): 베타 6개월 후 KPI 4/5 달성 시
- **Phase 3 가맹 확산**: Phase 2 후 6개월 (총 12개월 운영 데이터·SOP 정립 후)

### Reject 옵션 (회수·재설계)

- Bear 시나리오 (util ≤ 35%) **6개월 지속** 시 = 단위 경제 미검증 → 호점 폐쇄·모델 재설계
- capex 1억이므로 손실 buffer 가 검증 비용으로 수용 가능 (vs 강남 3억은 회수 부담 ↑)

### 가맹 확장 매력도 (Phase 3 함의)

- 점주당 capex 1억 = 점주 BEP **2.7개월** → 가맹 확장 매력 ↑
- 강남 capex 3억 = 점주 BEP **14개월** → 확장 어려움
- → 베타 모델 자체가 **가맹 확산 가능성을 내장**

## 검토한 대안 (Alternatives)

- **A. 강남 입지 (평당 35만·capex 3억)** — 브랜드 빌딩·언론 노출·고소득 회원 확보 유리. 단점: 단위 경제 검증 실패 시 손실 ↑, Bear 적자 1억, BEP 14개월. **기각** — 베타 목적 (단위 경제 검증)과 불일치.
- **B. 성수 입지 (평당 25만·capex 2억)** — 트렌디 입지, 브랜드 절충. 단점: 임대 1,500만 + capex 2억 = 여전히 buffer 부족. **기각** — Phase 2 후보로 이월.
- **C. 평당 10만 외곽 (본 결정)** — 단위 경제 검증 우선, Bear 도 흑자. 단점: 브랜드 빌딩 약함, 가맹점주 모집에 "강남 사례" 미사용. **채택** — 브랜드 빌딩은 Phase 2 에서 강남 2호점으로 확보.
- **D. 기존 헬스장 4개 가맹 변환** — 자본 ↓·검증 빠름. 단점: 기존 헬스장 운영 모델·강사 풀과 신규 모델 충돌. **보류** — Phase 2 가속 옵션으로 유지.

## 결과 (Consequences)

### 긍정적

- **단위 경제 검증 = 베타 1순위 목적과 정합**
- **Bear 시나리오 흑자 27%** → 검증 실패 리스크 최소화
- **BEP 2.7개월** → 빠른 손익분기, 자본 회수 ↑
- **가맹 확산 매력 내장** (점주당 1억 → BEP 빠름)
- **자본 buffer 확보** → Phase 2 강남 진입에 capex 2~3억 추가 투입 여력

### 부정적

- 브랜드 빌딩 약함 → 초기 PR·미디어 노출 감소. **완화**: Phase 2 강남 2호점으로 브랜드 보강
- 강남 회원 페르소나 (1A) 데이터 수집 지연 → Phase 2 진입 시 별도 가설 검증 필요
- 외곽 입지 강사 풀 검증 필요 (지방 강사 모집·통근 동선) — D-21 까지 확인

### 중립

- 외곽 입지 마케팅 전략 = 별도 검토 (강남과 채널 mix 다름)
- 자유업/체육시설업 분류는 지자체별로 변동 → 지자체별 인허가 확인 필수
