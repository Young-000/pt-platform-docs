# 0012. GX 단위 경제 최종 설계 — 슈퍼몽키 추종 모델의 재산출

- **상태**: Proposed (창업가 결정 대기 항목 §6 해소 시 Accepted)
- **작성일**: 2026-08-07
- **선행**: [ADR 0011](./0011-recovergx-gx-pivot.html)(GX 피벗) · [ADR 0010](./0010-unit-economics-3vars.html)(3변수 프레임, PT 레일) · 정책서 v2.0(4티어 통일가·P1~P5 정액 정산) · [런치 카탈로그](https://github.com/Young-000/pt-platform)(2026-06-28)
- **대체**: 본 ADR이 `economics/` 4페이지의 "🟡 GX 재산출 대상" 플래그를 해소하는 **경제 수치의 SSOT**다. ADR 0010의 3변수 *프레임*은 승계, *수치*는 전면 대체.

## 맥락

ADR 0011(2026-06-04) 이후 가격(4티어 통일가)·정산(P1~P5 회당 정액)·취소 정책은 v2.0으로 확정됐지만, **단위 경제 산출은 두 달째 "재산출 대상" 플래그만 붙은 채 비어 있었다**. 1:1 PT 레일 수치(unit 마진 17k·월 고정비 2,600만)가 문서에 남아 의사결정 앵커 역할을 계속하는 상태. 본 ADR은 슈퍼몽키 벤치마크(검증 라벨 붙은 것만 사용)를 대조군으로 GX 3변수를 최종 산출한다.

## 결정

### 1. 변수 1 — 공간·capacity·고정비 (GX 재산출)

**공간: 60평 승계, 스튜디오 2룸 재배치** (슈퍼몽키 초기 团课 직영교실 ~200㎡=60평과 동일 규모 [검증])

| 구획 | 면적 | 정원 |
|---|---|---|
| 스튜디오 A (댄스·버닝·펌프) | ~28평 | 20 |
| 스튜디오 B (코어·스트레칭·필라) | ~18평 | 12 |
| 로비·락커·샤워·창고 | ~14평 | — |

- capacity 단위: **클래스 슬롯 = 정원 N명** (PT 레일 "슬롯=1명"의 구조 전환)
- 이론 최대: 2룸 × 14h = 28슬롯/일. **편성 목표는 이론치가 아니라 시간표다**: base 월 350클래스(일 ~12) — 슈퍼몽키 단일매장 월 ~300타임 [검증] 대비 +17%.

**고정비: 월 2,200만** (PT 레일 2,600만에서 재산출)

| 항목 | 월 | 근거 |
|---|---|---|
| 임대 (60평 × 10만, 외곽·준도심) | 600만 | ADR 0006 승계 |
| 인건비 (매니저·CS 2명 — GX는 무인 체크인·리셉션 라이트) | 700만 | PT 레일 대비 감축 |
| 유틸리티·청소·소모품 | 250만 | |
| 마케팅 (로컬) | 400만 | |
| IT·보험·세무 + 수업 후 사진 의례(파트타임) | 250만 | 사진 의례 = 슈퍼몽키 입소문 80% 장치 [검증] |
| **합계** | **2,200만** | |

**CapEx: 1.35억 + 보증금 0.5억** — 인테리어·음향·조명·거울(스튜디오 2룸) + 경량 기구(매트·밴드·경량 바벨·스텝). 기구가 가벼운 것이 GX의 자본 이점 (PT 레일 1.5~2억 대비 감축). 60개월 상각 = 월 225만.

### 2. 변수 2 — U (2축 정의 확정)

```
U_정원  = 평균 출석 인원 / 평균 정원 16
U_슬롯  = 월 편성 클래스 / 420 (2룸 × 14h × 30일 이론치)
```

- 예약 후 노쇼는 **출석으로 계상** (결제 차감 유지 — v2.0 정책). 즉 U_정원의 분자는 "차감된 좌석".
- 시나리오 앵커 (아래 §4): 콜드스타트 25% → 보수 40% → base 55% → 낙관 70%.

### 3. 변수 3 — 클래스당 마진

- **평균 클래스 가격 21,000원** = 4티어 통일가 × 편성 믹스 (T1 30% · T2 35% · T3 25% · T4 10%, 런치 카탈로그 기준).
- 정산 (창업가 결정 대기 — §6-①):
  - **A안 (현행 v2.0)**: 등급별 회당 정액. P3 60분 = 28,000원. 출석 무관 → 빈 클래스 리스크를 플랫폼이 전액 부담.
  - **B안 (제안)**: **하이브리드 = 최소보장 25,000 + 인당 1,500원** (조합형 스키마의 기본금+인당 활성, 비율%=0). 슈퍼몽키의 "강사가 알아서 채우는" 동기 정렬 [검증: 등급 课时费+课量 연동] + 시스템은 이미 조합형 지원(ADR 0011 §4).
  - 정산율 검증: B안 15~26% — 슈퍼몽키 团课 정산율 추정 범위(10~20%)와 정합.

### 4. 지점 P&L 시나리오 (60분 클래스 · 정산 B안 기준)

| 시나리오 | U_정원 | 월 클래스 | 평균 출석 | 클래스 매출 | 정산 | 클래스 마진 | **월 지점 손익** | 임대비율 |
|---|---|---|---|---|---|---|---|---|
| 콜드스타트 | 25% | 240 | 4.0 | 84k | 31.0k | 53k | **−920만** | 29.7% ⚠️ |
| 보수 | 40% | 280 | 6.4 | 135k | 34.6k | 100k | **+380만** | 15.9% ⚠️ |
| **base** | **55%** | **350** | **8.8** | **185k** | **38.2k** | **147k** | **+2,720만** | 9.3% ✅ |
| 낙관 | 70% | 420 | 11.2 | 236k | 41.8k | 194k | **+5,720만** | 6.1% ✅ |

- 월 지점 손익 = 클래스 마진 × 월 클래스 − 고정비 2,200만 − 상각 225만.
- **sanity 앵커**: base 연매출 7.78억 ≈ 슈퍼몽키 단일매장 실측 연 373万元(~7.1억) [검증]. 우리 수치가 벤치와 같은 자리수임.
- **콜드스타트 적자 −920만/월 × 예상 6개월 = 런웨이 ~5,500만 별도 확보 필요** (CapEx와 별도).
- ⚠️ 슈퍼몽키의 "微盈利" [검증]와 base +2,720만의 갭 = ① 본사 비용(플랫폼 개발·본사 인력) 미배부 ② 도심 vs 외곽 임대. **본 표는 지점 공헌 P&L이다** — 본사 손익은 §5.

### 5. BEP · 스케일

- **CapEx 회수 (상각 전 공헌 기준)**: 보수 22개월 · base 5개월 · 낙관 2개월.
- **렌트 게이트 (슈퍼몽키 차용 [검증: 租售比 15% 이내 + "100% 성공" 신중 출점)**: **임대비율 15% 이하 검증 전 2호점 금지.** 보수 시나리오가 15.9%로 게이트에 걸림 = U_정원 40%로는 확장 불가, **실측 U_정원 ≥ 45%가 2호점 조건**.
- 100호점 projection: 기존 7C 문서의 PT 레일 수치 폐기. 지점 표준 P&L(본 ADR) × 지점 수 − 본사 비용(별도 모델링 — 플랫폼 개발비는 지점 수와 무관한 고정, 이것이 소프트웨어 레버리지). 상세는 U 실측(직영 1호점) 후 재산출 — **추정을 100배 곱하지 않는다.**

## 리스크 (반론 병기)

1. **U_정원 55%는 아직 신앙이다** — 슈퍼몽키 복购率 60% [검증]은 성숙기 수치. 콜드스타트 실측 전까지 base를 사실처럼 인용 금지. 직영 1호점 = U 실측 장치 (concept v3.0 "사이클 인위 증명"과 동일 결론).
2. **충전금 규제** — 선불전자지급수단(전자금융거래법) 리스크는 경제 모델과 독립적으로 열려 있음 (concept §12). 충전 보너스 설계는 법률 검토 후로 이연 — 본 ADR은 breakage(미사용 잔액)를 **수익으로 계상하지 않는다** (보수 회계).
3. **콘텐츠 비용 미반영** — Les Mills/Zumba 라이선스·강사 인증 TCO(진행 중 트랙)는 확정 시 고정비에 추가. 판권 코스당 十几万위안 [검증] 규모라 지점당 월 ~100만 수준까지 흡수 가능(base 기준).
4. **벤치 추종의 한계** — 슈퍼몽키 2024~25 일부 폐점·降薪 보도 [불확실] — 모델 자체가 시련기임. 낙관 시나리오를 계획 기준으로 삼지 말 것.
