# 0007. 강사 모델 — Pro Only · P1~P5 등급제 · 회당 고정 정산

- **상태**: Accepted
- **결정일**: 2026-05-20
- **결정자**: Young
- **선행**: [ADR 0001 §6](./0001-consumer-pivot.html), [ADR 0002](./0002-license-policy.html)
- **재봉인 대상**: [ADR 0001 §6](./0001-consumer-pivot.html) (S1/S2 하이브리드 폐기), [ADR 0002](./0002-license-policy.html) (일반 멘토 트랙 폐기)

## 맥락 (Context)

[ADR 0001 §6](./0001-consumer-pivot.html) 은 베타에서 **일반 멘토(S1) 위주**, 호점 확장 시 Pro(S2) 비중 ↑ 라는 하이브리드 전략을 채택했다. [ADR 0002](./0002-license-policy.html) 는 그 위에서 **일반 멘토 = 자격증 ❌**, Pro = 자격증 ✅ 의 단계적 의무화 모델을 설계했다.

5/19~20 리서치·재검토 결과 이 하이브리드의 전제가 깨진다:

1. **단골 통계** — 1:1 PT 산업의 LTV·재예약률은 강사 신뢰가 1순위 지표. "자격증 없는 일반 멘토" 풀은 회원 retention 함수에서 음의 기여를 한다.
2. **Super Monkey 2024 위기 사례** — 강사 정산 단가를 일방적으로 인하한 결과 (1) 우수 강사 이탈, (2) 회원 NPS 폭락, (3) 매출 8개월 연속 감소. **강사 신뢰는 회사가 임의로 깎으면 안 되는 자산**.
4. **회원 평균 ARPU 30,000원 (30분)** 가정 위에서 S1 12k 단가는 본사 마진 18k → 만석급에서 매출 함수가 capacity 에 묶임. 등급제로 단가를 회원 retention 함수에 정렬하는 게 LTV 관점에서 우월.
5. 회원 입장에서 "이 강사가 자격이 있는가" 는 1세션 안에 검증 불가 → **본사 자격 검증을 입구에서 막아주는** 게 시장 신뢰 형성에 더 효율적.

> 본 ADR 이전: 강사 = 일반(S1·자격증 ❌) + Pro(S2·자격증 ✅) 하이브리드.
> 본 ADR 이후: **강사 = Pro Only (전원 자격증·검증 통과)**. 일반 멘토 트랙 폐기.

## 결정 (Decision)

### 1. 강사 = Pro Only

- 모든 강사는 **생활스포츠지도사 2급** (또는 NSCA-CPT / NASM / KESPA 등 동등 자격) 1개 이상 보유.
- 본사 심사 (영상·면담·필기) 통과 필수.
- **일반 멘토(S1) 트랙은 폐기** — 자격증 없는 강사 영입 ❌.

### 2. 고용 형태 = 전속 · 프리랜서 모두 가능 (자유)

- 본사는 **자격·품질만 검증**. 고용 계약 형태는 강사 선택.
- 전속 = 주 4일 이상 본 지점 우선 배치. 프리랜서 = 본인 일정 자유 등록.
- 등급·정산 단가는 고용 형태에 무관 (등급 함수에만 의존).

### 3. 회당 고정 정산 (월급 ❌)

- 강사 보상 = **30분 unit × 등급 단가**. 월급·기본급 ❌.
- 강사가 본인 가용 시간을 등록 → 회원이 예약 → 정산은 실제 진행 세션 수에만 의존.
- 본사·강사 모두 capacity 활용에 정렬됨.

### 4. 등급 P1 ~ P5 (30분 unit 정산)

| 등급 | 명칭 | 30분 정산 | 시급 환산 | 진입 조건 (요약) |
|---|---|---|---|---|
| **P1** | 신입 | 10,000원 | 20,000원 | 자격증 + 검증 코스 통과 + 데뷔 |
| **P2** | 검증 | 12,000원 | 24,000원 | 세션 ≥ 100 + 회원 평점 ≥ 4.2 + 입력률 ≥ 85% |
| **P3** | 시니어 | 14,000원 | 28,000원 | 세션 ≥ 300 + 평점 ≥ 4.4 + 재예약률 ≥ 55% |
| **P4** | 전문 | 16,000원 | 32,000원 | 세션 ≥ 600 + 평점 ≥ 4.5 + 재예약률 ≥ 65% + NPS ≥ 40 |
| **P5** | 마스터 | 18,000원 | 36,000원 | 세션 ≥ 1,200 + 평점 ≥ 4.6 + 재예약률 ≥ 75% + NPS ≥ 50 + 멘토링 활동 |

**평균 정산 (P3 기준 가정) = 회당 13,000원** — 모든 단위 경제 시뮬레이션의 기본 강사 정산 단가.

### 5. 등급 변동 = 분기 1회 · 사전 공지 기준만

- **분기 1회** (3·6·9·12월 말) 등급 산정.
- 산정 기준은 **사전 공지된 항목만** 사용:
  - 회원 retention (3개월 재예약률)
  - 회원 NPS
  - 세션 완강율
  - 운동 기록 입력률 ([ADR 0009](./0009-workout-record-as-asset.html))
  - 재예약률
- **임계 일방 인상 ❌** — Super Monkey 2024 위기 교훈. 기준 변경은 1분기 사전 공지 필수.
- 강등 시 **6개월 유예** (현 등급 단가 유지) — 강사 안정성 보호.

### 6. 등급 투명성 (강사 앱)

강사는 본인 앱에서 실시간 조회 가능:

- 현재 등급 · 현재 단가
- 다음 등급 진입 조건 (KPI별 현재값 vs 임계)
- 분기 산정 시뮬레이션 (지금 상태로 분기 마감 시 결과)
- 회원 평점·재예약률·입력률 KPI 트렌드

### 7. 분기 미달 시 처리

| 상황 | 처리 |
|---|---|
| KPI 1개 임계 미달 | 등급 유지·경고 표시 |
| KPI 2개 이상 임계 미달 | 6개월 유예 후 1단계 강등 |
| 회원 신고·중대 사고 | 즉시 정지·조사 (등급 무관) |
| 세션 ≤ 30 (분기) | 등급 산정 보류 |

## 검토한 대안 (Alternatives)

### 대안 A — ADR 0001/0002 의 하이브리드(S1·S2) 유지
- 장점: 베타 공급 풀 확보 쉬움 (자격증 없는 강사 영입 가능).
- 단점:
  - 회원 retention 함수에 음의 기여 (단골 통계).
  - 시장 신뢰 형성 비용 ↑.
  - Super Monkey 가 강사 등급 단가 일방 인하로 위기를 겪은 사례 — 회원·강사 모두에게 신뢰 자산이 1순위.
- **기각**.

### 대안 B — Pro Only · 단일 단가 (모든 강사 같은 단가)
- 장점: 단순.
- 단점:
  - 우수 강사 보상 부족 → 이탈 위험.
  - 강사 성장 경로 ❌ → 데이터 플라이휠 약화.
- 기각.

### 대안 C (채택) — Pro Only · P1~P5 등급제 · 회당 고정 정산
- 회원 신뢰 = 입구에서 본사가 막아줌.
- 강사 성장 경로 = 등급 진입 조건 KPI 가 그대로 데이터 플라이휠.
- 단가는 회원 retention 함수에 정렬됨.

### 대안 D — Pro Only · 강사 본인 가격 책정 (마켓플레이스)
- 장점: 강사 자율성 ↑.
- 단점: 본사 통제 ❌, 가격 분산 → 회원 UX 복잡, 가맹 모델과 충돌.
- 기각 (cf. ADR 0001 대안 B 와 동일 사유).

## 결과 (Consequences)

### 긍정적

- **회원 신뢰** = 1세션 안에 검증 불가한 문제를 본사가 입구에서 해결.
- **강사 성장 경로** P1 → P5 = 명확한 보상·진입 조건 → retention.
- **데이터 플라이휠** — 평점·재예약률·입력률 KPI 가 강사 성장 함수의 입력 → 자연스러운 정합.
- **고용 자유** — 전속/프리랜서 mix 자유 → 공급 풀 다양화.
- **회당 정산** — capacity 활용에 본사·강사 모두 정렬.

### 부정적 / 리스크

- **베타 공급 풀 ↓** — 자격증 강제로 영입 풀이 좁아짐. 완화: KOL 채널 ([ADR 0008](./0008-marketing-channels.html)) + P1 신입 단가 10k 로 진입 마찰 ↓.
- **평균 정산 단가 ↑** (S1 12k → P3 평균 13k) — 본사 마진 −1k. ARPU 30k 가정에서 본사 마진 17k 로 흡수.
- **분기 1회 등급 변동** = 단기 조정 불가. 완화: 회원 신고·중대 사고 시 즉시 정지 별도 트랙.

### 중립

- [ADR 0002](./0002-license-policy.html) §1 (일반 멘토 자격증 ❌) 폐기. §2 (Pro 정의)·§3 (시설법용 슈퍼바이저)·§4 (호칭 안전판)·§5 (admin 토글) 은 그대로 유효.
- [ADR 0001 §6](./0001-consumer-pivot.html) S1/S2 하이브리드 표는 본 ADR 의 P1~P5 표로 대체.

## 단위 경제 영향

회원 평균 ARPU 30,000원 (30분) - 강사 평균 정산 13,000원 (P3) = **unit 당 본사 마진 17,000원**.

상세는 [ADR 0010](./0010-unit-economics-3vars.html) 참조.
