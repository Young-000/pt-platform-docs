# 0011. recoverGX — 오픈형 GX 그룹 클래스 피벗

- **상태**: Accepted
- **결정일**: 2026-06-04
- **결정자**: Young
- **영향 범위**: 사업 모델 전면 — [ADR 0001](./0001-consumer-pivot.html)(소비자향 PT)·[ADR 0004](./0004-one-time-ticket-pricing.html)(회차권)·[ADR 0007](./0007-trainer-model.html)(강사 모델) 의 **제품 레일을 GX로 전환**. 일부 인프라·법무·데이터 자산은 승계.

> 🔥 이 ADR이 현행 사업 방향의 최상위 결정이다. 이전 ADR(0001~0010)은 **1:1 PT 레일** 기준이며, 본 ADR로 제품·결제·정산·공급 모델이 **GX 그룹 클래스 레일**로 전환됐다. 1:1 PT 관련 본문은 "PT 레일 (보류)"로 읽을 것.

## 맥락 (Context)

[ADR 0007](./0007-trainer-model.html) Pro Only 피벗까지의 모델은 **1:1 PT(+다종목) · 30분 unit · 회차권 · 카리스마 강사 등급제**였다. 2026-05~06 슈퍼몽키 벤치마크([브랜드·성장 분석](https://github.com/Young-000/pt-platform))를 깊게 파면서 두 가지 결론에 도달:

1. **AI 개인화·강사 증폭이라는 우리의 moat은 1:1 PT 레일에서만 유효하다.** GX(그룹·드롭인)는 저개인화·저데이터라 AI가 설 자리가 약하다. 1:1 PT에 AI를 못 박는 건 맞지만, 콜드스타트 단계에서 카리스마 강사를 찾고·키우고·붙잡는 일(비싸고·깨지기 쉽고·선형)이 IP 없는 스타트업이 가장 못 하는 것이다.
2. **슈퍼몽키는 IP·명인·대형 광고 없이** ① 모델 자체(강매 없음·회차 결제) ② 내부에서 키운 강사 ③ 의례화된 입소문(성장 80%가 口碑) 으로 브랜드를 만들었다. 이 방법론은 **콜드스타트에 훨씬 강하다.**

→ 콜드스타트 리스크를 낮추기 위해 **초창기 진입 레일을 GX 그룹 클래스로 전환**한다. 1:1 PT 레일은 폐기가 아니라 **보류**(코드·데이터 보존) — PMF 확보 후 AI moat 레일로 부활 가능.

## 결정 (Decision)

**recoverGX = 어드민 큐레이션 룰 + 검증된 강사의 그룹 클래스 개설 + 회원 충전금 드롭인.**

### 1. 상품 — GX 그룹 클래스 (1:N)
- 1:1 PT(1슬롯=1회원) → **그룹 클래스(정원 N명, 기본 20)**. 룸당 시간당 1세션(배타).
- 회원은 지점 → 날짜 → **시간표**에서 열린 클래스를 탐색(잔여석 표시) → 드롭인 예약.

### 2. 결제 — 지갑(충전금) + 클래스별 가격
- 회차권([ADR 0004](./0004-one-time-ticket-pricing.html)) → **충전금(지갑) 모델**. 정액 패키지(5만/10만/30만, mock PG)로 충전 → 클래스별 가격만큼 차감.
- 가격은 **클래스마다 다름** (강사 지정, 어드민 상한/하한 범위 내). 예: 컨디셔닝 25k · 스트레칭 15k · 버닝 30k.
- 환불은 **지갑 즉시 크레딧** (현금 아님 — 슈퍼몽키와 동일).

### 3. 공급 — 어드민 큐레이션 + 강사 개설
- 어드민이 **룰**을 만든다: 카테고리 · 가격 상한/하한 · 강사 검증(개설 권한 `gxOpenEnabled`) · 충전 패키지 · 정산 정책 · 환불 마감.
- **검증된 강사**가 룰 안에서 클래스를 직접 개설(지점·룸·카테고리·시간·정원·가격). "누구나 개설(완전 오픈 마켓)"은 후기 비전.

### 4. 정산 — 조합형 정책
회당 고정 정산([ADR 0007](./0007-trainer-model.html) P1~P5)을 **조합형**으로 확장:
```
강사 지급액 = 기본금 + (인당 금액 × 출석 인원) + (클래스 매출 × 비율%)
```
어드민이 세 요소를 자유 조합(0으로 비활성), 강사별 정책 할당(미할당 시 기본). 클래스 완료 시 **정책 스냅샷**으로 정산 박제(정책 변경에도 과거 정산 불변).

### 5. 취소 / 환불 / 폐강 (슈퍼몽키 정책 차용)
- **회원 취소**: 시작 `refundCutoffHours`(기본 6h) 전 **전액 환불**, 이내 **0**(좌석은 항상 복구).
- **노쇼**: 패널티 없음 — 결제액이 정산 매출로 귀속.
- **폐강**: 강사(본인)·어드민(전체) → 예약자 **전원 전액 환불** + 좌석 복구.

### 6. AI — GX 레일에서는 보류
[ADR 0009](./0009-workout-record-as-asset.html) 데이터 플라이휠·AI 코칭은 **1:1 PT 레일 자산**으로 보류. GX는 접근성·큐레이션·입소문으로 승부. ("AI가 우리 브랜드의 스타"라는 마케팅 금지 — 체감 제품은 그룹 운동.)

## 승계 / 폐기 / 보류

| 영역 | 처리 |
|---|---|
| 인프라(모노레포·API·ECS·RDS·3앱 골격) | **승계** |
| 강사 검증·등급([ADR 0007] P1~P5) | **승계** (gxOpenEnabled 권한으로 큐레이션) |
| 카테고리(`CourseCategory`) | **승계** (GX 클래스 카테고리로 재사용) |
| 회차권([ADR 0004])·티어 멤버십 | **폐기** → 지갑 충전금 |
| 1:1 PT 예약·세션·AI 코칭([ADR 0001·0009]) | **보류** (코드·데이터 보존, 라우트 미노출) |
| 자유 헬스([ADR 0003]) | **보류** (GX 레일과 분리, 접근성 포지션) |

## 구현 상태 (2026-06-04)

- DB: `Wallet`·`WalletTransaction`·`ChargePackage`·`GxPolicy`·`GxPayoutPolicy`·`GxSettlement` 신규 + `GxClass.price`·`GxBooking.paidAmount`·`Mentor.gxOpenEnabled`.
- API: `/api/gx/*`(클래스·예약·출석·완료·폐강·정산) · `/api/wallet/*`(충전·잔액) · `/api/gx-admin/*`(룰). 어드민 로그인(`admin.service`) 구현.
- 3앱 GX 전용 전환 + 랜딩 GX 단일 + recoverGX 브랜드. Playwright e2e 검증.
- 잔여: ECS 배포 · 실 PG 연동(현 mock) · recoverGX 브랜딩(오렌지) 3앱 적용.

## 결과 (Consequences)

- (+) 콜드스타트 리스크↓ — 카리스마 강사 의존 제거, 입소문·큐레이션으로 진입.
- (+) 공실↓ — 오픈 시간표 + 드롭인으로 빈 좌석 재판매.
- (+) 진입장벽↓ — 약정·티어 없는 충전금 드롭인.
- (−) AI 데이터 moat 보류 — 1:1 PT 레일 부활 전까지 차별점은 운영·브랜드.
- (−) ARPU 변동성↑ — 클래스별 가격·드롭인이라 회차권 대비 예측성 낮음 → 정산 정책으로 마진 관리.
