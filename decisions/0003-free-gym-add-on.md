# 0003. 자유 헬스 = 부가 (단독 가입 ❌)

- **상태**: Accepted
- **결정일**: 2026-05-15
- **결정자**: Young

## 맥락 (Context)

소비자향 피벗 ([ADR 0001](./0001-consumer-pivot.html))에서 코스 카테고리를 정리하면서, **"강사 없이 회원 혼자 헬스 가능한가?"** 가 별개 결정 필요했다.

세 가지 옵션:

| 안 | 의미 |
|---|---|
| **A. 포함 (단독 가입 가능)** | 일반 헬스장과 가격 경쟁 들어감 |
| **B. 제외** | "강사 있는 운동 전문"으로 컨셉 명확 |
| **C. 강사 코스 회원에게만 부가 개방** | 자유 헬스 단독 가입 ❌ |

## 결정 (Decision)

**옵션 C**: 자유 헬스(오픈 공간 자유 이용)는 **강사 코스 회원에게만 부가 가치**로 제공한다.

### 세부 규칙
- 강사 코스 멤버십(월권/6개월권/1회권) 보유자만 자유 헬스 입장
- 별도 결제 ❌ (멤버십 내 포함)
- 자유 헬스 단독 가입 옵션 ❌ (제공하지 않음)
- 운영 시간 = 강사 코스 운영 시간과 동일
- 사고·안전 책임: 회원 본인 (입장 시 약관 동의)

### 운영
- 가맹점장(자격증 보유 슈퍼바이저)이 시설 안전 책임 ([ADR 0002](./0002-license-policy.html) §3)
- 비상 호출 버튼·CCTV·기본 안전 가이드 비치
- 청소·기구 점검 주기는 운영 변수 (`operation.free_gym_cleaning_interval_hours`)

## 검토한 대안 (Alternatives)

### 대안 A: 자유 헬스 단독 가입 가능
- 장점: 매출 다각화, 자유 헬스 회원이 강사 코스 전환 가능성
- 단점: **일반 헬스장과 직접 경쟁**. 가격 경쟁력 떨어짐(우리 임대료·평수 효율이 일반 헬스장 대비 불리). 컨셉 모호해짐
- 기각

### 대안 B: 자유 헬스 제공 ❌
- 장점: "강사 있는 운동 전문" 컨셉 가장 깨끗
- 단점: 오픈 공간 utilization 손실. 회원이 "운동만 하고 싶을 때" 다른 헬스장 이용 → 락인 약해짐
- 기각

### 대안 C (채택): 부가 개방
- 회원 입장: "강사 코스 + 자유 헬스 둘 다" → 한 번 가입으로 모든 운동 욕구 해결
- 본사 입장: 오픈 공간 utilization ↑ + 락인 강화 + 일반 헬스장과 경쟁 회피
- 단가는 멤버십에 흡수 (별도 청구 ❌)

## 결과 (Consequences)

### 긍정적
- 회원 만족도 ↑ (한 곳에서 모든 운동)
- 락인 ↑ (자유 헬스 못 쓰면 손해)
- 오픈 공간 비강사 시간대 활용
- 일반 헬스장 시장과 직접 충돌 회피

### 부정적
- 자유 헬스 회원이 강사 코스 회수를 안 쓰는 패턴 → 회원 가치 인식 ↓ 가능
- 안전·청소·기구 점검 운영 비용
- 가맹점장 자격증 보유 필수 (시설법)

### 중립
- 자유 헬스가 핵심 차별점은 ❌ — 진짜 차별은 강사 코스 다종목·자율 선택. 자유 헬스는 부가 락인 도구.

## 후속 작업
- [ ] 멤버십 약관에 "자유 헬스 부가 이용" 조항 추가
- [ ] 안전 가이드·비상 호출 UX 설계
- [ ] 자유 헬스 입장·이용 시간 기록 (회원 분석용)
