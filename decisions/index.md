# 의사결정 기록 (ADR)

> Architecture Decision Records — **사업·제품 차원의 결정**을 봉인하는 곳.

구두로만 합의된 결정은 시간 지나면 사라집니다. 여기에 기록해야 진짜 결정.

## 작성 규칙

- 파일명: `NNNN-title.md` (4자리 일련번호)
- [`_template.md`](./_template.html) 복사해서 사용
- 결정 트리의 노드가 닫힐 때마다 ADR 추가
