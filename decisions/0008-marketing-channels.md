# 0008. 마케팅 채널 mix — 강사 KOL + B2B 영업 + 자연 구전. 퍼포먼스 광고 최소화

- **상태**: Accepted
- **결정일**: 2026-05-20
- **결정자**: Young
- **선행**: [ADR 0006](./0006-beta-location-strategy.html), [ADR 0007](./0007-trainer-model.html)

## 맥락 (Context)

PT/피트니스 시장의 기존 신규 회원 획득 채널은 대부분 퍼포먼스 광고 (Meta·Google·네이버 GFA) 다. 그러나:

1. **CAC 인플레이션** — 2023~2025 PT 키워드 CPA 가 연 30%+ 상승.
2. **Super Monkey 사례** — 한국·일본 모두 광고 의존 ❌. 강사 SNS + 구전 + B2B 임직원 채널로 성장.
3. **Wellhub (구 Gympass)** — 한국 미진출. 우리가 직접 IT 법인 B2B 영업 가능.
4. **단골 통계** — 1:1 PT 산업의 신규 유입 중 구전·강사 채널이 50%+. 광고로 들어온 회원은 retention 평균 0.7배.
5. ARPU 30,000원 (30분) · LTV 가정에서 광고 CAC 가 20만원을 넘으면 LTV/CAC ≤ 3 무너짐. **광고 의존 = 단위 경제 적자 경로**.

[ADR 0007](./0007-trainer-model.html) 의 Pro Only · 등급제 → 강사 = 본인 SNS 채널 보유 가능성 ↑. 강사가 KOL 역할을 하면 본사 CAC ↓ + 강사 본인 단골 풀 확장 + 등급 진입 KPI (재예약률·NPS) 와 정렬됨.

## 결정 (Decision)

### 마케팅 채널 mix (베타 1호점 기준)

| 채널 | 비중 | 설명 |
|---|---|---|
| **강사 KOL** | **60%** | 강사 본인 SNS · 인스타·유튜브·블로그·구전. 본사 KOL 도구 (콘텐츠 템플릿·후기 영상 가이드·트래킹 링크) 제공. |
| **B2B 자체 영업** | **20%** | IT 법인·스타트업 임직원 복지. Wellhub 한국 미진출 → 우리가 직접. 단가 협상 별도. |
| **자연 구전 · NPS** | **15%** | NPS ≥ 50 회원의 추천 · 후기. NPS 임계 못 넘으면 자연 감소. |
| **퍼포먼스 광고** | **< 5%** | 베타 신규 카테고리·신규 입지 알림 한정. 정기 광고 ❌. |

### 1. 강사 KOL 채널 (60%)

- **콘텐츠 템플릿**: 회원 비포·애프터 (동의 시), 운동 기록 흥미 포인트, 강사 본인 트레이닝 일상.
- **본사 도구**:
  - 강사 트래킹 링크 (URL ?ref=mentor_id) → 강사를 통해 들어온 회원 자동 식별.
  - 강사 KOL 보너스 = 본인 트래킹 링크로 첫 결제한 회원 1인당 +20,000원 (1회).
  - 후기 영상 편집 가이드·예시 클립 라이브러리.
- **강사 인센티브 정렬**: 본인이 끌어온 회원이 재예약할수록 본인 재예약률 KPI ↑ → 등급 ↑ → 단가 ↑ ([ADR 0007 §5](./0007-trainer-model.html)).

### 2. B2B 자체 영업 (20%)

- **타겟**: IT 법인 · 스타트업 · 외국계 (임직원 복지 예산 보유).
- **상품 패키지**: 4회권 / 12회권 단가 −10% B2B 할인. 회사 결제·임직원 회당 사용.
- **Wellhub 모델 한국 변형**: 임직원이 본인 회사 SSO 로 회차권 신청 → 회사 일괄 결제.
- **영업 채널**: 본사 운영팀 직접 영업 (DM·세일즈 콜·HR 컨퍼런스). 외주 ❌.
- **베타 6개월 목표**: B2B 회원 ≥ 40명 (전체 200명 중 20%).

### 3. 자연 구전 · NPS (15%)

- **NPS ≥ 50 임계** 못 넘으면 채널 자체가 약화 → 회원 retention·세션 품질이 1순위.
- **추천인 보상**: 추천한 회원 + 추천받은 회원 모두 1회권 무료 1장.
- 후기 작성 보상 ❌ (자연 후기만 허용 — 광고법 회피).

### 4. 퍼포먼스 광고 (< 5%)

- **베타 launch 한정** — D-7 ~ D+30 입지 알림용 (Meta·인스타 지역 타깃, 일 5~10만원 예산).
- D+30 이후 **광고 ❌** — 강사 KOL·B2B·구전이 자체 성장 함수로 작동해야 함.
- 광고 매출 기여 시그널이 측정 불가하면 즉시 컷.

### 마케팅 예산 가정 (베타 1호점 6개월)

| 채널 | 6개월 예산 | 비고 |
|---|---|---|
| 강사 KOL 보너스 | 400만 (200명 × 2만) | 변동비 — 회원 1인당 |
| B2B 영업 운영 | 600만 (운영팀 인건비 부분) | 고정비 |
| 추천인 보상 | 200만 (1회권 × 100건) | 변동비 |
| 광고 (launch 한정) | 300만 (D-7 ~ D+30) | 일회성 |
| 콘텐츠 제작 (강사 가이드·후기 편집) | 200만 | 일회성 |
| **합계** | **1,700만 / 6개월 = 283만/월** | CAC ≤ 8.5만 (회원 200명 도달 시) |

> Super Monkey 한국·일본 패턴 — 광고 ❌, 강사 KOL + 임직원 채널 중심으로 6개월 회원 ≥ 500 달성. 우리는 베타 200 → Phase 2 강남에서 강사 KOL 풀 확장.

## 검토한 대안 (Alternatives)

### 대안 A — 퍼포먼스 광고 50%+
- 장점: 빠른 회원 확보.
- 단점:
  - CAC 인플레이션 → 단위 경제 적자 경로.
  - 광고 유입 회원 retention 평균 0.7배 → LTV ↓.
  - Super Monkey 사례에서 명시적으로 회피한 채널.
- **기각**.

### 대안 B — 외주 영업 대행 (B2B 채널)
- 장점: 빠름.
- 단점: 영업 멘트 통제 ❌·회원 retention 데이터 단절·수수료 ↑.
- 기각.

### 대안 C (채택) — KOL 60% + B2B 20% + 구전 15% + 광고 5% 미만
- 강사 인센티브 정렬, 회원 retention 함수와 정합.
- 본사 운영팀 부담 ↑ 이나 데이터 플라이휠 입력 단가 ↓.

## 결과 (Consequences)

### 긍정적

- **CAC 안정** — 강사 KOL · 구전 = 한계 CAC 가 자기 강사 단가에 흡수됨.
- **회원 retention ↑** — 광고 유입 ❌ 로 평균 retention 1.0배 유지.
- **강사 인센티브 정렬** — KOL 보너스 = 등급 KPI 와 같은 방향.
- **B2B = 정기 수익** — 임직원 결제 안정성 ↑.

### 부정적 / 리스크

- **베타 launch 속도 ↓** — 광고 ❌ 면 D+30 회원 ≥ 100 도달 가능성 의문. 완화: 강사 KOL 보너스 D-30 부터 사전 모집.
- **B2B 영업 = 운영팀 부담** — 영업 인력 1명 ≥ 필요. 운영비 (월 ~600만) 안에 포함.
- **자연 구전 = NPS 미달 시 작동 ❌** — 강사 등급 KPI 와 정렬되므로 강사 품질이 곧 마케팅 채널 품질.

- [ ] B2B 영업 자료·계약서 템플릿 (4회·12회 B2B 단가 -10%)

- [ ] 광고 ROI 측정 SOP — 측정 불가 시 즉시 컷
- [ ] D-30 강사 KOL 사전 모집 (강사 채널 ≥ 5명 ≥ 1만 팔로워)
