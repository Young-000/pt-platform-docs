# 0005. Phase별 가격 책정 전략

> ADR 0004 에서 회차권 5단 가격(1·4·12·24·48회)을 봉인했지만, 베타 · Phase 1~3호점 · Phase 4+ 단계별 가격 차등, 호점 입지별 변형, 회원 mix · 전환율 sensitivity 등 **운영 단계별 가격 전략**은 미정으로 남았다. 본 ADR 에서 Phase별 가격 매트릭스 · 트리거 · KPI 를 봉인한다.

- **상태**: Accepted
- **결정일**: 2026-05-16
- **결정자**: Young
- **선행**: [ADR 0001](./0001-consumer-pivot.html), [ADR 0004](./0004-one-time-ticket-pricing.html)

## 맥락 (Context)

[ADR 0004](./0004-one-time-ticket-pricing.html) 는 회차권 5단 단일 모델 + 가격 봉인 (4만 · 14만 · 36만 · 65만 · 120만). 그러나 다음은 미결:

1. **Phase 변천 (Phase 0 베타 → Phase 4+ 100호점)** 단계별 가격을 같게 유지할 것인가, 차등할 것인가
2. **호점 입지별 (강남/여의도/성수)** 평당 임대료 차이가 가격에 어떻게 반영되어야 하는가
3. **회원 mix·1회차 전환율·48회권 갱신율** 같은 변수에 대한 sensitivity — 어느 변수가 12개월 매출을 가장 크게 흔드는가
4. **Pro 강사 옵션 (+5k)** 인상 트리거 — 언제 +8k 로 올릴 것인가
5. **LTV 추정** — 1회차 체험 → 회차권 전환 → 갱신 의 캐스케이드

## Sensitivity 분석 (12개월 누적 매출 영향)

베타 1호점 기준 (회원 495명 · 매출 1.11억/월 · 이익 2,187만/월 · 마진 20%).

### 1차 sensitivity (단일 변수)

| 변수 | 변동 | 12개월 매출 영향 | 12개월 이익 영향 |
|---|---|---|---|
| 5단 mix (1회·4회 ↑ 10%p) | 단가 ↓ | −1.2억 (−9%) | −0.3억 |
| 5단 mix (24·48회 ↑ 10%p) | 단가 ↓·락인 ↑ | +0.4억 (+3%) | +0.6억 |
| 회차권가 ±10% | 일률 | ±1.3억 (±10%) | ±1.3억 |
| Pro 비중 0 → 30% | ARPU ↑ | +0.7억 (+5%) | +0.4억 |
| 1회차 전환율 30% → 50% | LTV ×1.5 | +0.5억 | +0.3억 |
| 48회권 갱신율 30% → 70% | 락인 ↑ | +0.8억 | +0.7억 |
| utilization 50 → 65% | capacity 활용 | +3.0억 (+22%) | +2.0억 |

→ **utilization > 가격 > 갱신율 > Pro > 1회차전환 > mix** 순으로 매출 민감.

### 2차 sensitivity (이중 변수, 2D 매트릭스)

`utilization × Pro 비중` 의 월 이익 (만원) — 시뮬레이터 v3 히트맵 참조:

| util\Pro | 0% | 15% | 30% | 50% |
|---|---|---|---|---|
| 40% | -200 | +50 | +250 | +500 |
| 50% | +2,187 | +2,480 | +2,781 | +3,100 |
| 60% | +4,500 | +4,800 | +5,100 | +5,500 |
| 70% | +6,800 | +7,150 | +7,500 | +8,000 |

> Phase 2 진입 트리거 = `util ≥ 70% × Pro ≥ 30%` → 월 이익 7,500만.

## LTV 추정

### 모델
```
LTV (1회차 entry 회원) =
  4만  (1회차 결제)
+ p_conv × avg_ticket_price        (전환 시 첫 회차권)
+ p_conv × p_renew × avg_lifetime_value
```

### 시뮬 (1회차 entry 회원당, 기간 12개월)

| 시나리오 | 전환율 | 갱신율 | 평균 회차권 | 12개월 LTV |
|---|---|---|---|---|
| 보수 | 30% | 30% | 4회권 | 약 **8만** |
| 중간 | 50% | 50% | 12회권 | 약 **42만** |
| 낙관 | 70% | 70% | 24회권 | 약 **95만** |

→ 1회차 신규 진입 1명당 평균 LTV ≈ **30~50만**. 1회차 마케팅 CAC 상한 ≈ **15만** (LTV/CAC ≥ 3).

## 결정 (Decision)

### 가격 고정 (Phase 0 · Phase 1)
- **Phase 0~1 가격 = [ADR 0004](./0004-one-time-ticket-pricing.html) 그대로**. 1회 4만 · 4회 14만 · 12회 36만 · 24회 65만 · 48회 120만, Pro +5k.
- 변경 ❌ 약 6개월 (2026-05 ~ 2026-11) → 데이터 수집기.

### Phase 2 가격 재검토
- **2026-11 운영 데이터 확보 후 별도 ADR (0006)** 로 Phase 2 가격 재산정.
- 트리거: 호점 수 ≥ 4 OR utilization ≥ 70% 도달 시.

### Pro 옵션 인상 트리거
- **Pro 옵션 +5k → +8k 인상 조건**: `utilization ≥ 70%` AND `Pro 비중 ≥ 30%` 동시 충족.
- 단일 트리거(util 만, Pro만) 로는 인상하지 않음 — 회원 저항 위험.

### 입지별 차등 (admin 변수)
- **평당 임대료 ±5만/월 차이마다 1회차 가격 ±5천원 조정** 가능 (`admin.PricingConfig.location_modifier`).
- 4·12·24·48회권은 입지 무관 (전국 통일). 1회차만 입지 변동 → 체험 진입 마찰 최소화.

### 가맹점 가격 자율 (Phase 4+)
- 30호점 이상 가맹점은 본사 권장가의 ±10% 범위 자율 결정.
- 본사 라이선스 fee 는 회원 수·매출 기반 (별도 ADR 필요).

## 검토한 대안 (Alternatives)

- **A. Phase 전체 가격 통일** — UX 단순, 마케팅 단순. 단점: 가맹 확장기 회원 확보 어려움, 입지별 임대료 흡수 ❌. **기각**.
- **B. Phase 0 부터 가맹점 자율** — 시장 학습 빠름. 단점: 본사 브랜드·정책 일관성 ❌, 베타 데이터 신뢰도 ↓. **기각**.
- **C. 입지별 전 회차권 차등** — 임대료 정확 반영. 단점: 회원 혼란, "강남이 더 비싸" 불만, 마케팅 복잡도 ↑. **기각** (1회차만 변동 채택).
- **D. Pro 옵션 즉시 +8k 인상** — ARPU 빠른 상승. 단점: Pro 비중 낮은 베타에서 회원 저항 위험. **기각** (트리거 조건 채택).

## 결과 (Consequences)

### 긍정적
- **Phase 단계별 가격 전략 = 가시화** → CEO·투자자에게 12·24·36개월 매출 곡선 제시 가능.
- **트리거 기반 인상** → 임의 가격 변경 방지, 데이터 근거 의사결정 문화.
- **입지 modifier** = admin 변수 → 코드 배포 없이 신규 호점 가격 책정.
- **LTV 시뮬** → 마케팅 CAC 상한 명확화 (15만/회원).

### 부정적
- Phase 2 가격이 **현 단계에서 가설** — 2026-11 실측 후 ADR 0006 재작성 필요.
- 2D sensitivity 매트릭스는 보수 가정 기반 — Phase 0 실측 후 갱신 필수.
- Pro 옵션 인상 트리거가 **자동 발동 ❌** — 인간 결정 필요. 트리거 도달 시 ADR 갱신 의무 명문화 필요.

### 중립
- Phase 4+ 가맹점 자율은 본 ADR 에서는 **방향만**, 구체 본사-가맹 정산 모델은 별도 ADR.
