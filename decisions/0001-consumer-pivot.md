# 0001. 소비자향 PT 시장 피벗

- **상태**: Accepted
- **결정일**: 2026-05-15
- **결정자**: Young 외 (5/15 회의)

## 맥락 (Context)

기존 PT 시장은 **공급자 중심**으로 구조화돼 있다:

- 회원은 처음 등록한 강사에게 락인 → 종목·시간 자유도 없음
- 강사 일정에 맞춰 회원이 시간을 조정
- 한 강사가 PT 한 종목만 (스트레칭·필라테스·요가 등 다른 운동 욕구는 별도 시설에서 충족)
- 1회권 결제가 사실상 없음 → 진입장벽 ↑

회원 입장에서 보면 **"오늘은 스트레칭, 내일은 PT, 다음 주는 필라테스를 다른 강사에게 30분만 받고 싶다"**는 자연스러운 욕구가 모두 차단된다.

## 결정 (Decision)

**소비자가 매 세션마다 자율적으로 선택**할 수 있도록 모델을 재정의한다.

### 1. 예약 대상 = "**강사 + 프로그램**" (룸 ❌)
회원은 강사·프로그램을 고른다. 룸은 프로그램 속성에 따라 자동 배정.

### 2. 프로그램 분류 (확장 가능)
- **룸 필요 프로그램** (스트레칭·필라테스 등): 8 private 룸 점유
- **오픈 공간 프로그램** (1:1 PT): 오픈 공간 + 강사 점유
- **자유 헬스** (강사 없음, 부가가치): 강사 코스 회원에게만 부가 개방 (단독 가입 ❌, 락인 도구)

> 코스 카테고리는 **미정·가변** — admin에서 추가 가능. 일반 멘토는 한 강사가 멀티 종목 가능 (모델 의존).

### 3. 시간 단위 = **30분 unit**
원하면 60분(2 unit) 연속 예약. 회원이 강도·시간 자유 조절.

### 4. 1회권 도입
멤버십 외 단발 결제 허용. 신규 회원 진입장벽 ↓.

### 5. 공간 = **60평** (기존 92평에서 축소)
- 8 private room (룸 코스 전용)
- 나머지 오픈 공간 (PT + 자유 헬스 겸용)

### 6. 멘토 시장 = **두 시나리오 병행 (하이브리드)**

> **강사 정산 30분당 20,000원이 상한선**. 실제는 등급·종목·utilization에 따라 12,000~20,000원 범위에서 결정. admin 정책 변수로 변경 가능.


| | **S1. 파트타이머** | **S2. 전문 강사** |
|---|---|---|
| 정산 (30분 슬롯) | 12,000원 (예시) | **최대 20,000원** (상한선) |
| 자격증 | ❌ (검증 코스만) | ✅ 생활스포츠지도사 2급 등 |
| 락인 미끼 | 유연 근무 | 학습·창업 찬스 |
| 공급 풀 | 넓음 | 좁음 |
| 회원 신뢰 | 중 | 상 |
| **베타에선 S1 위주** | | |
| **호점 확장 시 S2 비중 ↑** (Pro 인증) | | |

### 7. 가격 (변경)
- **월 이용권 (주 2회)**: **24만원** (회당 3만, 8회/월)
- **6개월권**: **120만원** (월할 20만, 회당 2.5만)
- **1회권**: 추가 옵션 (가격 미정)
- **프로그램 옵션 추가 결제**: 옵션 (가격 미정)

> **→ 1회권 포함 5단 라인업(1·4·12·24·48회) · 옵션 가격은 [ADR 0004](./0004-one-time-ticket-pricing.html)에서 봉인됨 (2026-05-16).** 본 §7의 "월 이용권/6개월권" 표현은 v2 회차권 단일 모델로 통합 — 회차 8회·48회는 각각 ADR 0004 표의 8회(폐기) → 12회·24회 또는 48회 라인업으로 흡수.

## 검토한 대안 (Alternatives)

### 대안 A: 기존 모델 유지 (1:1 PT 단일, 90분 세트, 룸 예약, 매칭)
- 장점: 코드·문서 변경 없음
- 단점: 시장 진단(공급자향)을 못 풀음. 차별화 ❌
- 기각

### 대안 B: 완전 마켓플레이스 (강사가 자기 프로그램·가격 등록, 본사는 플랫폼만)
- 장점: 확장성·강사 자율성 ↑
- 단점: 품질 관리 어려움. 본사 통제력 ↓. 가맹 모델과 충돌
- 기각

### 대안 C (채택): 본사 통제 + 회원 선택 자율성
- 본사가 프로그램 카테고리·강사 풀·가격을 통제
- 회원은 그 안에서 매 세션 자율 선택
- 30분 unit + 1회권으로 진입장벽 ↓

## 결과 (Consequences)

### 긍정적
- 회원 자율성 ↑ → 락인보다 만족도로 retention
- 다종목 → 평생 가치 ↑ (회원이 한 곳에서 모든 운동 욕구 해결)
- 1회권 → 신규 진입 ↑
- 60평으로 축소 → 호점당 투자비 ↓ → 가맹 매력 ↑

### 부정적 / 리스크
- **DB 모델 재설계 필요** (`RoomSlot` → 카테고리별, `Reservation` 모델 재정의, 1회권 결제 흐름)
- **매칭 알고리즘 폐기** → 회원 직접 선택 UI로 재구현
- **강사 단가 시나리오 미정** → 베타 결과 후 결정
- **6개월권 마진 ↓** (회당 본사 마진이 월권의 56%) → 가격 재검토 필요할 수도
- **자유 헬스의 추가 운영 비용** (안전·청소·관리)

### 중립
- AI 역할 = 종목 추천까지 확장 ("오늘 뭐 받지?")
- Pro 인증 = 전문 강사 풀(S2)의 진입점으로 유지
