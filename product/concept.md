# 서비스 컨셉

> "오프라인 링글 + 공간 예약 + AI 코치"

## 한 줄 정의

**링글의 1:1 튜터 매칭 모델을 오프라인 피트니스로 확장한 서비스.**

## 핵심 차별점

### 1. 3차원 매칭 예약
링글이 (시간 × 튜터) 2차원이라면, PT Platform은:
- **지점** × **시간** × **강사** 3차원 매칭
- 회원은 가까운 지점에서 원하는 시간에 원하는 강사 선택

### 2. 회차 기반 멤버십
| 티어 | 구성 | 타겟 |
|---|---|---|
| Basic | 그룹 PT 8회 | 입문자, 가격 민감 |
| Standard | 그룹 PT 8회 + 1:1 PT 2회 | 일반 |
| Premium | 그룹 PT 8회 + 1:1 PT 4회 | 본격 관리 |

### 3. Human-AI Hybrid Coaching
- **강사**: 주 1-2회 대면 세션, 고품질 피드백
- **AI**: 매일/매주 상시 코칭 — 식단·습관·동기부여
- 둘이 서로를 보완 (강사 = 디테일, AI = 지속성)

### 4. 데이터 플라이휠
```
강사 세션 기록 → 회원 운동 이력 축적 → AI 개인화 정밀도 ↑
                    ↑                          ↓
                    └─ 다음 세션 추천 정확도 향상 ─┘
```

## 무엇이 아닌가

- **헬스장이 아님** — 공간이 아니라 **세션**을 판매
- **PT샵이 아님** — 강사가 회원의 멤버십·결제 정보 못 봄 (운동 데이터만)
- **앱 only가 아님** — 오프라인 공간 + 디지털 도구의 결합

## 설계 원칙

1. **기본은 항상 PT 포함** — "추가 PT" 개념 없음
2. **강사는 운동 데이터만** — 결제·멤버십 정보 차단 (프리랜서 신뢰 문제)
3. **세션 기록은 5분 내 입력** — 강사가 부담 없이 매번 기록 가능한 수준
4. **AI는 데이터 양에 비례하는 가치** — 초기엔 단순, 시간 지날수록 정교
