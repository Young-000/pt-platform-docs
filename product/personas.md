## 1단계 — 페르소나 카테고리 결정 ✅

> **Option A — 단일 페르소나 (Middle Ground Mover) 채택.**
> 검토한 대안 (B 단계화 / C 라이프스테이지)은 향후 옵션으로 보존.

```
"Middle Ground Mover (운동 중립지대)"
주 2-3회 움직이고 싶지만, 풀 PT는 부담이고 혼자 가면 막막한 사람.
연령·성별 불문, 행동 기반.
```

## 2단계 — 구체적 모집 대상 정의 🔴 **(현재 작업)**

"Middle Ground Mover" 라벨만으론 1호점 마케팅·입지·강사 모집 불가능. 다음을 정의해야 함:

### 결정해야 할 것

- [ ] **연령대**: 20대 후반? 30대 초반? 40대?
- [ ] **성별 비중**: 여성 우선? 혼합? 남성 우선?
- [ ] **소득**: 월 300만 / 500만 / 700만+?
- [ ] **거주·직장 패턴**: 오피스 직장인 / 프리랜서 / 자영업?
- [ ] **운동 동기 1순위**: 외모 / 건강 / 체력 / 사회성?
- [ ] **운동 경험**: 입문자 / 경험 단절 후 재개 / 중급 (헬스 다닌 적)?
- [ ] **결정 트리거**: 다이어트 시작? 부상 회복? 출산 후? 직장 스트레스?
- [ ] **모집 채널**: 인스타그램? 구글? 입소문? 인플루언서?

### 검증 방법

| 방법 | 기간 | 비용 |
|---|---|---|
| 시장 인터뷰 5-10명 (Middle Ground 후보) | 1-2주 | 시간 |
| 기존 PT샵·헬스장 회원 분포 데이터 (공개 자료) | 1주 | 0 |
| 1호점 입지 후보 인구 통계 매핑 | 1주 | 0 |
| 페이스북·인스타 광고 A/B 테스트 (소규모) | 1주 | 50-100만 |

## 3단계 — 강사 페르소나로 연결 (3A)

회원 페르소나가 정해지면 **그 회원에게 매칭되는 강사 페르소나**가 자동으로 좁혀짐.

예 (가설):
- 회원 = 직장인 여성 28-35세 → 강사 = 여성 강사 비중 ↑, 출산 후 운동 경험 강사 매력
- 회원 = 직장인 남성 30-40세 → 강사 = 체력·근력 중심, 베테랑 비중 ↑

→ **[3A 강사 페르소나](../partners/personas.html)**가 1A 결정 후 다음 결정.
