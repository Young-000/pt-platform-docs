# 1D. Value Proposition

**🟢 Decided** · 의존: [1A](./personas.html), [1B](./problems.html), [1C](./competition.html) → 모든 마케팅·모집 카피

## 한 줄

> **"강매 없음 · 연장 압박 없음 · 충전해서 쓰는 만큼만."**

## 이해관계자별 VP

### 회원

- **투명한 클래스별 가격** — 등록 전에 얼마인지 다 보임
- **약정 없음** — 안 맞으면 그냥 안 가도 됨. 충전금 잔액은 남음
- **드롭인** — 원하는 날·원하는 클래스 골라서 예약
- **충전금 모델** — 선불 장기약정 대신 충전 후 차감. 강매 구조 자체 없음

### 강사

- **검증 후 클래스 직접 개설** — 본사가 정한 품질 기준 통과 후 자율적으로 클래스 구성
- **조합형 정산** — 클래스 단위 정산. 수강생 수·클래스 수 조합으로 수입 결정
- **플랫폼 인프라** — 예약·결제·정산·고객 관리 본사가 처리

### 본사

- **룰·검증·결제·정산·데이터 보유** — 플랫폼 레이어 장악
- **공실 최소화** — 드롭인 특성상 다양한 시간대 수요 분산
- **브랜드 락인** — 강사 개인이 아닌 recoverGX 브랜드로 회원 귀속

## 4요소

- **오픈 탐색** — 약정 없이 클래스 보고 드롭인
- **큐레이션** — 검증된 강사, 품질 보장 클래스
- **투명 가격** — 클래스별 명시 가격, 숨겨진 비용 없음
- **충전금** — 강매 구조 해체, 쓴 만큼만 소비
