# Level 0 — 비전 🟢 LOCKED

> **100호점 이상 체인화.**

## 야망 수준

- 단일 스튜디오가 아닌 **체인 브랜드**.
- GX 드롭인 모델로 콜드스타트 → PMF → 직영 확장 → 가맹 하이브리드.
- 지점 수 100+ 도달 후에도 운영 품질·강사 검증·클래스 큐레이션 일관성 유지.

---

## 단계별 마일스톤 (Phase) — 시점 미정 ⚠️

{: .warning }
> **각 Phase의 도달 시점은 모두 미정 (TBD).** 단계 간 전환은 **시간 기준이 아닌 KPI 기준**으로 결정합니다. 이는 검증되지 않은 가설로 시간을 박는 위험을 피하기 위함.

```
Phase 1 ──────► Phase 2 ──────► Phase 3 ──────► Phase 4
1-3호점          4-10호점         10-30호점        30-100호점
GX 직영 검증     가맹 시작        본격 확장        체인 굳히기
```

| Phase | 지점 수 | 핵심 과제 | 다음 Phase 진입 KPI | 시점 |
|---|---|---|---|---|
| **Phase 1** | 1 → 3호점 | **GX PMF 검증** + 검증 강사 코어 확보 + 운영 매뉴얼 | PMF 시그널 (재방문율·클래스 충원율) + 매뉴얼 완성 | 미정 |
| **Phase 2** | 4 → 10호점 | 가맹 1호 시작, 강사 모집 다양화·클래스 카테고리 확장 | 가맹 매뉴얼 안정화 + 본사 시스템 자동화 | 미정 |
| **Phase 3** | 10 → 30호점 | 가맹 본격 확장, 본사 시스템 안정화, 본사 BEP | 본사 누적 흑자 전환 | 미정 |
| **Phase 4** | 30 → 100호점 | 지역 가맹 마스터, 브랜드 굳히기 | 100호점 도달 | 미정 |

{: .note }
> **Phase 1의 핵심은 BEP가 아니라 PMF (Product-Market Fit) 검증.**
> GX 드롭인 모델이 진짜 되는지 — 클래스 충원율·재방문율·강사 만족도·입소문이 진짜 KPI.
> 강사 많이 모집할 필요 없음. 검증된 코어 강사로 클래스 품질 유지가 우선.

→ 각 Phase는 KPI 충족 시 다음 Phase로. 시간이 아닌 **결과 기준 진행**.

## 100호점이 결정하는 것들

| 영역 | 영향 |
|---|---|
| 확장 모델 | 자기 자본만으로는 불가능 → [가맹 모델 검토](../expansion/model.html) |
| 강사 모델 | 100개 지역에서 검증 강사 공급 가능해야 → [모집 전략](../partners/recruitment.html) |
| 운영 시스템 | 본사 SOP·매뉴얼·클래스 개설·정산 자동화 필수 |
| 단위 경제 | 지점당 BEP 빠르게 도달해야 가맹 매력 ↑ (수치 재산출 대상) |
| 브랜드 | 강사 개인이 아닌 **recoverGX 플랫폼 브랜드**로 회원 락인 (슈퍼몽키 방법론) |
