# Level 0 — 비전 🟢 LOCKED

> **100호점 이상 체인화.**

## 야망 수준

- 단일 부티크 스튜디오가 아닌 **체인 브랜드**.
- 지점 수 100+ 도달 후에도 운영 품질·AI 데이터·강사 풀 일관성 유지.

---

## 단계별 마일스톤 (Phase) — 시점 미정 ⚠️

{: .warning }
> **각 Phase의 도달 시점은 모두 미정 (TBD).** 단계 간 전환은 **시간 기준이 아닌 KPI 기준**으로 결정합니다. 이는 검증되지 않은 가설로 시간을 박는 위험을 피하기 위함.

```
Phase 1 ──────► Phase 2 ──────► Phase 3 ──────► Phase 4
1-3호점          4-10호점         10-30호점        30-100호점
직영 검증        가맹 시작        본격 확장        체인 굳히기
```

| Phase | 지점 수 | 핵심 과제 | 다음 Phase 진입 KPI | 시점 |
|---|---|---|---|---|
| **Phase 1** | 1 → 3호점 | **유저 반응도 검증 (PMF)** + 강사 안정 코어 12명 ± 운영 | PMF 시그널 + 매뉴얼 완성 | 미정 |
| **Phase 2** | 4 → 10호점 | 가맹 1호 시작, **강사 모집 다양화·파트형 본격화** | 가맹 매뉴얼 안정화 + 본사 시스템 자동화 | 미정 |
| **Phase 3** | 10 → 30호점 | 가맹 본격 확장, 본사 시스템 안정화, 본사 BEP | 본사 누적 흑자 전환 | 미정 |
| **Phase 4** | 30 → 100호점 | 지역 가맹 마스터, 브랜드 굳히기 | 100호점 도달 | 미정 |

{: .note }
> **Phase 1의 핵심은 BEP가 아니라 PMF (Product-Market Fit) 검증.**
> 방 8개 × 30분 단위 슬롯 = 강사 12명이면 공급 충분.
> 강사 많이 모집할 필요 없음. 회원 반응·재예약·강사 만족·AI 데이터 축적이 진짜 KPI.

→ 각 Phase는 KPI 충족 시 다음 Phase로. 시간이 아닌 **결과 기준 진행**.

## 100호점이 결정하는 것들

| 영역 | 영향 |
|---|---|
| 확장 모델 | 자기 자본만으로는 불가능 → [가맹 모델 검토](../expansion/model.html) |
| 강사 모델 | 100개 지역 모집 가능해야 → [모집 전략](../partners/recruitment.html) (Phase 2부터 다양화) |
| 운영 시스템 | 본사 SOP·매뉴얼·소프트웨어 자동화 필수 |
| 단위 경제 | 지점당 BEP 빠르게 도달해야 가맹 매력 ↑ |
| 브랜드 | 강사 개인이 아닌 플랫폼 브랜드로 회원 락인 |

## Phase별 강사 모델 변화 (요약)

| Phase | 강사 모델 | 모집 |
|---|---|---|

| **Phase 4** | 지역 분산, 마스터 가맹 강사 풀 | 지역 단위 |
