# Level 0 — 비전 🟢 LOCKED

> **100호점 이상 체인화.**

## 야망 수준

- 단일 부티크 스튜디오가 아닌 **체인 브랜드**.
- 지점 수 100+ 도달 후에도 운영 품질·AI 데이터·강사 풀 일관성 유지.

## 100호점이 결정하는 것들

| 영역 | 영향 |
|---|---|
| 확장 모델 | 자기 자본만으로 100호점은 불가능 → [가맹 모델 검토](../expansion/model.html) |
| 강사 모델 | 100개 지역에서 강사 모집 가능해야 함 → [모집 전략](../partners/recruitment.html) |
| 운영 시스템 | 본사 SOP·매뉴얼·소프트웨어 자동화 필수 |
| 단위 경제 | 지점당 BEP 빠르게 도달해야 가맹 매력 ↑ |
| 브랜드 | 강사 개인이 아닌 플랫폼 브랜드로 회원 락인 |

## 단계별 마일스톤 (가설)

| 단계 | 지점 수 | 핵심 과제 |
|---|---|---|
| 1단계 | 1~3호점 | 직영 운영, 모델 검증 |
| 2단계 | 4~10호점 | 운영 SOP 정립, 가맹 1호 시작 |
| 3단계 | 10~30호점 | 가맹 본격 확장, 본사 시스템 안정화 |
| 4단계 | 30~100호점 | 지역 가맹 마스터, 브랜드 굳히기 |
