# Level 0 — 정체성 🟢 LOCKED

> **"검증된 강사가 여는 그룹 클래스를 회원이 충전금으로 골라 드롭인하는 오픈형 GX 플랫폼."**
> 슬로건: **"강매 없음 · 연장 압박 없음 · 충전해서 쓰는 만큼만."**
> 목표: **100호점 이상 체인화** (직영 → 가맹 하이브리드). ([ADR 0011](../decisions/0011-recovergx-gx-pivot.html))

## 정의

- **오픈형 GX** — 강사가 클래스를 직접 개설하고, 회원은 원하는 클래스를 골라 드롭인. 경직된 장기 프로그램 없음.
- **충전금 모델** — 선불 장기약정 대신 충전금 충전 후 클래스별 명시 가격으로 차감. 쓴 만큼만 소비.
- **드롭인** — 특정 강사·시간 고정 없이 스케줄을 보고 원할 때 예약. 이탈 부담 없음.
- **검증 강사** — 본사가 검증한 강사만 클래스 개설 가능. 강사 복불복 해소.

## 무엇이 아닌가

| 비교 대상 | 차이 |
|---|---|
| 헬스장 | 공간만 파는 게 아닌 **큐레이션된 클래스** 판매 |
| 일반 GX 센터 | 강매·장기약정 없음. 클래스별 투명 가격 |
| 1:1 풀 PT | 그룹 포맷. 1:1 PT 레일은 현재 **보류** (GX PMF 이후 재검토) |
| 운동 앱 | 오프라인 공간 + 검증된 인간 강사 결합 |

{: .note }
> 1:1 private PT 레일은 GX 단일 레일로 PMF를 검증한 뒤 옵션으로 재검토합니다. ([ADR 0011](../decisions/0011-recovergx-gx-pivot.html))
