# 로드맵 (3-Track Timeline) ⭐

> **시점 미정.** 단계 전환은 시간이 아닌 **KPI 기준**.
> 세 트랙이 각자 흐르되 Phase 단위로 동기화됩니다.

---

## 트랙 정의

| 트랙 | 핵심 질문 | 다루는 결정 영역 |
|---|---|---|
| 🏢 **Business** | 어떻게 조직·돈을 굴리는가? | 정체성·BM·가맹·정산·법무·자본 |
| 📍 **Space** | 어디에 어떻게 공간을 짓는가? | 입지·평수·인테리어·임대·운영 |
| 🎯 **Service** | 무엇을 어떻게 제공하는가? | 세션·AI·강사·회원·예약 |

## Phase 1 — 유저 반응도 검증 (PMF) (1 → 3호점)

**진입 조건**: 정체성·비전 락 (완료) · 1A 페르소나 결정 필요
**진출 조건**: **PMF 시그널 확보** (재예약률·NPS·회원 만족도) + 운영 매뉴얼 완성

{: .note }
> 이 단계 핵심은 BEP가 아니라 **"우리 모델이 진짜 되는가"** 검증.
> 방 8개 × 30분 슬롯 = 강사 12명이면 공급 충분. 강사 풀 확장은 Phase 2.

- 🔴 [3A Pro 강사 모델](../partners/model.html) — Hybrid 결정 + 코어 풀
- 🔴 [3D 정산](../partners/payout.html) 구조 결정
- 🔴 [4A 멤버십·4B 가격](../members/pricing.html) 결정
- 🔴 자본 조달 (자기자본 + 시드)
- ⚪ 법인 설립

### 📍 Space

## Phase 2 — 가맹 시작 (4 → 10호점)

**진입 조건**: Phase 1 완료 (1호점 BEP + 매뉴얼)
**진출 조건**: 가맹 매뉴얼 안정화 + 본사 시스템 자동화

### 🏢 Business

- 🔴 [5A 확장 모델](../expansion/model.html) — 직영+가맹 혼합 본격화
- 🔴 [5B R&R](../expansion/responsibility.html) · [5C 수익 분배](../expansion/revenue-share.html) 확정
- ⚪ [8A 가맹사업법](../legal/franchise-law.html) — 정보공개서 등록
- 🔴 가맹 1호점 모집·계약
- 🔴 시리즈 A 검토

### 📍 Space

- 🔴 직영 추가 1-2호점 (검증 강화)
- 🔴 가맹점 표준 사이즈 락 (50평·90평 두 모델)
- 🔴 가맹점 인테리어 표준화 (지정 시공업체)
- 🔴 가맹 1호점 오픈

### 🎯 Service

- 🔴 ★ **[3A 강사 모델 다양화](../partners/model.html) — 파트타임·다채널 본격화**
- 🔴 강사 풀 자동화 onboarding 시스템
- 🔴 AI 시스템 본격 가동 (Mock → 실 데이터 학습)
- 🔴 회원 데이터 플라이휠 작동 검증

## Phase 3 — 본격 확장 (10 → 30호점)

**진입 조건**: 가맹 매뉴얼 안정화
**진출 조건**: 본사 누적 흑자 전환

### 🏢 Business

- 🔴 본사 BEP (회원 6,000명 가정)
- 🔴 가맹 모집 자동화·표준화
- ⚪ 마스터 가맹 (지역 단위) 도입 검토
- 🔴 본사 인사·CS 조직 확대

### 📍 Space

- 🔴 가맹 본격 확장 (전국 주요 도시)
- 🔴 입지 데이터 축적 → 입지 추천 알고리즘
- 🔴 직영 비율 30%로 축소

### 🎯 Service

- 🔴 등급별 차등 강사 운영
- 🔴 다이나믹 프라이싱 도입 (피크/오프피크)
- 🔴 회원 LTV 데이터 기반 retention 운영
- 🔴 AI 코칭 정밀도 ↑

## Phase 4 — 체인 굳히기 (30 → 100호점)

**진입 조건**: 본사 흑자 + 가맹 시스템 자동화
**진출 조건**: 100호점 도달

### 🏢 Business

- 🔴 지역 마스터 가맹 본격화
- 🔴 본사 R&D (AI·하드웨어 moat)
- 🔴 IPO·M&A 등 EXIT 시나리오

### 📍 Space

- 🔴 가맹 90% / 직영 10% (플래그십·R&D 점)
- 🔴 부동산 자산화·임대 마진 검토

### 🎯 Service

- 🔴 회원 데이터 기반 영양·습관 코칭 확장
- 🔴 하드웨어 moat (스마트 미러·InBody 자동 연동)
- 🔴 강사 평가·매칭 알고리즘 고도화

## 트랙 간 의존성 (예시)

```
🏢 가맹 모델 결정 (5A)  ──► 📍 가맹점 표준 사이즈 (Phase 2)  ──► 🎯 가맹점 강사 풀 운영
                                                                         ▲
🏢 강사 정산 (3D)  ──────────────────────────────────────────────────────┘
```

- 🏢 결정이 📍·🎯 실행을 가로막을 수 있음
- 📍 입지가 🎯 강사 모집·회원 페르소나에 영향
- 🎯 회원·강사 검증 결과가 🏢 가맹 모델 검토를 트리거

→ Phase 진입 KPI 충족 = 3개 트랙 모두 진전 필요.
