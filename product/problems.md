# 1B. 문제의식

**🟢 Decided** · 의존: [1A 페르소나](./personas.html) → [1C 경쟁](./competition.html), [1D VP](./value-prop.html)

## 회원이 느끼는 5가지 페인

1. **장기결제 강매·환불 먹튀** — 등록하면 먹튀 아닐까 불안. 중도 환불이 사실상 불가.
2. **경직된 스케줄** — 특정 강사·시간에 묶임. 못 가면 손해.
3. **강사 복불복** — 강사가 좋아야 운동이 좋음. 그런데 검증 방법이 없음.
4. **폐쇄적 장기등록** — 일단 끊어야 뭔지 알 수 있음. 탐색·드롭인 불가.
5. **혼자 해서 흐지부지** — 그룹 에너지·사회적 압력이 없으면 혼자선 꾸준히 못 함.

→ 뿌리: **선불 장기약정 + 불투명 구조**. 충전금 + 클래스별 명시 가격 + 오픈 탐색으로 해체.

## 공급 측 환경 (왜 지금)

저가 무인(짐박스 등) ↔ 고가 풀 PT 양극화. **중간 빈자리** = 같이 운동 × 투명 가격 × 약정 없는 드롭인 × 큐레이션 품질.

부티크·소규모 운영 비용 상승, 공실 압박 증가. 강사 입장에서도 홀로 스튜디오 운영 부담 ↑ → 플랫폼에 의존할 유인.

## 우리 솔루션 매핑

| 페인 | 솔루션 |
|---|---|
| 강매·환불 먹튀 | 충전금 모델 + 클래스별 투명 가격 → 강매 구조 자체 제거 |
| 경직된 스케줄 | 드롭인 — 언제든 원하는 클래스 선택 |
| 강사 복불복 | 본사 검증 통과 강사만 클래스 개설 가능 |
| 폐쇄적 등록 | 오픈 탐색 — 충전금 없이도 스케줄 열람·체험 가능 |
| 혼자 흐지부지 | 그룹 클래스 에너지 + 드롭인 습관화 |
