# 6B. 본사 ↔ 가맹점주 R&R

**🟢 Decided** · 의존: [6A 확장 모델](./model.html), [3E 강사 모델](../partners/model.html) → [6C 본사 수익](./revenue-share.html), [3D 모집](../partners/recruitment.html), 가맹 매뉴얼

## 핵심 원칙

> **본사 = Software + Pool / 가맹점주 = Real Estate + Operations**
>
> 가맹점주는 **"동전노래방 관리자"** 같은 가벼운 운영 — 공간 청결·기구 관리·일상 체크인만. 회원·강사·결제·AI 전부 본사가 처리.

## 효과

- 회원·강사·결제·AI = 본사 자산 → **가맹점주·강사 우회 불가**
- 가맹점주 운영 부담 ↓ → 가맹 매력 ↑
- 100호점 일관된 회원 경험 보장
