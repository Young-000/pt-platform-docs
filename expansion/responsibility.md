# 6B. 본사 ↔ 가맹점 R&R

**🟢 v2 봉인 (2026-05-20)** · 의존: [6A 확장 모델](./model.html), [3E 강사 모델](../partners/model.html) → [6C 본사 수익](./revenue-share.html), [3D 모집](../partners/recruitment.html), 가맹 매뉴얼

> **📌 v2 봉인 (2026-05-20)**
>
> - 강사 = Pro Only. **모집·아카데미·등급 평가·정산 = 본사 100%** 책임.
> - 운영·고객 응대·시설 관리 = **가맹점 100%** 책임.
> - 가맹점장 = Pro 자격증 + 본사 아카데미 통과 (시설법 §26 자동 충족).

## 핵심 원칙

> **본사 = Software + Pool + 강사 / 가맹점 = Real Estate + Operations + Frontline CS**
>
> 가맹점은 **"동전노래방 + 카페 매니저"** 같은 가벼운 운영 — 공간 청결·기구 관리·일상 체크인·1차 CS만. 회원·강사·결제·AI·강사 정산 전부 본사가 처리.

## R&R 매트릭스

### 본사 책임

| 영역 | 세부 |
|---|---|
| 강사 모집·평가 | Pro 자격증 보유자 모집·아카데미 운영·등급 P1~P5 평가 |
| 강사 정산 | 회당 고정 정산 (P1 10k ~ P5 18k, 30분 unit). 격주 입금 |
| 회원 가입·결제·CS | 앱·웹 채널. 결제 PG 운영 |
| 회원 DB·운동 데이터 | 본사 소유. 가맹점은 열람만 |
| AI 시스템·본사 프로그램 | 운동 설계·추천 알고리즘·프로그램 카탈로그 |
| 브랜드·전국 마케팅 | 본사 100% (KOL·B2B·구전·광고) |
| 운영 SOP·매뉴얼 | 가맹점 표준 운영 가이드 발급 |
| 강사 매칭 | 본사 풀에서 회원·예약에 자동 매칭 (가맹점 개입 ❌) |

### 가맹점 책임

| 영역 | 세부 |
|---|---|
| 공간 임대 | 호점당 capex 1.5~2억 (외곽 60평) |
| 인테리어·시공 | 본사 가이드 기준 시공 (브랜드 일관성) |
| 일상 운영 | 청소·체크인·기구 점검·소모품 관리 |
| 매니저·알바 인건비 | 가맹점 부담 |
| 시설 안전·기구 관리 | 본사 가이드 + 정기 점검 |
| 지역 마케팅 | 본사 보조 + 가맹점 자율 (지역 광고·전단·이벤트) |
| 1차 CS | 회원 컴플레인 일선 대응 (심각 시 본사 에스컬레이션) |
| 가맹점장 (Pro) | **Pro 자격증 + 본사 아카데미 통과 + 정산 분배 의무** |

### 가맹점장 R&R 상세

| 항목 | 내용 |
|---|---|
| **자격** | **Pro 자격증 (생활스포츠지도사 2급 이상) + 본사 아카데미 통과** — 시설법 §26 자동 충족 |
| 역할 | 시설 안전·청소 감독·CS 1차·강사 출퇴근 관리·비상 대응. 직접 회원 세션 진행 가능 (정산은 강사 등급 P 기준 동일 적용) |
| 고용 형태 | Phase 1 (직영): 본사 직고용. Phase 2+ (가맹): 가맹점 채용 (본사 풀에서 추천) |
| 인건비 | Phase 1: 본사 부담. Phase 2+: 가맹점 부담 |
| 1지점 인원 | 1명 (시설법 최소 요건). 회원 수·운영 시간 따라 알바 추가 |
| 정산 분배 의무 | unit당 마진 17k 중 본사·가맹점 분배 ([6C](./revenue-share.html)) |

## 효과

- 회원·강사·결제·AI = 본사 자산 → **가맹점·강사 우회 불가**
- 가맹점 운영 부담 ↓ → 가맹 매력 ↑
- 100호점 일관된 회원 경험 보장
- 강사가 가맹점에 종속되지 않음 (본사 풀) → 강사 retention 본사 중심
