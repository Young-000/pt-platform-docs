# 6A. 확장 모델 (직영 vs 가맹 vs 하이브리드)

**recoverGX** — 오픈형 GX 그룹 클래스 공간 기반 확장 모델. 참조: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html)

**🟢 v2 봉인 (2026-05-20)** · 의존: [0 비전](../product/vision.html) → [6B R&R](./responsibility.html), [6C 본사 수익](./revenue-share.html), [3D 모집](../partners/recruitment.html), [7C 100호점 추정](../economics/projection.html)

> **📌 v2 봉인 (2026-05-20)**
>
> - 호점당 Capex = **1.5~2억** (외곽 60평·인테리어 1억·GX 기구·보증금 등)
> - 가맹점장 = **Pro 자격 + 본사 아카데미 통과 + 정산 분배 의무**
> - **클러스터 전략**: 3호점 도심·준도심 밀집 (강사 풀 공유·GX 클래스 운영 시너지)

## 하이브리드 단계별

| Phase | 모델 |
|---|---|
| **Phase 1 (1-3호점)** | **100% 직영** — GX PMF 검증, 운영 매뉴얼 정립, 클러스터 형성 |
| **Phase 2 (4-10호점)** | 직영 + 가맹 1-2개 병행 — GX 가맹 시스템 다듬기 |
| **Phase 3 (10-30호점)** | 가맹 70% + 직영 30% — 본격 확장 |
| **Phase 4 (30-100호점)** | 가맹 90% + 직영 10% — 직영은 플래그십·R&D |

## 클러스터 전략 (Phase 1·v2 봉인)

> **3호점 도심·준도심 밀집 배치** — 단일 GX 강사 풀이 3개 지점 순환 가능. 회원이 동선 따라 지점 자유 선택.

| 지점 | 입지 | 특징 |
|---|---|---|
| 1호점 (베타) | 외곽·준도심 평당 10만 | 단위 경제 검증 |
| 2호점 | 준도심 평당 10~15만 | 클러스터 진입 |
| 3호점 | 도심·준도심 평당 15~20만 | 강사 풀 공유·운영 시너지 검증 |

→ Phase 1 종료 시 클러스터 3호점 데이터 → Phase 2 (강남·여의도 등) 진입 판단.

## 가맹점주 요건 (v2 봉인)

| 항목 | 요건 |
|---|---|
| 자격 | **Pro 자격증 (생활스포츠지도사 2급 이상) + 본사 아카데미 통과** |
| Capex | **1.5~2억** (외곽 60평 기준) — 가맹점주 부담 |
| 정산 분배 의무 | 클래스 매출 분배 중 본사 ~60% / 가맹점 ~40% (가설, [6C](./revenue-share.html)에서 봉인) |
| 운영 책임 | 시설 관리·CS 일선·일상 운영 ([6B](./responsibility.html)) |
| GX 강사 관리 | 본사 풀에서 매칭. 가맹점주가 별도 강사 직고용 ❌ |

→ 가맹점장이 자격증 보유자 = 체육시설법 §26 자동 충족 + 본사 SOP 정착.

## 자본 소요 — v2 봉인

| Phase | 호점당 capex | 임대 가정 | BEP 회수 |
|---|---|---|---|
| **Phase 1 (베타·1~3호점)** | **1.5~2억** | 평당 10만 외곽·준도심 (월 600만) | Base 3~4개월 |
| Phase 2 (4~10호점) | 1.5~3억 | 입지 다양화 (외곽~강남) | 입지별 6~14개월 |
| Phase 3+ (가맹) | 가맹점주 부담 1.5~2억 (외곽) ~ 3~4억 (강남) | 가맹점 자율 | 외곽 3~4개월 / 강남 14개월+ |

→ **가맹 확장 매력**: 외곽 모델 capex 1.5~2억 → Base 시나리오 BEP 3~4개월. GX 클러스터 시너지(강사 풀 공유·클래스 밀도)까지 고려 시 더 단축 가능.

## 폐기 옵션

- 100% 직영 ❌ (CapEx 부담 큼)
- 100% 가맹 ❌ (검증 안 된 모델로 모집 어려움)
- 단일 점포 강남 진입 (Phase 1) ❌ (capex 3억·BEP 14개월·검증 위험)

## 추가 가속 옵션

- **기존 헬스장·스튜디오 → 가맹 변환 검토** (Phase 1 가속·GX 강사 모집 인프라 활용)
- Phase 1 클러스터 3호점 형성 후 → 같은 클러스터 내 추가 1~2호점 (강사 풀 공유 효과)
