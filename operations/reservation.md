# 5A. 예약 시스템

**🟢 Decided** · 의존: [4B 세션 포맷](../service/session.html), [4D 공간](../service/space.html), [2B 멤버십](../members/membership.html), [3E 강사 모델](../partners/model.html), [2D 정책](../members/policies.html)

## 예약 단위

회원 1예약 = **카디오 30분 슬롯 + 방 60분 슬롯** 연속 세트. 모든 공간 예약 필수 (워크인 ❌).

## 피크 시간 (6-10pm) — 고정 슬롯제

- **회원**: 매주 같은 요일·시간 고정 슬롯 보유
- **멘토**: 고정 ❌ — 본인이 원할 때 슬롯 자유 오픈
- 일반 예약 ❌ — 고정 회원이 취소한 자리만 풀림

## 고정권 회원의 핵심 권리 — 멘토 연속성

```
1주차: 멘토 A 첫 매칭
2주차: 멘토 A가 그 슬롯 오픈 → 자동 A 매칭 (다른 회원 가로채기 ❌)
3주차: 멘토 A 슬롯 안 오픈 → AI가 다른 멘토 추천
```

## 매칭 방식 (회원 선택)

| 모드 | 흐름 |
|---|---|
| **수동 (default)** | AI 3명 추천 → 회원 선택 |
| **자동 매칭 ON** | AI 자동 매칭 → 회원 24h 이내 거절 가능 (거절 시 재매칭) |

회원 설정에서 자동/수동 전환 가능. Pro 인증 멘토 = 배지 노출, 포인트 차감.

## 비피크 시간

- 자유 예약 (선착순), 14일 전부터 가능
- 모든 회원 동일 시점

## 변경·취소 룰 (오프라인 기준)

| 시점 | 처리 |
|---|---|
| 48h 전까지 | 무료 (회차 미차감) |
| 48h ~ 6h 전 | 회차 차감 + **당일 예약권 1매** |
| 6h 이내 | 회차 100% 차감 (= 노쇼) |
