# 5A. 예약 시스템

**🟡 Updated (2026-05-16)** · 의존: [ADR 0001](../decisions/0001-consumer-pivot.html), [4B 세션 포맷](../service/session.html), [4D 공간](../service/space.html), [2B 멤버십](../members/membership.html), [3E 강사 모델](../partners/model.html), [2D 정책](../members/policies.html)

## 예약 단위

회원 1예약 = **강사 + 프로그램** (30분 unit, 60분 원할 시 2 unit 연속). 룸은 프로그램 속성에 따라 자동 배정 (워크인 ❌).

## 예약 흐름 (v2)

```
1. 회원이 코스 카테고리 선택 (스트레칭·필라테스·1:1 PT·자유 헬스 등)
2. 가용 강사·시간 슬롯 검색
3. 강사 + 시작 시각 + 30/60분 선택
4. (Pro 강사면) +5,000원 포인트 차감 안내
5. 결제(회차 차감) → 룸/오픈 공간 자동 배정 → 예약 확정
```

## 피크 시간 (6-10pm) — 강사·슬롯 자유 검색

- **회원**: 매번 **강사 + 프로그램을 직접 선택** (이전 강사 반복도 자유)
- **멘토**: 본인이 원할 때 슬롯 자유 오픈 (배달기사 모델)
- 인기 슬롯은 선착순.
- Pro 인증 멘토 = 배지 노출, 회당 +5,000원 포인트.

> **v2 결정**: 자동 매칭(AI 추천 → 회원 거절 가능) 흐름은 폐기. 회원이 강사·프로그램을 직접 선택하는 단일 흐름. Phase 2+ 데이터 축적 후 추천 보조(랭킹·추천 슬롯)는 별도 검토.

## 비피크 시간

- 자유 예약 (선착순), 14일 전부터 가능
- 모든 회원 동일 시점

## 변경·취소 룰 (오프라인 기준)

| 시점 | 처리 |
|---|---|
| 48h 전까지 | 무료 (회차 미차감) |
| 48h ~ 6h 전 | 회차 차감 + **당일 예약권 1매** |
| 6h 이내 | 회차 100% 차감 (= 노쇼) |
