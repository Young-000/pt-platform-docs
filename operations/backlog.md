# 5H. 작업 백로그 — recoverGX 모델 기준

> 신규 모델(**지갑 충전금 + 클래스별 차감 + 강사 오픈마켓 개설 + 어드민 큐레이션 + 조합형 정산**)을 도메인별로 펼친 "해야 할 일" 보드. 상태: ✅ 완료 · 🟡 부분 · 🔴 미착수.
> 전략 로드맵 = [1D 로드맵](../product/roadmap.html) · 런칭 일정·예산 = [5F](./launch-plan.html) · 분담 = [5G](./rnr.html). 인프라 상세는 repo `docs/ops/2026-06-04-infra-audit.md`(비공개).
> 기준일 2026-06-05.

## 1. 회원 앱 (충전금·드롭인)

- ✅ 지갑 충전 (충전패키지 선택, 멱등 처리)
- ✅ GX 클래스 탐색·시간표 (카테고리 필터)
- ✅ 드롭인 예약 (좌석 원자 점유 + 충전금 차감)
- ✅ 예약 취소·환불 (시작 6h 전 전액 / 이내 0, 좌석 복구)
- ✅ 예약 내역 (취소 후 재예약)
- ✅ 로그인·회원가입 (토큰 매핑·비번 정책 수정 완료)
- 🟡 체크인 흐름 — GX 드롭인 기준으로 점검 필요
- 🔴 디자인 모노크롬 내부 화면 적용 (클래스 카드·지갑·예약·시간표)
- 🔴 실 PG 충전 연동 (현재 mock)

## 2. 강사 앱 (오픈마켓)

- ✅ 클래스 개설 (본인 명의·카테고리·가격·정원)
- ✅ 내 시간표·예약 현황
- ✅ 출석 체크 (attended/no_show)
- ✅ 폐강 (전원 환불, claim-then-read)
- ✅ 정산 조회 (조합형 결과·클래스명)
- ✅ 로그인 (accessToken 매핑·mentor 역할 허용 수정)
- 🔴 **강사 자가 신청·온보딩 플로우 (앱 기능 부분오픈)** — 오픈마켓 공급 진입점
- 🔴 디자인 모노크롬 내부 화면 + 워드마크 통일

## 3. 어드민 앱 (큐레이션)

- ✅ 어드민 로그인 (API 인증 + 토큰 매핑)
- ✅ 카테고리 룰 입력
- ✅ 가격 범위 정책 (GxPolicy, 환불 마감 포함)
- ✅ 충전패키지 관리
- ✅ 정산정책 관리 (조합형: 기본+인당+비율)
- ✅ 강사 GX 개설 권한 부여·정책 할당 (gxOpenEnabled)
- 🔴 **강사 심사 큐 실구현** (현재 placeholder) — 신청 검토·승인/반려
- 🟡 운영 모니터링 대시보드 (cron·알림·감사 — 기존 자산 점검·정합)
- 🔴 디자인 모노크롬 + 워드마크 통일

## 4. 결제·정산 (백엔드)

- ✅ 지갑/충전 거래 (idempotencyKey DB unique — 이중 적립 차단)
- ✅ 클래스별 차감 (잔액 가드, 음수 불가)
- ✅ 환불 정책 로직 (경계 6h 정확)
- ✅ 조합형 정산 계산 + 완료 시 정책 스냅샷(불변)
- ✅ 예약 취소 원자화 (동시 요청 이중 환불 차단)
- 🔴 예약 멱등성 DB 레벨 보강 (멀티 인스턴스 대비)
- 🔴 refresh 토큰 블랙리스트 영속화 (현재 인메모리)
- 🔴 정산 매출 모수 정책 결정 (미출석 예약 포함 여부)
- 🔴 실 PG(토스/포트원) 연동 + webhook 서명 검증

## 5. 디자인·브랜드 (recoverGX 모노크롬)

- ✅ 디자인 시스템 v1.0 확정 (순수 모노크롬 에디토리얼, recover DNA)
- ✅ 3앱 토큰 적용 (CSS 변수) + prod 배포
- ✅ 회원앱 로그인/가입 워드마크 `RECOVER GX`
- 🔴 강사·어드민 워드마크·카피 통일
- 🔴 내부 화면 리스킨 (3앱 핵심 화면)
- 🔴 공통 컴포넌트(pill 버튼 등) + 토큰 단일 소스화(@pt/ui)

## 6. 인프라·배포 (recover 계정 격리)

- 🔴 **API 컴퓨트 복구** — 삭제된 로드밸런서 재생성 + 현행 이미지 빌드·배포 (로그인 불가 해결)
- 🔴 프론트 API 주소 교체·재배포 후 로그인 검증
- 🟡 DB·인프라 recover 계정 격리 확인 (컨설팅 클라이언트 계정과 분리)
- 🔴 재배포 스크립트/IaC 코드화 + 배포 권한(IAM) 정리 + 문서 최신화
