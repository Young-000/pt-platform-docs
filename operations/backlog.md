현재 회원·강사·어드민 3앱이 **로그인 안 됨**: 백엔드 API 컴퓨트(로드밸런서)가 삭제돼 프론트가 죽은 주소를 가리킴. **데이터(DB)는 생존.** 상세·계정 정보는 repo `docs/ops/2026-06-04-infra-audit.md`(비공개) 참조.

- [ ] recover 계정의 API 서비스 상태 점검 (서비스 정의 잔존, 로드밸런서 삭제 확인됨)
- [ ] 삭제된 로드밸런서 재생성 + 타깃 그룹·리스너 + 서비스 연결
- [ ] **현행 코드로 API 이미지 새로 빌드·푸시** (현 이미지는 recoverGX 전 버전, 4월자)
- [ ] 태스크 정의 갱신 → 서비스 재배포 → 헬스체크 통과
- [ ] 프론트 3앱 API 주소(rewrite)를 새 엔드포인트로 교체 → 재배포 → **로그인 복구 검증**
- [ ] DB 소유 계정·격리 확인 (recoverGX 인프라는 recover 계정 단독 — 컨설팅 클라이언트 계정과 분리)
