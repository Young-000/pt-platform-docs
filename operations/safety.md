# 5C. 안전 · 보험 · 사고 대응 SOP

**🟢 확정 (2026-06-04)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [6B R&R](../expansion/responsibility.html), [3F 일반 멘토](../partners/peer-leader.html), [8B PT 자격증법](../legal/pt-license.html), [5B 지점 운영](./store.html), [5D 자유 헬스](./free-gym.html)

> 1호점 베타 OPEN 시점 안전 SOP. 변호사 자문(약관·면책동의) 및 보험사 협의(한도) 결과로 일부 수치 갱신 예정.

---

## 1. 사고 분류

| 등급 | 정의 | 1차 대응 | 보고 |
|---|---|---|---|
| 경미 | 가벼운 타박·찰과상, 자가 회복 가능 | 가맹점장 응급처치 + 기록 | 24h 내 본사 보고 |
| 중대 | 부상 후 운동 중단·병원 이송 필요 | 가맹점장 응급 + 119 호출 + 보호자 통보 | 즉시 본사 보고 (전화) |
| 응급 | 심정지·실신·중증 외상 | CPR / AED + 119 즉시 + 가맹점장 동행 | 즉시 본사 보고 (전화) |

## 2. 응급 대응 절차

### 2.1 심정지 / 실신
1. 의식·호흡 확인 (10초 이내)
2. 119 신고 + AED 즉시 가져옴
3. CPR 시작 (가슴 압박 30:2 호흡, 분당 100-120회)
4. AED 도착 시 패드 부착 → 안내 음성 따름
5. 119 도착까지 지속

### 2.2 응급 외 사고
1. 환자 안정 · 안전 위치 이동
2. 부상 부위 확인 → 응급처치 (RICE: Rest · Ice · Compression · Elevation)
3. 필요 시 119 또는 자가 병원 이송
4. `IncidentReport` 작성 (admin UI · 사진 첨부)

## 3. 그룹 클래스 정원 안전

- 정원(capacity)은 룸 면적·기구 간격 기준으로 admin에서 확정
- 정원 초과 입장 불가 (예약 시 `bookedCount < capacity` 가드)
- 강사는 클래스 시작 전 출석 인원과 예약 명단 대조 의무
- 정원 기준 미달 폐강 시 강사 + 가맹점장이 동시에 알림 수신

## 4. CCTV 모니터링 · 녹화 보관

- 전체 공간 (룸·오픈·복도·게이트): 24h 녹화
- 락커룸 · 화장실 : 미설치 (사생활)
- 녹화 보관: **90일** (분쟁 대비). 사고 발생 건은 별도 archive 보관.
- 가맹점장 실시간 모니터링 (모바일 알림 — 비상벨·단독 입장 등)
- 정책 변수: `safety.cctv_retention_days` (기본 90)

## 5. 회원 면책동의

- **가입 시**: 약관 + 면책동의 modal 노출 → 동의 시 `MemberAgreement` 레코드 생성 (서명 timestamp 보관)
- **첫 자유 헬스 입장 시**: 안전 가이드 영상 시청 + 별도 동의 ([5D §3](./free-gym.html))
- 동의 항목 (변호사 자문 final 반영 예정):
  - 자신의 건강 상태에 대한 책임
  - 시설 사용 중 자기 과실 부상에 대한 면책
  - CCTV 녹화 동의
  - 응급 시 119 호출 및 의료 정보 공유 동의

## 6. 본사 배상보험 (가맹점장 책임 분리)

- **본사 가입**: 시설배상책임보험 (전 지점 일괄)
  - 대인 한도: 1억 / 1인 (보험사 협의 후 확정)
  - 대물 한도: 5천만 / 사고
- **가맹점장**: 자격증 기반 시설법상 책임자 — 시설법 위반 시 1차 책임. 본사가 법무 지원.
- **강사 (GX 클래스)**: 별도 강사 책임보험 가입 권장 (Pro 옵션 가입 조건에 포함 검토)
- 보험 청구 · 사고 처리는 본사 CS가 일괄 대행.

## 7. 자유 헬스 비상 호출 버튼

- **설치 위치**: 룸 4개 코너 · 오픈 공간 4개 · 락커룸 입구 · 게이트 (총 10개)
- **연동**: 누르면 (1) 가맹점장 모바일 (2) 본사 CS (3) 119 자동 알림 ([5D §4](./free-gym.html))
- **테스트 주기**: 월 1회 가맹점장이 전 버튼 작동 테스트 → `EquipmentCheck` 기록
- **단독 입장 자동 알림**: 무인 시간대 1명만 입장 시 가맹점장 모바일 알림 (CCTV 인원 카운트 기반)
