# 2026-05-20 — Pro Only 피벗 + 3변수 단위 경제 모델 일괄 봉인

5/19~20 리서치 결과 (Super Monkey 위기 사례 · 1:1 PT 단골 통계 · 도심 vs 외곽 입지 단위 경제) → ADR 8개 일괄 봉인.

## 배경 — 리서치 3축 요약

### 1. Super Monkey 2024 위기 사례
- 중국 부티크 피트니스 1위 (Super Monkey · 超猩练) 가 2024 강사 정산 단가를 일방적으로 인하.
- 결과: 우수 강사 이탈 → 회원 NPS 폭락 → 매출 8개월 연속 감소.
- 교훈: **강사 단가·등급 변동은 사전 공지 + 일관된 KPI 기준** 만 사용. 임계 일방 인상·인하 ❌.
- 마케팅 패턴: 광고 ❌, 강사 SNS KOL + 임직원 채널 + 구전 중심으로 6개월 회원 ≥ 500 달성.

### 2. 1:1 PT 단골 통계
- LTV·재예약률의 1순위 함수 = 강사 신뢰.
- 자격증 없는 강사 풀에서 회원 retention 평균 0.7배.
- 광고 유입 회원 retention 0.7배 (자연 유입 대비).
- 신규 유입 50%+ 가 구전·강사 채널.
- → **자격증 강제 + KOL 채널 + 회원 retention 함수와 정렬된 강사 등급제** 가 단위 경제 우월.

### 3. 도심 입지 단위 경제 재검토
- ADR 0006 의 베타 1호점 = 평당 10만 외곽 입지 (강남 평당 35만 vs 베타 10만) — 유지.
- 추가 분석: capex 1억 가정이 인테리어 비반영 → **1.5~2억으로 상향 필요**.
- 60평 capacity = 동시 12명 · 시간당 24 unit · 시간당 고정비 62k.
- BEP utilization = 18.7% (capex 상각 포함) — 베타 D+30 U 20%만 넘어도 흑자.

## 3변수 단위 경제 핵심 공식

```
시간당 본사 마진 = 24 × U × 17,000
시간당 본사 순익 = 시간당 본사 마진 − 62,000 (고정비)

BEP util:
  운영      U = 62,000 / 408,000 = 15.2%
  Capex 포함 U = 76,500 / 408,000 = 18.7%
```
