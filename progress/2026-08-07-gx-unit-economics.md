# 2026-08-07 — GX 단위 경제 최종 설계

창업가 결정 반영 세션. 무인 운영·하이브리드 정산을 확정하고 지점 P&L을 전면 재산출. [ADR 0012](../decisions/0012-gx-unit-economics.html) 봉인.

## 배경

- ADR 0011(GX 피벗) 이후 단위 경제가 "유인 운영 + 등급별 회당 정액" 가정으로 남아 있었음.
- 슈퍼몽키 벤치마크(무인 자동관리·CCTV 평审) 재검토로 **운영 인력 0 전환**이 경제적으로 성립함을 확인.
- 구판 P&L의 가장 큰 오차 원인인 인건비(월 700만+)를 제거하고 신규 수치로 재산출.

## 결정 (ADR 0012)

1. **무인 운영 확정** — 상주 매니저·CS 없음. 강사 3명이 수업+현장 겸임. 출입·체크인·결제·CS 1차는 자동화.
2. **정산 하이브리드 확정** — `최소보장 25,000원 + 인당 1,500원 × 출석`. 등급 밴드: P1 22k ~ P5 28k (기준 P3 25k). 구판 "등급별 회당 정액" 폐기.
3. **입구 티어(9,900원 등) 경제 이관** — 획득 마케팅 도구로 분류. 단위 경제는 4티어 통일가(15/19/26/34k) 믹스 기준.

## 재산출 요약

| 항목 | 구판 | v2(무인) |
|---|---|---|
| 월 고정비 | ~2,200만 | 1,310만 |
| 콜드스타트 월 적자 | −920만 | **−330만** |
| 상각 전 BEP | U ~40% | U ~26% |
| 런웨이 (6개월) | ~5,500만 | ~2,000만 |
| CapEx+런웨이 총 | ~1.95억 | **1.65억** |

- base 시나리오(U 55%) 월 손익: **+3,410만** (상각 포함)
- 실질 회수 기간: 개점 기준 **12~18개월**이 현실적 기대치

## 무인 전제 조건 (제품에 거는 요구)

경제 수치는 아래 자동화가 **플랫폼에 존재**해야 성립:

1. 무인 출입·체크인 (도어락 + 앱 QR 체크인)
2. 예약·결제·환불 전자동 (기구현: 지갑·6h 컷오프)
3. CS 1차 자동화 (앱 내 FAQ·챗) + 이슈만 본사 에스컬레이션
4. CCTV 원격 관제 + 수업 품질 원격 평가
5. 수업 후 단체사진 자동 발행 (입소문 의례 제품화)

→ 상세: `pt-platform/docs/benchmark/2026-08-07-supermonkey-app-must-copy.md`

## 확장 게이트

- **렌트 15% 게이트**: 임대료 ÷ 월매출 ≤ 15% 검증 전 2호점 금지. 실측 U_정원 ≥ 45%가 2호점 조건.

## 잔여 확인 (창업가)

- **① 정원 상한 종목별 차등**: 런치 카탈로그안(12~20) 유지, 룸 실측 후 고정.
- **② 렌트 15% 게이트**: 채택 권고 — 2호점 확장의 정지 조건으로 차용.

## 리스크

1. U_정원 55%는 실측 전 가정 — base를 사실처럼 인용 금지.
2. 무인의 숨은 비용(사고·클레임·파손) — 개점 후 3개월 실측 재검증.
3. 충전금 규제(선불전자지급수단) — 별도 트랙 유지.
4. 강사 3명 체제의 취약성 — 파트 강사 풀을 콜드스타트부터 확보.
5. 슈퍼몽키 2024~25 폐점·降薪 보도 — 낙관 시나리오 계획 기준 사용 금지.
