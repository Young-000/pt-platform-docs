# 2026-08-07 — GX 단위 경제 최종 설계

창업가 결정 반영: 무인 운영 확정 · 하이브리드 정산 확정 · 입구 티어를 단위 경제 외로 이관. [ADR 0012](../decisions/0012-gx-unit-economics.html) 봉인.

## 배경

- GX 피벗(ADR 0011) 이후 단위 경제 재산출 필요 — 1:1 PT 레일 가정(매니저 상주·인건비 700만)을 GX 레일로 교체.
- 슈퍼몽키 벤치마크(무인 컨테이너 자동관리 `Sream` 사례·全교실 CCTV 원격 품질 평審)에서 **무인 운영 가능성** 확인 → 단위 경제에 반영.
- 선행 ADR 0010(3변수 프레임: 정원·클래스수·출석)의 프레임을 승계, 수치를 GX 조건으로 전면 재산출.

## 결정 요지 (ADR 0012)

1. **무인 운영** — 상주 매니저 없음. 강사 3명이 수업+현장 겸임. 출입·체크인·결제·CS 1차는 자동화(플랫폼 기능).
2. **정산 = 하이브리드** — `최소보장 25,000원 + 인당 1,500원 × 출석` (P1 22k ~ P5 28k 등급 밴드).
3. **입구 티어(9,900원 등)는 단위 경제 사항 아님** — 마케팅 획득 도구로 이관. 경제 계산은 4티어 통일가(15/19/26/34k) 믹스.

## 주요 수치 (지점 P&L)

| 시나리오 | 월 손익(상각 포함) | 임대비율 |
|---|---|---|
| 콜드스타트 (U 25%) | −330만 | 29.7% |
| 보수 (U 40%) | +1,150만 | 15.9% |
| **base (U 55%)** | **+3,410만** | 9.3% ✅ |
| 낙관 (U 70%) | +6,310만 | 6.1% ✅ |

- 월 고정비: 1,310만 (구판 2,200만 → 무인 전환 인건비 700만 제거)
- CapEx: 1.45억 (60개월 상각 = 월 242만)
- base 기준 원금 회수: **CapEx+런웨이 4.5개월** (공헌 기준)
- Sanity 앵커: base 연매출 7.78억 ≈ 슈퍼몽키 단일매장 실측 연 ~7.1억 [검증]

## 경제가 제품에 거는 요구

무인 고정비 1,310만은 다음 5개 기능이 제품에 존재해야 성립:
1. 무인 출입·체크인 (도어락 + 앱 QR)
2. 예약·결제·환불 전자동
3. CS 1차 자동화 (앱 내 FAQ·챗)
4. CCTV 원격 관제 + 수업 품질 원격 평가
5. 수업 후 단체사진 자동 발행

→ 상세 기능 차용 목록: `pt-platform/docs/benchmark/2026-08-07-supermonkey-app-must-copy.md`
