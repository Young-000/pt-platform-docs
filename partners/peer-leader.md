# 3F. GX 개설 권한 검증 (gxOpenEnabled · P1~P5)

**🟢 v3 (recoverGX 피벗)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [ADR 0007](../decisions/0007-trainer-model.html) 승계, [4A 세션 종류](../service/session-types.html), [4C AI](../service/ai-role.html), [8B 자격증법](../legal/pt-license.html) → [3G 정산](./payout.html), [3D 모집](./recruitment.html), [3I 아카데미](./verification-course.html)

> **📌 recoverGX 개설 권한 검증 (v3)**
>
> 강사가 GX 클래스를 개설하려면 어드민이 `gxOpenEnabled` 권한을 부여해야 한다.
>
> **모든 강사 = Pro** = 자격증 보유 (생활스포츠지도사 2급 이상) + **본사 아카데미 통과**. 이후 등급 P1~P5 부여.
> `gxOpenEnabled` 부여 = 어드민 검증 완료 신호. 초기(Phase 1)는 어드민이 직접 부여. Phase 3+에서 등급 P3+ 강사에게 자동 부여 확대 예정.
>
> 고용 형태 = **전속·프리랜서 자유**. 본사가 선택권 보유.

## 자격 요건 (단일)

- **자격증 필수**: 생활스포츠지도사 2급 이상 (또는 동등 — 운동처방사·전문 트레이너 자격증)
- **본사 아카데미 통과 필수**: 4 모듈 (사업·안전·AI·CS) — [3I 아카데미](./verification-course.html)
- 자격증법 회피용 "멘토" 호칭 + 운동 설계 = AI 원칙 동일 적용

## 강사 등급 P1~P5 (ADR 0007 승계)

[ADR 0007](../decisions/0007-trainer-model.html) P1~P5 등급 기준을 승계. GX 모델에서는 등급이 **조합형 정산 기본금 기준선** + **`gxOpenEnabled` 자동 부여 기준**으로 활용.

| 등급 | 호칭 | 기본금 기준선 (30분) | 자격 | gxOpenEnabled |
|---|---|---|---|---|
| **P1** | 신입 Pro | 10,000원 | 자격증 + 아카데미 통과 (첫 분기) | 어드민 수동 부여 |
| **P2** | 검증 Pro | 12,000원 | 출석률·NPS·기록 입력률 기준 | 어드민 수동 부여 |
| **P3** | 시니어 Pro | 14,000원 | 재예약률 ↑ + 분기 KPI 통과 | Phase 3+: 자동 부여 |
| **P4** | 전문 Pro | 16,000원 | 클래스 만족도 상위 20% | Phase 3+: 자동 부여 |
| **P5** | 마스터 Pro | 18,000원 | 클래스 만족도 상위 5% + 본사 추천 | Phase 3+: 자동 부여 |

## gxOpenEnabled 부여·회수 프로세스

```
아카데미 통과 (P1 신입 Pro)
    │
    ▼
어드민이 gxOpenEnabled = true 부여 (검토 후 수동)
    │
    ▼
강사 앱에서 GX 클래스 개설 가능 (지점·룸·카테고리·시간·정원·가격 범위 내)
    │
    ▼
분기 평가 → 등급 승급 (P1 → P2 → … → P5)
    │
    └── Phase 3+: P3 도달 시 gxOpenEnabled 자동 부여 범위 확대
```

**회수 조건**: 클래스 품질 기준 미달 (출석률·NPS 지속 하락) 또는 정책 위반 시 어드민이 `gxOpenEnabled = false` 처리.

## 등급 변동 (분기 1회, ADR 0007 승계)

| 평가 변수 | 가중 | 비고 |
|---|---|---|
| 클래스 출석률 | 25% | 정원 대비 실 출석 비율 |
| NPS | 20% | 회원 평점 (1~5점) |
| 재방문율 | 20% | 동일 강사 클래스 재예약률 |
| 기록 입력률 | 20% | 5분 SOP 준수율 |
| 재수강률 | 15% | 같은 강사 클래스 재등록 비율 |

→ 분기마다 자동 산출 → 본사 심사 → 등급 ±1 단계 조정.

## 고용 형태 (전속 ↔ 프리랜서 자유)

| 형태 | 특징 | 본사 판단 |
|---|---|---|
| **전속 (정규직)** | 본사 4대보험·고정급 + 조합형 정산 인센티브 | 고급 등급 P4~P5 |
| **프리랜서** | 조합형 정산만, 자유 일정 | 일반 등급 P1~P3 |

- 본사가 고용 형태 선택권 보유.
- 프리랜서도 동일 등급 기준선 적용. 4대보험·복지 차이만 존재.

## 자격증법·체육시설법 준수

- **자격증 보유자만 모집** → 자격증법 회피 부담 ↓ (시설법 §26 시설 단위 의무도 자동 충족)
- 운동 설계 = AI (개별 강사가 처방·치료 표현 ❌ 기조 유지)
- "멘토·코치" 호칭 정책은 그대로 (ADR 0002 §3)

## 폐기된 모델

- "S1 파트타이머 (자격증 ❌) / S2 전문 강사" 2풀 하이브리드 → 모든 강사 = Pro 통일 (v2 봉인)
- "일반 멘토 → Pro 승격 경로" → 처음부터 Pro Only (v2 봉인)
- 1:1 PT 슬롯 오픈 모델 → GX 클래스 개설 모델 (recoverGX 피벗, ADR 0011)
