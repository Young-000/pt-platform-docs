# 3E. 강사 운영 모델 (Hybrid)

**🟢 Decided** · 의존: [ADR 0001](../decisions/0001-consumer-pivot.html), [ADR 0002](../decisions/0002-license-policy.html), [0 비전](../product/vision.html), [3A 페르소나](./personas.html), [4A 세션 종류](../service/session-types.html) → [3D 모집](./recruitment.html), [3G 정산](./payout.html), [3H 등급](./quality.html), [5A 예약](../operations/reservation.html)

## 공통 (모든 Phase)

- **프리랜서 계약** (직고용 ❌)
- **본사가 마케팅·예약·결제·CS·세금 전부 대행**
- **회당 정산 + 등급 보너스** + Pro 인증 시 **단가 자율**
- **슬롯 자유 오픈** (배달기사형)

## Phase별 진화

| Phase | 모델 | 강사 수/지점 | 의무 슬롯 |
|---|---|---|---|
| **Phase 1 (1-3호점, PMF 검증)** | 본사 헤드헌팅 코어 12명 | 12명 | 강함 (피크 시간) |
| **Phase 2 (4호점+)** | 검증 통과자 자율 가입 시작 + 코어 의무 일부 유지 | 20+명 / 자율 | 약함 |
| **Phase 3 (10호점+)** | 완전 자동 onboarding, 등급별 차등 | 가맹점 자율 | 등급별 |

## 폐기 옵션

- 완전 직고용/풀타임 — 인건비·100호점 확장 불가
- 완전 자유 gig — Phase 1엔 품질 통제 어려움

→ Hybrid가 100호점 비전과 사실상 유일 양립.
