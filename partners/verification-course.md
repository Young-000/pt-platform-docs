# 3I. 본사 아카데미 (Pro 전속 강사 양성)

**🟢 v2 봉인 (2026-05-20)** · 의존: [0002 자격증 정책](../decisions/0002-license-policy.html), [3F 강사 등급](./peer-leader.html), [3D 모집](./recruitment.html) → [3H 품질 관리](./quality.html)

> **📌 v2 봉인 (2026-05-20)**
>
> "검증 코스 → 일반 멘토" 흐름은 폐기. 본 문서는 **본사 아카데미** = **Pro 자격증 보유자**를 본사 표준 강사로 양성하는 SOP.
>
> 모든 강사 = Pro = 자격증 보유 + 본사 아카데미 통과. 일반 멘토 트랙 ❌.

## 목적

1. 자격증 보유자에게 **본사 표준 SOP** (운동 설계 = AI · 5분 기록 SOP · 회원 데이터 관리) 내재화
2. 자격증법·의료법 회피 안전판 — "처방·치료·진단" 금기 표현, AI 가이드 준수 기조
3. 본사·가맹점 어디 배치되어도 동일 회원 경험 보장
4. 등급 P1 부여 (아카데미 통과 = P1 신입 Pro 등급 자동 부여)

## 코스 구성 (4 모듈, 약 8시간)

| # | 모듈 | 시간 | 목적 |
|---|---|---|---|
| 1 | 사업 이해 + 정책 | 1h | 우리 컨셉·강사 역할·운동 설계는 AI라는 원칙·금기 표현 |
| 2 | 본사 프로그램·안전 | 2h | 본사 8 프로그램 숙지 + 부상 위험·응급 대응 (이미 자격증으로 검증됨, 본사 표준만 학습) |
| 3 | AI 가이드 실습 | 3h | 회원 데이터 읽기 · AI 추천 해석 · **5분 기록 SOP** 실습 |
| 4 | CS·UX | 1h | 회원 응대·매너·인계 메모·등급 변동 변수 이해 |

## 평가 기준

| 평가 | 기준 | 가중 |
|---|---|---|
| 모듈별 퀴즈 (객관식) | 모듈마다 80% 이상 통과 | 필수 |
| 실습 영상 제출 (모듈 3) | 본사 평가 5점 만점 중 **3.5 이상** | 필수 |
| 최종 면담 (15분) | 본사 SOP 이해도·금기 표현 회피·5분 기록 SOP 숙지도 | 통과/불통과 |

**탈락 시**
- 1회 재시험 가능 (불합격 모듈만 재이수)
- 2회 탈락 시 → **6개월 후 재신청** 가능

## 비용

- **본사 부담** (강사 무료) — 자격증 보유자 모집 인센티브
- 본사 1인당 비용 ≈ **30만원** (교육 인건비 + 자료비)
- → 공급 측 락인 투자 (Pro 풀 확보 + 본사 SOP 정착)

## 운영 흐름

```
[3D 모집] 자격증 보유자 신청서 접수
            │
            ▼
        본사 아카데미 등록 (모듈 1~4, 약 8h)
            │
            ▼
        퀴즈 + 실습 영상 + 최종 면담
            │
       ┌────┴────┐
       ▼         ▼
     통과     탈락
       │       │
       │       ├─ 1회 재시험
       │       └─ 2회 탈락 시 6개월 대기
       ▼
   등급 P1 부여 (신입 Pro)
       │
       ▼
   활성 강사 (앱 노출·예약 가능)
       │
       ▼
   분기 평가 → P1 → P2~P5 승급 ([3F](./peer-leader.html))
```

## 강사 앱 UI 권고

- 강사 가입 후 **아카데미 탭**에서 모듈 진행률·퀴즈 응시·영상 업로드·면담 예약 일괄 관리
- 통과 시 프로필에 **"Pro 인증 (P1)"** 자동 부여 → 회원 앱에서 신뢰 시그널로 노출

## 회원 앱 신뢰 시그널

- 모든 강사 카드에 **"Pro 인증"** 표시 (자격증 + 본사 아카데미 통과 사실)
- 회원 페이지 FAQ에 "강사 양성 과정" 항목 → 본 문서 요약 링크
