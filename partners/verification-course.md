# 3I. 멘토 검증 코스 (본사 자체 검증 SOP)

**🟢 New (2026-05-16)** · 의존: [0002 자격증 정책](../decisions/0002-license-policy.html), [3F 일반 멘토](./peer-leader.html), [3D 모집](./recruitment.html) → [3H 품질 관리](./quality.html)

> [ADR 0002](../decisions/0002-license-policy.html)에서 "일반 멘토 자격증 ❌ + 본사 검증 코스 통과 필수"로 결정. 본 문서는 그 검증 코스의 운영 SOP.

## 목적

1. 자격증 없는 일반 멘토가 회원에게 **안전·기본 서비스**를 제공할 수 있는지 검증
2. 자격증법·의료법 회피의 **안전판** — "처방·치료·진단" 금기 표현, AI 가이드 준수 기조 내재화
3. 법안 변화 시 (자격증 의무화) **admin 정책 토글**로 즉시 강화 가능한 형태로 설계

## 코스 구성 (4 모듈, 약 8시간)

| # | 모듈 | 시간 | 목적 |
|---|---|---|---|
| 1 | 사업 이해 + 정책 | 1h | 우리 컨셉·멘토 역할·운동 설계는 AI라는 원칙·금기 표현 ("처방"·"치료"·"진단" ❌) |
| 2 | 기초 운동 안전 | 2h | 부상 위험 자세, 응급 대응 (심정지·실신·갑상선·당뇨 등) |
| 3 | AI 가이드 실습 | 3h | 회원 데이터 읽기 · AI 추천 해석 · 자세 교정 가이드 따라하기 |
| 4 | CS·UX | 1h | 회원 응대·매너·5분 SLA 기록 입력·인계 메모 |

## 평가 기준

| 평가 | 기준 | 가중 |
|---|---|---|
| 모듈별 퀴즈 (객관식) | 모듈마다 80% 이상 통과 | 필수 |
| 실습 영상 제출 (모듈 3) | 본사 평가 5점 만점 중 **3.5 이상** | 필수 |
| 최종 면담 (15분) | 멘토 역할 이해도·태도·금기 표현 회피 검증 | 통과/불통과 |

**탈락 시**
- 1회 재시험 가능 (불합격 모듈만 재이수)
- 2회 탈락 시 → **6개월 후 재신청** 가능

## 비용

- **본사 부담** (멘토 무료)
- 본사 1인당 비용 ≈ **30만원** (강사 인건비 + 자료비 추정)
- → 회원 풀 확보를 위한 공급 측 투자로 간주

## 운영 흐름

```
[3D 모집] → 신청서 접수
            │
            ▼
        검증 코스 등록 (모듈 1~4, 약 8h)
            │
            ▼
        퀴즈 + 실습 영상 + 최종 면담
            │
       ┌────┴────┐
       ▼         ▼
     통과     탈락
       │       │
       │       ├─ 1회 재시험
       │       └─ 2회 탈락 시 6개월 대기
       ▼
   "검증 완료" 뱃지 부여
       │
       ▼
   활성 멘토 (앱 노출·예약 가능)
```

## 멘토 앱 UI 권고

- 멘토 가입 후 **검증 코스 탭**에서 모듈 진행률·퀴즈 응시·영상 업로드·면담 예약 일괄 관리
- 통과 시 프로필에 **"검증 완료" 뱃지** 자동 부여 → 회원 앱에서 신뢰 시그널로 노출
- 자격증 보유자는 별도 **"자격증 보유" 뱃지** 병행 노출

## 회원 앱 신뢰 시그널

- 멘토 카드에 **"본사 검증 완료"** 표시 (Pro 인증자는 추가 뱃지)
- 회원 페이지 FAQ에 "우리 멘토는 어떻게 검증되나요?" 항목 → 본 문서 요약 링크

## 정책 토글 연결 (ADR 0002)

| 토글 변수 | 검증 코스에 미치는 영향 |
|---|---|
| `mentor.require_license_general = true` | 검증 코스 + 자격증 모두 요구 (코스 폐지 ❌, 보완 관계 유지) |
| `mentor.license_grace_period_days > 0` | 기존 검증 멘토에게 자격증 취득 유예 기간 부여 |

법안 변화 시 코스 자체는 유지 (안전·CS 모듈은 자격증과 무관하게 가치 있음).
