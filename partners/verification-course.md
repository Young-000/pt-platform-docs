# 3I. 본사 아카데미 (Pro GX 강사 양성 SOP)

**🟢 v3 (recoverGX 피벗)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [ADR 0002 자격증 정책](../decisions/0002-license-policy.html), [3F 개설 권한](./peer-leader.html), [3D 모집](./recruitment.html) → [3H 품질 관리](./quality.html)

> **📌 v3 (recoverGX 피벗)**
>
> 본 문서는 **본사 아카데미** = **Pro 자격증 보유자**를 recoverGX 표준 GX 강사로 양성하는 SOP.
>
> 모든 강사 = Pro = 자격증 보유 + 본사 아카데미 통과. 아카데미 통과 → 등급 P1 자동 부여 → 어드민이 `gxOpenEnabled` 부여 → GX 클래스 개설 가능.

## 목적

1. 자격증 보유자에게 **본사 표준 SOP** (GX 클래스 운영 · AI 가이드 준수 · 5분 기록 SOP · 회원 데이터 관리) 내재화
2. 자격증법·의료법 회피 안전판 — "처방·치료·진단" 금기 표현, AI 가이드 준수 기조
3. 어느 지점에서 GX 클래스를 개설해도 동일 회원 경험 보장
4. 등급 P1 부여 (아카데미 통과 = P1 신입 Pro 등급 자동 부여) + `gxOpenEnabled` 부여 전제 조건 충족

## 코스 구성 (4 모듈, 약 8시간)

| # | 모듈 | 시간 | 목적 |
|---|---|---|---|
| 1 | 사업 이해 + 정책 | 1h | recoverGX 컨셉·GX 강사 역할·운동 설계는 AI 원칙·금기 표현·클래스 개설 정책 |
| 2 | GX 프로그램·안전 | 2h | 본사 GX 프로그램 숙지 + 그룹 클래스 부상 위험·응급 대응 (자격증으로 기검증, 본사 표준만 학습) |
| 3 | AI 가이드 실습 | 3h | 회원 데이터 읽기 · AI 추천 해석 · **5분 기록 SOP** 실습 · 클래스 개설 앱 실습 |
| 4 | CS·UX | 1h | 회원 응대·매너·클래스 취소 정책·등급 변동 변수 이해 |

## 평가 기준

| 평가 | 기준 | 가중 |
|---|---|---|
| 모듈별 퀴즈 (객관식) | 모듈마다 80% 이상 통과 | 필수 |
| 실습 영상 제출 (모듈 3) | 본사 평가 5점 만점 중 **3.5 이상** | 필수 |
| 최종 면담 (15분) | 본사 SOP 이해도·금기 표현 회피·5분 기록 SOP·클래스 개설 정책 숙지도 | 통과/불통과 |

**탈락 시**
- 1회 재시험 가능 (불합격 모듈만 재이수)
- 2회 탈락 시 → **6개월 후 재신청** 가능

## 비용

- **본사 부담** (강사 무료) — 자격증 보유자 모집 인센티브
- 본사 1인당 비용 ≈ **30만원** (교육 인건비 + 자료비)
- → 공급 측 락인 투자 (Pro GX 강사 풀 확보 + 본사 SOP 정착)

## 운영 흐름

```
[3D 모집] 자격증 보유자 신청서 접수
            │
            ▼
        본사 아카데미 등록 (모듈 1~4, 약 8h)
            │
            ▼
        퀴즈 + 실습 영상 + 최종 면담
            │
       ┌────┴────┐
       ▼         ▼
     통과     탈락
       │       │
       │       ├─ 1회 재시험
       │       └─ 2회 탈락 시 6개월 대기
       ▼
   등급 P1 부여 (신입 Pro)
       │
       ▼
   어드민이 gxOpenEnabled = true 부여 (검토 후)
       │
       ▼
   GX 클래스 개설 가능 (강사 앱 클래스 개설 메뉴 활성화)
       │
       ▼
   분기 평가 → P1 → P2~P5 승급 ([3F](./peer-leader.html))
```

## 강사 앱 UI 권고

- 강사 가입 후 **아카데미 탭**에서 모듈 진행률·퀴즈 응시·영상 업로드·면담 예약 일괄 관리
- 통과 시 프로필에 **"Pro 인증 (P1)"** 자동 부여 → 회원 앱에서 신뢰 시그널로 노출
- `gxOpenEnabled` 부여 시 강사 앱 **클래스 개설 메뉴** 활성화

## 회원 앱 신뢰 시그널

- 모든 강사 카드에 **"Pro 인증"** 표시 (자격증 + 본사 아카데미 통과 사실)
- 회원 페이지 FAQ에 "강사 양성 과정" 항목 → 본 문서 요약 링크

## 정책 토글 연결 (ADR 0002)

| 토글 변수 | 영향 |
|---|---|
| `mentor.require_license = true` (default) | Pro Only 통일 |
| `mentor.academy_required = true` (default) | 아카데미 통과 필수 |
| `gxOpenEnabled` (어드민 부여) | GX 클래스 개설 권한 활성화 — 아카데미 통과 후 어드민 수동 부여 |
