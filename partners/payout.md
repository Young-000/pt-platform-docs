# 3G. 강사 정산 — 조합형 정책 (recoverGX)

**🟢 v3 (recoverGX 피벗)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [ADR 0007](../decisions/0007-trainer-model.html) 승계·확장, [3E 운영 모델](./model.html), [3F 개설 권한](./peer-leader.html), [3H 등급](./quality.html), [2C 가격](../members/pricing.html) → [7B 매출·원가](../economics/revenue-cost.html), [6C 본사 수익](../expansion/revenue-share.html)

> **📌 recoverGX 정산 정책 (v3)**
>
> [ADR 0007](../decisions/0007-trainer-model.html) P1~P5 등급 정산 구조를 승계하되, GX 클래스 특성에 맞춰 **조합형 정책**으로 확장.
>
> **강사 지급액 = 기본금 + (인당 단가 × 출석 인원) + (클래스 매출 × 비율%)**
>
> - 세 요소 각각 0으로 비활성 가능. 어드민이 조합 설정 후 강사별 정책 할당.
> - 미할당 강사는 기본 정책 적용.
> - 클래스 완료 시 정책 스냅샷으로 박제 (소급 변경 불가).
> - 회원 우회 방지: 회원 결제·멤버십 정보 강사 미열람.

## 등급 P1~P5 (ADR 0007 승계)

P1~P5 등급 구조는 [ADR 0007](../decisions/0007-trainer-model.html) 및 [3F](./peer-leader.html)에서 정의된 기준을 그대로 승계. 조합형 정산 정책의 **기본금 기준선**으로 활용.

| 등급 | 호칭 | 30분 기본금 기준선 | 비고 |
|---|---|---|---|
| **P1** | 신입 Pro | 10,000원 | 첫 분기 |
| **P2** | 검증 Pro | 12,000원 | |
| **P3** | 시니어 Pro | 14,000원 | |
| **P4** | 전문 Pro | 16,000원 | |
| **P5** | 마스터 Pro | 18,000원 | |

## 조합형 정산 구조

| 요소 | 설명 | 비활성 조건 |
|---|---|---|
| **기본금** | 클래스 시간 × 등급 기준선 (30분 unit) | 0원 설정 시 비활성 |
| **인당 단가 × 출석** | 출석 인원 1인당 추가 지급액 | 0원 설정 시 비활성 |
| **매출 × 비율%** | 클래스 총 매출 대비 % | 0% 설정 시 비활성 |

### 계산 예시

> 정책: 기본금 30,000원 + 인당 3,000원 / 클래스 정원 20명·가격 25,000원·출석 15명

```
기본금          = 30,000원
인당 × 출석     = 3,000원 × 15명 = 45,000원
매출 비율       = 0% (비활성)
───────────────────────────
강사 지급액     = 75,000원
클래스 총 매출  = 25,000원 × 15명 = 375,000원
본사 차감       = 375,000원 − 75,000원 = 300,000원
```

## 정산 정책 관리

- **어드민이 정책 생성·수정** (기본금·인당 단가·매출 비율 세 요소 설정)
- **강사별 정책 할당** — 미할당 강사는 기본 정책 자동 적용
- **클래스 완료 시 스냅샷 박제** — 클래스 종료 후 정책 소급 변경 불가
- 강사 앱에서 클래스별 정산 예정액 실시간 조회 가능

## 정산 주기

- **격주 (2주마다)**. 강사 앱에서 클래스별 출석·정산 내역 실시간 조회.

## 등급 변동 → 정산 영향

- 분기 1회 등급 변동 ([3F](./peer-leader.html)) — 다음 분기 기본금 기준선에 자동 반영
- 등급 ↓ 강등 가능 (출석률·NPS 하락 시)
- 회원에게 강사 등급·단가 비공개.

## 분배 룰 (직영 vs 가맹)

| 흐름 | 직영 (Phase 1) | 가맹 (Phase 2+) |
|---|---|---|
| 1. 회원 결제 | 본사 100% 수령 | 본사 100% 수령 |
| 2. 강사 정산 (조합형) | 본사 → 강사 직접 | 본사 → 강사 직접 |
| 3. 본사 차감분 | 본사 100% | 본사 vs 가맹점 분배 |
| 4. 가맹점 분배율 | — | 베타 검증 후 봉인 ([6C](../expansion/revenue-share.html)) |

> **분배 핵심**: 강사 정산은 조합형 정액 우선. 가맹점 분배는 본사 차감분에 한해서만 비율 적용.

## 결제 흐름

- 회원 결제 → 본사 앱이 직접 수령 → 강사·가맹점주 자동 분배 → 격주 입금
