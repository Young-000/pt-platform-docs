# 3G. 강사 정산 (회당 고정 · P1~P5)

**🟢 v2 봉인 (2026-05-20)** · 의존: [3E 운영 모델](./model.html), [3F 강사 등급](./peer-leader.html), [3H 등급](./quality.html), [2C 가격](../members/pricing.html) → [7B 매출·원가](../economics/revenue-cost.html), [6C 본사 수익](../expansion/revenue-share.html)

> **📌 v2 봉인 (2026-05-20)**
>
> - 강사 정산 = **회당 고정 (30분 unit 기준)**. 비율·% 분배 ❌.
> - 등급 P1~P5: **10,000 / 12,000 / 14,000 / 16,000 / 18,000원/30분 unit**.
> - 평균 정산 단가 = **13,000원/30분 unit** (시급 환산 26,000원).
> - **할인은 본사 책임**. 회원이 할인 회차권을 써도 강사 정산은 등급 고정 단가.
> - "S1 파트타이머 12k / S2 전문 강사 20k" 2 트랙 + "Pro +5천 옵션" 폐기.

## 단가 구조 (30분 unit · v2)

| 등급 | 30분 unit | 60분 (2 unit) | 비고 |
|---|---|---|---|
| **P1 신입 Pro** | 10,000원 | 20,000원 | 첫 분기, 시급 20,000원 |
| **P2 검증 Pro** | 12,000원 | 24,000원 | 시급 24,000원 |
| **P3 시니어 Pro** | 14,000원 | 28,000원 | 시급 28,000원 |
| **P4 전문 Pro** | 16,000원 | 32,000원 | 시급 32,000원 |
| **P5 마스터 Pro** | 18,000원 | 36,000원 | 시급 36,000원 |
| **평균 (모델 가정)** | **13,000원** | **26,000원** | 베타 mix (P1 20% / P2 30% / P3 25% / P4 15% / P5 10%) |

→ 회원이 60분 예약 시 위 단가 × 2. **등급 보너스 ❌** (등급이 단가에 직결).

## 본사 마진 구조

| 항목 | 30분 unit 기준 | 비고 |
|---|---|---|
| 회원 평균 회당가 | **30,000원** | ARPU 가정 ([2C](../members/pricing.html)) |
| 강사 평균 정산 | **13,000원** | 등급 mix 평균 |
| **unit당 마진** | **17,000원** | 본사 (운영비·임대·AI·CS 충당) |

> **할인 = 본사 책임** — 회원이 24회권 (회당 30k) 또는 48회권 (회당 27.5k) 을 써도 강사 정산은 등급 P 단가 고정. 본사 마진이 변동 흡수.

## 분배 룰 (직영 vs 가맹)

| 흐름 | 직영 (Phase 1) | 가맹 (Phase 2+) |
|---|---|---|
| 1. 회원 결제 (평균 30k/unit) | 본사 100% 수령 | 본사 100% 수령 |
| 2. 강사 정산 (P1~P5 회당 고정) | 본사 → 강사 직접 | 본사 → 강사 직접 |
| 3. unit당 마진 17k | 본사 100% | 본사 vs 가맹점 분배 |
| 4. 가맹점 분배율 | — | 가설 ~40% (베타 검증 후 봉인, [6C](../expansion/revenue-share.html)) |

> **분배 핵심**: 강사 단가는 비율 ❌ 정액 ✅. 가맹점 분배는 unit당 마진(17k)에 한해서만 비율 적용. 분배율은 [6C](../expansion/revenue-share.html)에서 봉인 예정.

## 정산 주기

- **격주 (2주마다)**. 강사 앱에서 unit 누적·정산 예정액 실시간 조회.

## 등급 변동 → 정산 영향

- 분기 1회 등급 변동 ([3F](./peer-leader.html)) — 다음 분기 회당 정산에 자동 반영
- 등급 ↓ 강등도 가능 (회원 retention·NPS 하락 시)
- 회원에게 등급 비공개. 강사 단가도 비공개.

## 결제 흐름

- 회원 결제 → 본사 앱이 직접 수령 → 강사·가맹점주 자동 분배 → 격주 입금
