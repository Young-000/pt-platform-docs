# 3D. 강사 모집 전략 (Pro Only · recoverGX)

**🟢 v3 (recoverGX 피벗)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [3A 페르소나](./personas.html), [3E 운영 모델](./model.html), [3F 개설 권한](./peer-leader.html), [3I 아카데미](./verification-course.html), [0 비전](../product/vision.html)

> **📌 v3 (recoverGX 피벗)**
>
> 모든 강사 = **Pro** (자격증 보유 + 본사 아카데미 통과). 일반 멘토 트랙 ❌.
>
> 모집 흐름: Pro 자격증 보유자 모집 → 본사 아카데미 통과 → 등급 P1 부여 → `gxOpenEnabled` 어드민 부여 → GX 클래스 개설 가능.

## 전제 — 기존 인프라

> **자체 헬스장 4개 운영 중** → 초기 모집 채널 확보됨 (인근 자격증 강사 referral).

## 활성 흐름 (모집 → 아카데미 → 개설 권한)

```
[3D] 모집 채널 (헬스장 referral · 자격증 카페 · 잡 포털 · 외부 채용)
    │
    │  자격 1차 필터: 생활스포츠지도사 2급 이상 보유
    ▼
지원서 접수 + 1차 스크리닝 (자격증 인증·이력·GX 카테고리·고용 형태 선택)
    │
    ▼
[3I] 본사 아카데미 (4 모듈·8h·본사 부담) → 퀴즈·영상·면담
    │
    ├─ 통과 → 등급 P1 자동 부여
    │            │
    │            ▼
    │         어드민이 gxOpenEnabled = true 부여 (검토 후)
    │            │
    │            ▼
    │         GX 클래스 개설 가능 (강사 앱 → 클래스 개설 메뉴 활성화)
    │
    └─ 탈락 → 1회 재시험 → 2회 탈락 시 6개월 후 재신청
```

→ **자격증 미보유자는 모집 단계에서 거절**. 본사가 자격증 취득 지원 ❌ (Pro GX 강사 풀 모집에 집중).

## 고용 형태 선택 (전속 ↔ 프리랜서)

지원 단계에서 선택. 본사가 회원 풀·등급에 따라 조정 가능.

| 형태 | 적합 군 |
|---|---|
| **전속 (정규직)** | 본사 4대보험·고정급 + 조합형 정산 인센티브 — P4~P5 / 고급 GX 강사 |
| **프리랜서** | 조합형 정산만, 자유 일정 — P1~P3 / 독립 GX 강사 |

## GX 강사 베타·확장 시나리오

| Phase | 지점 수 | GX 강사 풀 | 정책 |
|---|---|---|---|
| **Phase 0~1 (베타·1호점)** | 1호점 | **15명 (오픈 시)** | P1 신입 10명 + P2~P3 시니어 5명. 자격증 보유 + 아카데미 통과 + `gxOpenEnabled` 어드민 부여 |
| **Phase 2 (2~4호점)** | 4호점 | **호점당 12~15명** | 1호점 데이터로 P4~P5 1차 승급. 외부 영입 가속. `gxOpenEnabled` 부여 범위 확대 |
| **Phase 3+ (5호점+)** | 5호점+ | **호점당 15명 표준** | 분기 등급 평가 정착. P3+ 강사 `gxOpenEnabled` 자동 부여. 오픈마켓 지향 |

## 모집 채널 (Phase 1)

| 채널 | 비중 | 비고 |
|---|---|---|
| 자체 헬스장 4개 referral | 30% | 인근 자격증 보유 GX 강사 1차 풀 |
| 자격증 카페·커뮤니티 | 30% | "생활스포츠지도사 2급" · GX 강사 카페 광고·DM |
| 잡 포털 (잡플래닛·원티드) | 20% | 정규직·프리랜서 별도 공고 |
| 강사 → 강사 referral 보너스 | 10% | 활성 P3+ 강사 추천 시 보너스 (정책 TBD) |
| 외부 채용 헤드헌팅 | 10% | P4~P5 시니어 GX 강사 영입용 |
