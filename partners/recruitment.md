## 결정해야 할 것

> **단계별로 강사를 어떻게 모집할 것인가?** 콜드스타트(0→1호) ≠ 스케일(1→100호).

세부 질문:
1. 1호점 오픈일에 Pro 강사 몇 명·Peer 리더 몇 명 필요?
2. 어디서 모집하나? (PT샵 헤드헌팅? 채용공고? 입소문?)
3. 강사 입장에서 우리 플랫폼이 매력적이게 보이려면?
4. 가맹 단계 (10호점+)에서 모집은 본사가? 가맹점주가?

---

## 단계별 전략 분리

### Phase 1 — PMF 검증 (1 → 3호점)

특징: 브랜드 인지 ❌, 회원 풀 ❌, 강사 입장에선 "검증 안 된 신생"
**핵심: 강사를 많이 뽑을 필요 없음.** 공급은 적정 코어로 커버, 검증이 우선.

**적정 강사 규모 (1호점 가설)**:
- 방 8개 × 30분 슬롯 단위
- 피크(저녁) 4시간 ≈ 64 슬롯 / 일
- 강사 1명 = 4시간 = 8 슬롯 가능
- → **강사 8~12명이면 충분** (회전·휴무·여유 포함)

**모집 매커니즘**:
- 본사 직접 헤드헌팅 (네트워크 + LinkedIn + 헬스 커뮤니티)
- 초기 강사에게 **인센티브 패키지**:
  - 입점 보너스 (예: 첫 3개월 회당 +5,000원)
  - 본사 마케팅 보장 (회원 X명 보장)
  - 등급제 우선 정착 (초기 강사 = 자동 상위 등급)
- 강사 풀의 안정성·검증 가능성이 모집 수보다 중요

**규모**: 1지점당 Pro 8-12명 + Peer 4-8명 정도. **확장은 Phase 2에서.**

### Phase 2 — 검증 (4 → 10호점)

브랜드 인지 점진적 ↑, 강사 자발 지원 시작.

**모집 매커니즘**:
- 채용 공고 + 강사 → 강사 추천 (referral 보너스)
- 1호점 강사 후기·사례 활용

### Phase 3 — 스케일 (10호점+)

브랜드 인지 ↑, 가맹 본격화.

**모집 매커니즘**:
- 자동화된 강사 onboarding (앱 내 가입·검증·교육)
- 지역별 마스터 가맹이 모집 책임 (본사는 시스템 제공)
- "PT 강사 → 우리 플랫폼이 1순위" 위치 확보

## 옵션

### A. **본사가 모든 단계 모집**
- 가맹점주는 공간만, 강사는 본사 풀
- ✅ 품질 통일
- ❌ 100호점 = 본사 인사 부담 폭증

### B. **단계별 분리** ⭐
- Phase 1-2: 본사 모집
- Phase 3: 가맹점주가 본사 가이드라인 따라 모집
- ✅ 본사 부담 분산
- ❌ 가맹점주 모집 역량 편차

### C. **가맹점주 모집 + 본사 검증**
- 가맹점주가 모집, 본사가 검증·등급 결정
- ✅ 지역 밀착
- ❌ 가맹점주가 "내 강사" 의식 → 우회 위험

---

## 추천

**B (단계별 분리)** — 본사 → 가맹 점진 이관.

콜드스타트가 가장 위험한 단계 → 본사가 직접 책임지고 빠르게 검증.
