# 3D. 강사 모집 전략

**🔴 TBD** · 의존: [3A 페르소나](./personas.html), [3E 운영 모델](./model.html), [0 비전](../product/vision.html)

## 전제 — 기존 인프라

> **자체 헬스장 4개 운영 중** → 초기 모집 채널 확보됨.

Phase 1 PMF 검증 단계 강사 모집은 기존 헬스장 네트워크로 충분히 커버 가능. 외부 헤드헌팅·광고 부담 ↓.

## 활성 흐름 (모집 → 검증 → 활성)

```
[3D] 모집 채널 (기존 헬스장·referral·외부 채용)
    │
    ▼
지원서 접수 + 1차 스크리닝 (기본 인적 사항·동기)
    │
    ▼
[3I] 본사 검증 코스 (4 모듈·8h·본사 부담) → 퀴즈·영상·면담
    │
    ├─ 통과 → "검증 완료" 뱃지 → 활성 멘토 (회원 앱 노출·예약 가능)
    └─ 탈락 → 1회 재시험 → 2회 탈락 시 6개월 후 재신청
```

자격증 보유자도 검증 코스 면제 ❌ (본사 정책·금기 표현 학습은 모두 필수). 단 자격증 보유 시 별도 뱃지 노출 + Pro 인증 트랙 진입 가능 ([3F](./peer-leader.html)).

## Pro 강사 베타·확장 시나리오 (2026-05-16)

| Phase | 지점 수 | Pro 인증 멘토 수 | 정책 |
|---|---|---|---|
| **Phase 1 (베타)** | 1호점 | **0명 시작** | 일반 멘토 12명 운영. 회원 데이터·강사 통계 누적 후 Phase 1 후반부터 내부 1차 승격 가능 |
| **Phase 2** | 2~4호점 | **1~3명** | 1차 승격자 + 외부 영입. Pro 비중 ~10% |
| **Phase 3+** | 5호점+ | **지점당 1명 이상** | 자격증 보유자 의무 배치 → 시설법 §26 + Pro 옵션 매출 레버 충족 |

> Pro 승격 트리거: 회원 평점 상위 + 재예약률 + 자격증 보유 + 본사 인터뷰. 자세한 자격은 [3F](./peer-leader.html) + [ADR 0002](../decisions/0002-license-policy.html).

- Phase 3 (스케일): 자동화 onboarding 설계
