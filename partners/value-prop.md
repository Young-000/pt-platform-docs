# 3C. 강사 Value Proposition (recoverGX)

**🟢 Decided** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [ADR 0001](../decisions/0001-consumer-pivot.html), [ADR 0002](../decisions/0002-license-policy.html), [3A 페르소나](./personas.html), [3B 문제](./problems.html), [3G 정산](./payout.html), [3H 등급](./quality.html), [3F 개설 권한](./peer-leader.html) → 강사 모집 카피

## 한 줄 약속

> **"검증만 통과하면, 내 클래스를 내가 직접 개설한다.
> 영업·결제·정산은 플랫폼이 대행. 강사는 클래스 운영에만 집중."**

## 핵심 매력

| 항목 | 강사 입장 |
|---|---|
| 영업·CS | 본사가 회원 모집·예약·CS 일괄 처리. 강사는 클래스 운영만 |
| 클래스 자율 개설 | `gxOpenEnabled` 부여 후 지점·룸·카테고리·시간·정원·가격 범위 내 자유 설정 |
| 정산·세무 | 조합형 정산 자동 처리. 격주 입금 |
| 회원 우회 방지 | 회원 결제·멤버십 강사 미열람 → 플랫폼이 결제 채널 보호 |
| **수익화 경로** | **등급 승급 (P1→P5) → 기본금 기준선 ↑ + 조합형 정산 정책 협의** |

## gxOpenEnabled 검증의 의미 (수익화 메커니즘)

```
자격증 보유자 지원
    │
    │ 본사 아카데미 (4 모듈·8h) 통과
    ▼
등급 P1 부여
    │
    │ 어드민이 gxOpenEnabled = true 부여
    ▼
GX 클래스 개설 권한 활성화
    → 지점·룸·카테고리·시간·정원·가격 범위 내 자유 개설
    → 회원 앱에 "Pro 인증" 배지 노출
    → 등급 P1→P5 승급 시 기본금 기준선 상향
```

→ 어드민 검증 = 강사 입장에서도 **"가치 증명 + 클래스 개설 권한 + 수익 확장 경로"** (회원 입장 신뢰 자산과 동일).
