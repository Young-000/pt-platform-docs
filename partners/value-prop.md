## 핵심 매력

| 항목 | 강사 입장 |
|---|---|

| 정산·세무 | 본사 자동 처리 |
| **수익화 경로** | **Pro 인증 심사 통과 → 단가 자율 권한** |

## Pro 인증의 의미 (수익화 매커니즘)

```
일반 멘토 (검증 통과)
    │
    │ 자격증 보유 + 본사 심사 통과
    ▼
Pro 인증 멘토
    → 회당 단가 자율 설정 권한 ↑
    → 회원 노출 시 "Pro 인증" 배지
    → 단가 ↑ 수용 가능 회원이 자발 선택
```

→ 본사 심사 = 강사 입장에서도 **"가치 증명 + 수익 확장 경로"** (회원 입장 신뢰 자산과 동일).
