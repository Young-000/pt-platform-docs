# 3B. 강사 문제의식 (recoverGX)

**🟢 Decided** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [3A 강사 페르소나](./personas.html) → [3C 강사 VP](./value-prop.html), [3G 정산](./payout.html)

## GX 강사가 시장에서 겪는 페인

1. **영업·CS 부담** — 회원 모집·마케팅·문의 응대 강사 자기 책임
2. **수수료·시설 압박** — 스튜디오/헬스장 소속 시 매출의 25-40% 차감 + 시설 사용 제약
3. **세금·정산 행정** — 프리랜서 시 세무·일정·결제 직접 처리
4. **클래스 개설 장벽** — 독립 클래스 개설 시 공간·결제 인프라를 직접 확보해야 함
5. **회원 우회 리스크** — 직접 계좌이체 유도 시 플랫폼 페널티 또는 분쟁 노출

## 우리 솔루션 매핑

| 페인 | recoverGX 솔루션 |
|---|---|
| 영업·CS | 본사가 회원 모집·예약·CS 일괄 처리. 강사는 클래스 운영에만 집중 |
| 수수료·시설 압박 | 조합형 정산 (기본금 + 인당 출석 + 매출 비율). 강사가 가격 범위 내 자율 설정 |
| 세금·정산 | 본사 자동 시스템. 격주 자동 입금 |
| 클래스 개설 장벽 | `gxOpenEnabled` 검증 후 지점·룸·카테고리·시간·정원·가격 범위 내 자유 개설 |
| 회원 우회 리스크 | 회원 결제·멤버십 강사 미열람. 본사가 결제 채널 통제하여 강사 보호 |
