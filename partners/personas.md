## 비전 — **PT 강사를 "파트타임 잡"으로**

```
배달기사처럼,
원할 때 슬롯 오픈하고,
원하는 만큼 일하는 PT 강사.
```

특정 강사군(성장 발판형·독립 검증형 등)을 타겟하지 않습니다.
**자격증 보유자라면 누구나 자기 시간만큼 파트타임으로 일하는 모델**을 만듭니다.

---

## 핵심 매커니즘

| 차원 | 파트타임 잡 모델 |
|---|---|
| 가입 마찰 | 자격증 인증 + 기본 검증 → 즉시 활동 가능 |
| 시간 | 본인이 슬롯 자유 오픈/닫음 |
| 약정 | 풀타임 의무 ❌ |
| 영업·CS | 본사가 회원·예약·결제·CS 처리 |
| 정산 | 회당 즉시 계산, 격주 입금 |
| 본업 | 별도 본업 있어도 OK / 풀타임 전업도 OK |

→ "PT 강사 = 풀타임 직업" 고정관념 해체.

---

## 누가 들어오는가 (자연 발생)

특정 페르소나를 좁히지 않으므로 다음이 모두 자연스럽게 풀에 들어옴:

- 헬스장·PT샵 피고용 강사 (퇴근 후 부수입)
- 전직 트레이너 (재진입 발판)
- 부업 원하는 자격증 보유자 (직장인 + 자격증)
- 신입 강사 (성장 발판)
- 베테랑 프리랜서 (안정 회원풀 + 자율성)
- 일반 멘토 (Pro 자격증 없는 일반인) ← [3F 일반 멘토](./peer-leader.html)

→ **풀을 좁히지 않고 시스템으로 다양한 강사를 흡수.**

---

## Phase별 적용

| Phase | 적용 |
|---|---|
| **Phase 1 (1-3호점)** | "파트타임 잡 모델"은 비전. 실제론 본사가 직접 헤드헌팅한 **안정 코어 12명** 운영 (PMF 검증) — **다종목 mix** (스트레칭·필라테스·1:1 PT) 분포로 구성. 단일 PT 가정 ❌. 회원 카테고리 수요 데이터 누적 시 추가 채용 trigger (특정 카테고리 가동률 > 70% 또는 대기열 발생) |
| **Phase 2 (4호점+)** | 모집 자동화. 자격증 인증 + 검증 통과하면 누구나 슬롯 오픈 |
| **Phase 3 (10호점+)** | 완전 자동 onboarding. 진짜 "배달기사형" 강사 풀 형성 |
