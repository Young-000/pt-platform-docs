# 2D. 회원 정책 (환불·취소·폐강)

**🟢 GX 피벗 (2026-06-04)** · 의존: [ADR 0011](../decisions/0011-recovergx-gx-pivot.html), [2B 지갑](./membership.html), [2C 가격](./pricing.html) → [8C 약관](../legal/privacy-tos.html), CS SOP

{: .note }
GX 피벗([ADR 0011](../decisions/0011-recovergx-gx-pivot.html))으로 회차권 기반 정책(환불 공식·일시정지·양도)은 **지갑(충전금) + 드롭인** 정책으로 대체됨. 모든 정책 수치는 `admin.PolicyConfig` 변수로 운영 중 즉시 변경 가능.

## 0. 정책 요약

| 항목 | 기본값 | 변수명 |
|---|---|---|
| 취소 환불 마감 | 시작 **6h 전** | `refundCutoffHours` (기본 6) |
| 마감 전 환불 | **전액 지갑 크레딧** | — |
| 마감 후 환불 | **0원** | — |
| 좌석 복구 | **항상** (마감 전/후 무관) | — |
| 노쇼 패널티 | **없음** | — |
| 폐강 환불 | **전액 지갑 크레딧** | — |

## 1. 취소 정책 (슈퍼몽키 패턴)

| 시점 | 환불 | 좌석 |
|---|---|---|
| 시작 `refundCutoffHours`(기본 6h) **전** | **전액 지갑 즉시 크레딧** | 복구 |
| 시작 6h **이내** | **0원** | 복구 |

- 좌석은 취소 즉시 항상 복구 (다른 회원 예약 가능)
- 마감 이내 취소 시 결제액은 정산 매출로 귀속

## 2. 노쇼

| 누구 | 처리 |
|---|---|
| 회원 노쇼 | 패널티 없음. 결제된 클래스 금액은 정산 매출 귀속 |
| 강사·본사 측 귀책 | 회원에게 **전액 지갑 즉시 크레딧** + 사과 메시지 |

## 3. 폐강 (강사/어드민 취소)

강사 또는 어드민이 클래스를 폐강하면 예약한 **모든 회원에게 전액 지갑 즉시 크레딧**.

```
폐강 확정 → 예약자 전원 알림 → 지갑 즉시 크레딧
```

{: .warning }
폐강은 회원 신뢰에 직접 영향. CS SOP에서 폐강 허용 기준·빈도 한도 별도 정의 필요.

## 4. 지갑 잔액 환불 (서비스 탈퇴)

- 회원이 서비스 탈퇴 시 지갑 잔액 처리 방식은 재산출 대상 (약관 정의 필요).
- 베타 기간 중: 잔액 현금 환불 또는 지갑 소멸 여부 미확정.

## 5. 일시정지 · 양도

- GX 드롭인 모델에서는 약정이 없으므로 **일시정지 개념 없음**.
- 지갑 잔액은 만료 기한 없이 유지 (정책 변수로 조정 가능).
- **양도 불가** (지갑은 본인 계정 귀속).

## 6. 폐기된 정책 (GX 피벗 이전)

- 회차권 환불 공식 (`priceCharged − 35,000 × 사용 회차`) — [ADR 0011](../decisions/0011-recovergx-gx-pivot.html)로 충전금 대체
- 24h 전 무료 / 6h 이내 100% 차감 회차 차감 방식 — 지갑 차감 방식으로 대체
- 4회 이상 일시정지(잔여 30% 한도) — 드롭인 모델에서 불필요
- 당일 예약권 1매 보상 — 폐기
