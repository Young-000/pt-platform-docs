## 결정해야 할 것

5가지 정책 묶음:

1. **환불** — 멤버십 중도 해지 시 부분환불 계산
2. **노쇼** — 회원 안 옴 (회차 차감? 패널티?)
3. **예약 변경/취소** — 몇 시간 전까지 무료?
4. **일시정지 (Pause)** — 부상·여행 시 멤버십 잠금
5. **양도** — 가족·지인에게 양도 가능?

---

## 1. 환불 정책

세부 질문:
- 회차 미사용분 환불 vs 일할 계산?
- 환불 수수료 (10%)?
- 약정 할인 적용분 어떻게 처리?

옵션:
| | 계산법 | 환불 마찰 |
|---|---|---|
| A. 미사용 회차 100% 환불 | 단순 | 낮음 |
| B. 미사용 회차 - 위약금 10% ⭐ | 표준 | 중간 |
| C. 정상가 적용 후 차액 환불 | 약정 할인 무효화 | 높음 |

→ B 추천. 표준 룰 + 위약금 명시.

## 2. 노쇼 정책

| 옵션 | 설명 | 임팩트 |
|---|---|---|
| A. 회차 1회 차감 ⭐ | 회원이 와도 안 와도 회차 소진 | 단순, 강사 보호 |
| B. 회차 차감 + 패널티 | 노쇼 3회 시 멤버십 정지 | 강력 |
| C. 무료 (한 달 1회까지) | 관대 | 강사 손실 |

→ **A 추천**. 강사 정산 보장 + 룰 명확.

## 3. 예약 변경/취소

옵션:
| 변경/취소 시점 | 처리 |
|---|---|
| 24시간 전까지 | 무료 (회차 미차감) |
| 6시간 전까지 | 회차 50% 차감 |
| 6시간 이내 | 회차 100% 차감 (=노쇼) |

→ 표준 룰. 강사 일정 보호 + 회원 유연성 균형.

## 4. 일시정지 (Pause)

세부 질문:
- 정지 가능 기간 (월 1회 / 최대 4주?)
- 사유 인증 필요 (의사 소견서 등)?

옵션:
| 옵션 | 조건 |
|---|---|
| A. 무조건 가능 (월 X회 한도) | 자율 |
| B. 사유 + 인증 ⭐ | 부상·해외출장 등 |
| C. 불가 | 가장 단순, but 회원 불만 |

→ **B 추천**. 의료·해외 사유 인정.

## 5. 양도

옵션:
| 옵션 | 설명 |
|---|---|
| A. 양도 불가 ⭐ | 회원 1인 = 1 멤버십 |
| B. 1회 양도 가능 (수수료 1만) | 유연 |
| C. 자유 양도 | 위험 — 회원 데이터 유실 |

→ **A 추천** — AI 데이터 플라이휠 보호.
