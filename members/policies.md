# 2D. 회원 정책 (환불·노쇼·취소·일시정지·양도)

**🟢 Decided** · 의존: [2B 멤버십](./membership.html), [2C 가격](./pricing.html) → [8C 약관](../legal/privacy-tos.html), CS SOP

## 1. 환불 (중도 해지)
- 미사용 회차 = **정상가 환산 100% 환불** (약정 할인분 정상가 적용 후 차액)
- 청약철회: 결제 7일 이내 + 미사용분 100% 환불

## 2. 노쇼

| 누구 | 처리 |
|---|---|
| 회원 노쇼 | 회차 1회 차감 (멘토 정상 정산) |
| 본사·멘토 측 노쇼 | 회원에게 **회차 +1 보상** + 사과 메시지 |

## 3. 변경·취소

| 시점 | 처리 |
|---|---|
| 48h 전까지 | 무료 (회차 미차감) |
| 48h ~ 6h 전 | 회차 차감 + **당일 예약권 1매** (당일 다른 슬롯 재예약 가능) |
| 6h 이내 | 회차 100% 차감 (= 노쇼) |

## 4. 일시정지 (Pause)
- **사유 제한 ❌, 회원 자유**
- 약정 기간의 30% 이내 (예: 12개월 약정 = 최대 3-4개월)
- 약정 기간 자동 연장

## 5. 양도
- **불가** (회원 운동 데이터 누적 = 핵심 자산. 양도 시 연속성 깨짐)

## 6. 포인트 (Pro 옵션) 환불
- 미사용 포인트 = 100% 환불 (현금 결제분)
- 약정 할인 보너스 포인트 = 환불 ❌
