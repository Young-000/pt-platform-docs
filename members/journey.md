# 2A. 회원 여정

**🟡 Updated (2026-05-16)** · 의존: [ADR 0001](../decisions/0001-consumer-pivot.html), [ADR 0004](../decisions/0004-one-time-ticket-pricing.html), [2B 멤버십](./membership.html), [2D 정책](./policies.html), [4C AI](../service/ai-role.html) → 앱 UX, CS SOP

## 8단계

| 단계 | 액션 |
|---|---|
| **1. 인지** | 인스타·구글·입소문 (1A 페르소나 채널) |
| **2. 첫 방문** | 1회권 4만원 체험 또는 프로모션 첫 1회 (의지 검증) |
| **3. 첫 결제** | **1회권 또는 4회권** 시작 권유 (약정 부담 ❌, 회차권 단일 카테고리) |
| **4. 첫 세션** | 회원이 강사·프로그램 자율 선택 (스트레칭·필라테스·1:1 PT 등), 4점↓ 시 멘토 변경 |
| **5. 반복** | 회차 잔여 알림, AI 다음 세션 운동 제안 |
| **6. 이탈 위기** | 14일 미예약 / 회차 미사용 → AI 체크인 메시지 |
| **7. 갱신** | 잔여 회차 소진 시 상위 회차권(12·24·48) 업그레이드 인센티브 |
| **8. 이탈** | 사유 서베이, 환불 처리(2D), 6개월 후 콜백 |

## 톤

- **AI-first** — AI 체크인·추천이 1차
- **위기 시 인간 백업** — 만족도 ↓ 또는 이탈 위기 시 본사 CS·멘토 직접 연락
- **일상 코칭·매일 챙김 ❌** ([4C AI 스코프](../service/ai-role.html) 정합)
