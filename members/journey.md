## 8단계

| 단계 | 액션 |
|---|---|
| **1. 인지** | 인스타·구글·입소문 (1A 페르소나 채널) |
| **2. 첫 방문** | 무료 체험 1회 또는 1만원 첫 1회 (의지 검증) |
| **3. 첫 결제** | 주 1회권 시작 권유, 월결제 default (약정 부담 ❌) |
| **4. 첫 세션** | AI 추천 멘토 3명 중 선택, 4점↓ 시 멘토 교체 옵션 |
| **5. 반복** | 회차 잔여 알림, AI 다음 세션 운동 제안 |
| **6. 이탈 위기** | 14일 미예약 / 회차 미사용 → AI 체크인 메시지 |
| **7. 갱신** | 자동결제 default, 7일 전 알림, 주 1→2 업그레이드 인센티브 |
| **8. 이탈** | 사유 서베이, 환불 처리(2D), 6개월 후 콜백 |
