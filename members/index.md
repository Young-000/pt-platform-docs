# 2. 회원 (Members)

> **회원 여정이 1순위.** 어떤 회원을 모집할 것인가가 모든 결정의 시작점.

{: .note }
**GX 피벗 (2026-06-04, [ADR 0011](../decisions/0011-recovergx-gx-pivot.html))**: 회차권·티어 멤버십 → **지갑(충전금) + 드롭인** 모델로 전환. 1:1 PT 여정은 코드 보존 후 보류.

## 우선 결정

회원 페르소나(1A) 구체화 → 지갑 패키지(2B) → 클래스 가격(2C) → 정책(2D).

→ 페르소나 결정은 [1A 회원 페르소나](../product/personas.html).

## 핵심 모델 요약 (GX 피벗 후)

| 항목 | 내용 |
|---|---|
| 결제 단위 | **지갑(충전금)** — 패키지 충전 후 클래스별 차감 |
| 약정·연장 압박 | **없음** (드롭인, 클래스별 단건 예약) |
| 클래스 가격 | **1~5만원** (강사 지정, 어드민 상한/하한 범위 내) |
| 취소 마감 | 시작 `refundCutoffHours`(기본 6h) 전 — 이후 0원 환불 |
| 노쇼 패널티 | 없음 (결제액 정산 매출 귀속) |

## 신뢰 시그널 — "검증된 강사" 노출

회원 앱에 강사 신뢰도를 가시화. ([ADR 0002](../decisions/0002-license-policy.html) 신뢰 보완 장치)

- 강사 카드: **"본사 검증 완료"** 뱃지 + **"자격증 보유"** 뱃지 병행
- 평점·재예약률·클래스 수 함께 표시 (일관성)
